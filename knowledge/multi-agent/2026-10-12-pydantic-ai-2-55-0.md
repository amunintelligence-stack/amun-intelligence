# Pydantic AI 2.55.0 — تخزين موجّه مؤقت عبر المزودين وإسقاط Python 3.10
## ماذا تغيّر
- صدر Pydantic AI 2.55.0 في 2026-10-09 (PyPI: pydantic-ai-slim).
- الجديد: إعداد `cache` موحد وقدرة `Caching` للتخزين المؤقت للموجّهات عبر المزودين (cross-provider prompt caching) مع تقارير صحة التخزين لكل محادثة — يخفض التكلفة والزمن للمهام المتكررة؛ كائن `Conversation` يحمل الحالة بين التشغيلات؛ خلفية `OpenAIDecisionsModel`؛ مخازن خطوات ووسائط مدعومة بـ Postgres؛ دعم `claude-haiku-5-5`.
- تحسين أداء لافت: تحميل وحدة MCP أصبح كسولًا (lazy) فيخفض زمن `import pydantic_ai` إلى النصف تقريبًا — إشارة إلى أن تضخم سياق/وحدات MCP مشكلة معترف بها حتى لدى الأطر الكبرى.
- كسر: يتطلب الآن Python 3.11+ (إسقاط 3.10).
## لماذا يهم ACI
- التخزين المؤقت للموجّهات عبر المزودين نمط يستحق التبني في مهام ACI المتكررة (نفس التعليمات تُرسل لعشرات الأهداف) — خفض مباشر في التكلفة.
- تحذير التوافق: أي اعتماد مستقبلي يتطلب Python 3.11+؛ بيئتنا الحالية متوافقة.
