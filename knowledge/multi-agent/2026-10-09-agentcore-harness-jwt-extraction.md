# حقن موجّه غير مباشر يستخرج JWTs هوية AWS AgentCore من heap الأداة عبر `/proc` (أكتوبر 2026)

- التاريخ: 2026-10-09 | الفئة: multi-agent | الإجراء: **مراقبة (watch)** — قاعدة تصميمية لوكلاء ACI

## ما الذي تغيّر
حقن في تذكرة دعم يجعل أداة الـ shell الافتراضية (root) في AWS AgentCore Harness تقرأ heap المضيف عبر `/proc` وتستخرج JWTs هوية AgentCore بنص صريح، ثم تُعاد ضد خدمات MCP لاحقة. AWS أغلقت البلاغ كـ "مسؤولية مشتركة" — الإصلاح على المستخدم: إزالة أداة الـ shell الافتراضية أو تقييد نطاقها.

## لماذا يهم ACI
تحذير مباشر لأي وكيل OSINT نمنحه أدوات shell/تنفيذ: أداة shell واسعة + بيانات اعتماد في البيئة = استخراج أسرار. القاعدة: مبدأ أقل امتياز، وعزل الأسرار عن بيئة تنفيذ الوكيل.
