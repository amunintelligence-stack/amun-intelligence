# دلتا الأطر متعددة الوكلاء — 6 نوفمبر 2026

## CrewAI 1.15.36 — صدر اليوم؛ جلسات وكيل محادثة تجريبية
- **التاريخ:** 1.15.36 صدر 2026-11-06 (اليوم)؛ 1.15.35 في 3 نوفمبر.
- **ما الذي تغيّر:** ميزات: **جلسات وكيل محادثة تجريبية** (experimental conversational Agent sessions)، طلب مفتاح API مفقود عند بدء `crewai run`، تسجيل صنف الخطأ عند فشل تحميل مشروع، تسمية التطبيقات التي لا يحلها CrewAI AMP. إصلاحات: تنفيذ استدعاءات غير متزامنة في سياق المتصل للأدوات المتزامنة، إيقاف نظيف لتشغيل JSON crew عند غياب مفتاح API، استدعاء أدوات GPT-6 Astra وGPT-6.1 Sol عبر Responses API، إسقاط قيم metadata الفارغة قبل الكتابة إلى ChromaDB، تثبيت crewai-files في extra معالجة الملفات.
- **لماذا يهم ACI:** ACI لا يشغّل CrewAI (التنسيق n8n + FastAPI). جلسات المحادثة التجريبية نمط يستحق الملاحظة إن أُضيفت واجهة محادثة لمهام ACI يومًا؛ لا محفز اعتماد.
- **المصادر:** https://github.com/crewAIInc/crewAI/releases/tag/1.15.36
- **الإجراء: watch.**
