# OpenAI Agents API بيتا عامة (10 سبتمبر 2026) — runtime أوركسترا مُدار مع MCP + وكلاء فرعيين؛ تقاعد Assistants API

- التاريخ: 2026-10-08 | الفئة: multi-agent | الإجراء: **مراقبة (watch)**

## ما الذي تغيّر
أطلقت OpenAI واجهة Agents API في بيتا عامة بتاريخ 2026-09-10، معبّئة بنية الوكلاء طويلة التشغيل الخاصة بـ Codex harness خلف API: جلسات دائمة، وإدارة سياق، وملفات، وتنفيذ كود، وأدوات MCP، وبحث ويب، وتنسيق وكلاء فرعيين. تكمّل Responses API (استدعاءات الموديل العامة) وAgents SDK مفتوح المصدر (حلقة أوركسترا ذاتية الاستضافة)؛ وتقاعدت Assistants API القديمة في 26 أغسطس 2026.

## لماذا يهم ACI
يُصدّق اتجاه بنية orchestrator-workers + evaluator في ACI (مختبر رئيسي يبيع الآن بالضبط هذا كخدمة مُدارة). على المدى الطويل يوفر بديلًا لأوركسترا FastAPI ذاتية الاستضافة في ACI؛ وعلى المدى القصير نموذج تنسيق الوكلاء الفرعيين فيه مرجع تصميمي للمقارنة مع تنفيذ الأنماط الخمسة في ACI.
