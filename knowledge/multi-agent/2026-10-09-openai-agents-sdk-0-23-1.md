# OpenAI Agents SDK v0.23.1 — تكامل Realtime API، دعم MCP أصيل، تتبّع Sentry، والنموذج الافتراضي gpt-5.4-mini (2 أكتوبر 2026)

- التاريخ: 2026-10-09 | الفئة: multi-agent | الإجراء: **مراقبة (watch)** — مرشح للتجربة في مهام ACI الخفيفة

## ما الذي تغيّر
السلسلة حتى v0.23.1 أضافت: تكاملًا أصيلًا مع Realtime API (وكلاء صوتيون)، دعمًا من الدرجة الأولى لخوادم MCP (أي أداة تتكلم MCP تصبح قدرة جاهزة)، تكامل تتبّع Sentry (يلتقط التشغيلات واستدعاءات الأدوات والـ prompts وعدد الـ tokens)، والنموذج الافتراضي أصبح gpt-5.4-mini. الـ SDK معلن كـ provider-agnostic منذ ديسمبر 2025 (يدعم Claude عبر LiteLLM وOllama محليًا). ملاحظة: هذا غير الـ Agents API المدارة التي غُطيت الليلة الماضية — هذا الـ SDK مفتوح المصدر الذي يُشغَّل ذاتيًا.

## لماذا يهم ACI
الـ SDK خيار خفيف لبناء حلقات orchestration مخصصة ضد Responses API؛ دعم MCP الأصيل يعني أن أدوات OSINT المكشوفة عبر MCP تندمج مباشرة.
