## 1. Perplexity Multiagent — وضع جهد جديد ينسّق حتى 16 وكيلًا داعمًا (17 نوفمبر 2026)

- **ما الذي تغيّر:** أطلقت Perplexity اليوم **17 نوفمبر 2026** وضع **Multiagent** في منصة وكيل Computer: قائد (Claude Fable 5.2) يخطط العمل ويوزعه على **حتى 16 وكيلًا داعمًا** عبر نماذج حدودية عدة (Claude Opus 5.5، GPT 6.1 Sol، Gemini 4 Carbon؛ ويمكن لـ Fable 5.2 وGPT 6 Astra الانضمام كداعمين عند الطلب)، يشاركون الأدلة ويتحققون متقاطعًا قبل تسليم رد واحد. يقع فوق مستوى Ultra في منزلق الجهد (Light/Standard/High/Ultra منذ سبتمبر 2026). **متاح لمشتركي Perplexity Max فقط، على الويب.**
- **لماذا يهم ACI:**‏ نمط «قائد + وكلاء داعمون متعددو النماذج مع تحقق متقاطع» هو نفسه نمط مجلس ACI (M1 يجمع الأصوات ← M3 مدافع الشيطان ← M2 مخاطر ← E1 بوابة) — لكنه هنا منتج مغلق مدفوع (Max $200/شهر) بلا API موثق للتنسيق. القيمة مرجعية نمطية: التحقق المتقاطع بين نماذج مختلفة قبل الرد الواحد يقلل هلوسة الإجماع في مهام الاستخبار؛ لا اعتماد ولا اشتراك.
- **المصادر:** https://www.unite.ai/perplexity-launches-multiagent-to-coordinate-frontier-ai-models/ (17 نوفمبر 2026)
- **الإجراء: watch** — سجّل النمط (تحقق متقاطع متعدد النماذج) في مرجع تصميم المنسّق؛ لا اشتراك Max.

## 2. نماذج القرار — Perplexity Decider v1.3 وGemini Decisions API (انظر ملف بحث الذكاء الاصطناعي)

- **ما الذي تغيّر:** **Perplexity Decider v1.3 وDecider Flash v1.3** (12 نوفمبر): استخراج نص حرفي (Locate) بمواضع أحرف دقيقة لـ NER وكشف PII والأسئلة الاستخراجية؛ أوزان مفتوحة Apache-2.0 (Qwen3.8-27B / Qwen3.5-4B)؛ دقة 91.6% عبر 63 مهمة تصنيف؛ Decisions API بـ $0.02/$0.01 لكل مليون رمز إدخال. وفي السياق: **Google DeepMind أطلقت Gemini Decisions API** (Gemini Decision 1 يجيب حتى 1,000 سؤال عن نفس المادة في تمريرة واحدة)، وOpenAI عمّمت Decisions API في 22 أكتوبر، وAmazon أصدرت Strands Decider 2B في أكتوبر.
- **لماذا يهم ACI:**‏ نماذج القرار (احتمالات بدل نثر) تناسب بوابات ACI (E1: قبول/رفض بدرجة) وتصنيف الأدلة وكشف PII في المستندات المجمّعة — أرخص وأكثر حتمية من توليد نص حر. التفاصيل الكاملة في ملف `data-sources/ai-search/2026-11-17-ai-search-nov17.md`.
- **المصادر:** https://www.unite.ai/perplexity-releases-decider-v1-3-models-with-text-span-extraction/ (12 نوفمبر 2026)
- **الإجراء: watch** — قيّم Decider Flash (محلي، 8.5 GiB) لتصنيف الأدلة وكشف PII في مهمة تجريبية لاحقة؛ لا اعتماد قبل قياس.
