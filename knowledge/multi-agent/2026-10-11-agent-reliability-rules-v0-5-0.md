# Trustabl agent-reliability-rules v0.5.0: 276 قاعدة فحص لوكلاء الإنتاج (أكتوبر 2026)

- التاريخ: 2026-10-11 | الفئة: multi-agent | الإجراء: **اعتماد**

## ما الذي تغيّر
أصدر مشروع trustabl/agent-reliability-rules النسخة **v0.5.0** (~1 أكتوبر 2026) — أكبر إصدار حتى الآن: من 208 إلى **276 قاعدة** (+68)، ومخطط الحزم 15→17. حزم القواعد تغطي: LangChain، OpenAI Agents SDK، **MCP** (8 قواعد جديدة: MCP-023–MCP-029 وMCP-201)، CrewAI، AutoGen/AG2، Google ADK، Claude Agent SDK، Vercel AI، Pydantic AI، ومهارات الوكلاء. محاور التغطية: مهلات الشبكة، عقود الأخطاء المنظمة، سلامة المسارات، مفاتيح عدم التكرار (idempotency)، جودة أوصاف الأدوات، أسماء الأدوات الغامضة، كتابات stdout التي تفسد نقل stdio، **قوائم السماح (allow-lists) وبوابات الموافقة في MCP**، والمشاريع التي تُشحن دون وثيقة توجيه للوكيل.

## لماذا يهم ACI
هذه قائمة فحص جاهزة وقابلة للأتمتة في CI لكل ما نبنيه: وكلاء ACI، تكاملات MCP، وأدوات OSINT. قواعد MCP (allow-lists + approval gates) و«جودة أوصاف الأدوات» تعالج مباشرة مخاطر تسميم الأدوات التي رصدناها الليلة. لا تتطلب تشغيل أي خدمة — فحص استاتيكي.
