# Google ADK Python 2.11.0 — إلغاء منفّذ لطيف، تأكيد الأدوات في سير العمل، ModelConsultTool، ذاكرة SQLite، ودعم MCP SDK 2.x (1 أكتوبر 2026)

- التاريخ: 2026-10-09 | الفئة: multi-agent | الإجراء: **مراقبة (watch)** — قيّم الترقية في اختبار أولًا

## ما الذي تغيّر
من صفحة الإصدار الرسمية على GitHub:
- إلغاء التنفيذ: `abort_signal` لـ Runner/Workflow/العقد لإيقاف لطيف؛ `/run_sse` يلغي التشغيل عند انقطاع العميل.
- تأكيد الأدوات في سير العمل: عقد الأدوات تتوقف الآن لطلب موافقة المستخدم عبر `RequestInput` بدل تمرير الخطأ للأسفل.
- ModelConsultTool: وكيل يستشير نموذجًا آخر mid-task بميزانيات لكل دورة وجلسة.
- خدمة ذاكرة SQLite مدمجة (عبر `sqlite://` URI).
- دعم MCP SDK 2.x عبر مسار opt-in جديد (البروتوكول الحديث 2026-07-28).
- توجد breaking changes — تُراجع من صفحة الإصدار قبل أي ترقية.

## لماذا يهم ACI
ADK أحد الأطر المرشحة لبنية وكلاء ACI؛ دعم MCP 2.x الأصلي + الذاكرة المحلية + بوابات الموافقة البشرية في سير العمل كلها تخدم مهام OSINT الطويلة. الثغرة المعروفة لدينا CVE-2026-79696 كانت في ADK — أي ترقية يجب أن تمر بمراجعة أمنية.
