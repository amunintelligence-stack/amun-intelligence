# CrewAI 1.15.19←1.15.23 (سبتمبر 2026) — تقييم آخر trace عبر AMP، ودعم Gemini 3.8 Flash أصليًا، وخطافات استدعاء الموديلات

- التاريخ: 2026-10-08 | الفئة: multi-agent | الإجراء: **مراقبة (watch)**

## ما الذي تغيّر
إصدارات CrewAI في سبتمبر كانت تدريجية لكن ذات صلة بالتقييم: v1.15.23 (28 سبتمبر) أضاف دعم Gemini 3.8 Flash أصليًا و`crewai eval` الذي يقيّم **آخر تشغيل مُتتبَّع** عبر AMP (تسجيل التشغيلات المتتبعة، وتتبع امتدادات المهام بصيغة/نتائج الإخراج المعلنة، وزر Evaluate في TUI، وطباعة CLI للمجالات المُدرَّجة)؛ v1.15.19 (4 سبتمبر) أضاف خطافات استدعاء موديلات تعمل على كل مسار وتنشر الرفض، ومخرجات منظمة أصلية لموديلات Claude الحالية، وترقيات أمنية (pypdf 6.16.2 وnltk 3.10.3 لثغرات). جانب LangGraph: 1.2.12 الحالي مطلع أكتوبر 2026 بإيقاع إصلاحات ثابت؛ لا إصدار ميزة رئيسي داخل النافذة. Microsoft Agent Framework مستقر عند Python 1.19.0 / .NET 1.22.0 (18 سبتمبر 2026) مع Agent Harness/Foundry Hosted Agents المستضافة من Microsoft الآن GA — نضج مؤسسي ثابت، لا تغييرات API ذات صلة بـ ACI.

## لماذا يهم ACI
نمط "تقييم آخر تشغيل مُتتبَّع" هو تنفيذ خفيف لـ evaluator-optimizer تصفه بنية ACI مفاهيميًا أصلًا — النسخة المشحونة في CrewAI (تتبع ← تقييم ← تغذية راجعة) مرجع ملموس لكيفية إغلاق الحلقة بين المهام ودرجات التقييم في مخزن RAG/الذاكرة الخاص بـ ACI.
