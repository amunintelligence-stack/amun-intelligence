## 2. Microsoft Agent Framework python 1.26.0 (13 نوفمبر) — مسار الخلف الوحيد من Microsoft

- **ما الذي تغيّر:** **agent-framework 1.26.0** على PyPI (13 نوفمبر 2026) — الخليفة الرسمي لـAutoGen وSemantic Kernel (GA 1.0 في 2 أبريل 2026)، بإصدارات شبه أسبوعية. **AutoGen مؤرشف**: آخر إصدار autogen-agentchat 0.7.5 (30 سبتمبر 2025)، وMicrosoft تعلن «لا إصلاحات ولا دعم»، وتنصح بعدم استخدامه في الإنتاج.

- **المصادر:** https://agilefever.com/ai-agent-frameworks-compared/ (فُحص 18 نوفمبر 2026)؛ https://www.aiagentsinfo.com/research/which-ai-agent-framework-to-install-november-2026 (14 نوفمبر 2026)
