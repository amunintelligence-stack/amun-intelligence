# LangGraph 1.2.13 و1.2.14 (أكتوبر 2026): إصلاحات إعادة تشغيل نقاط التفتيش

- التاريخ: 2026-10-11 | الفئة: multi-agent | الإجراء: **مراقبة**

## ما الذي تغيّر
صدرت langgraph **1.2.13** (~5 أكتوبر 2026) ثم **1.2.14** (~10 أكتوبر 2026) على GitHub (langchain-ai/langgraph). كلتا النسختين إصلاحات دقيقة في محرك نقاط التفتيش/الفروع: الانشقاق (fork) قبل إعادة تشغيل checkpoint تجاوزه الخيط، إبقاء update_state على checkpoint قديم خارج فروعه الأخرى، إصلاح عدّادات DeltaChannel في كل مسارات update_state، وعدم الإبلاغ عن interrupts المُجابة في get_state. بالتوازي: langgraph CLI **0.4.33** أضاف أمر `deploy` (نشر صورة مبنية مسبقًا، وقوائم المستمعين) و**يرفض تبعيات Git الحاملة لبيانات اعتماد**.

## لماذا يهم ACI
نمط المنسّق (orchestrator) في ACI يعتمد على التنفيذ الدائم القابل للاستئناف — وإصلاحات إعادة تشغيل الـ checkpoints تمسّ بالضبط سيناريو «مهمة استخبارات طويلة تُستأنف بعد انقطاع». رفض بيانات الاعتماد في تبعيات Git ممارسة أمنية جديرة بالنسخ في أي نشر نفعله.
