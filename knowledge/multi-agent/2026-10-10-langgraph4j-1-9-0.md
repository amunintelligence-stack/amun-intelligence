# LangGraph4j — نسخة 1.9.0/1.9.3 (سبتمبر–أكتوبر 2026)
- التاريخ: 2026-10-10 | الفئة: multi-agent | الإجراء: **مراقبة**

## ما الذي تغيّر
- **1.9.0** (منتصف سبتمبر 2026، مع 1.8.x الآن في LTS): العقدة يمكنها بث مخرجات مخصصة (`NodeOutput`) أثناء التنفيذ قبل إرجاع النتيجة — streaming للتقدّم داخل العقدة.
- **1.9.1** (2026-09-23): تكامل AG-UI (واجهات agent-chat) و Spring Boot implementation لـ CopilotKit.
- **1.9.3** (2026-10-01): lifecycle أغنى لـ checkpoint savers، أسباب موثقة للـ interrupts، وإصلاح ترميز UTF-8 في Studio.
- خط البث: threadplane 0.2.0 (18 سبتمبر 2026) جلب durable agent recovery و interrupts أكثر أمانًا مع تغييرات auth في LangGraph client (إزالة `apiKey` لصالح `defaultHeaders` — فصل مفاتيح الـ deployment عن session tokens).

## لماذا يهم ACI
- ACI حاليًا بايثون بالكامل، لكن إن احتاج محمد يومًا مكون Java (أو دمج مع أنظمة جافا مؤسسية) فـ LangGraph4j أصبح ناضجًا في البثّ والـ persistence.
- نمط NodeOutput streaming مفيد conceptually: أي مهام ACI طويلة (جمع OSINT) يمكنها إرسال تقدّم جزئي قبل اكتمال العقدة — يمكن تقليد الفكرة في Python backend.
