# Neo4j Context Engine launched (2026-10-20)

## What changed
Neo4j announced the **Neo4j Context Engine** on 2026-10-20: a productized "AI knowledge layer" for enterprise agents, now in private preview. Components: **Agent Setup** (simplified config for agents, MCP servers, dev tools), **Context Memory** (graph-native short-term, long-term and reasoning memory plus skill distillation), **Decision Tracking** (logs agent reasoning paths as a permanent enterprise record), **Knowledge Distillation** (graph algorithms condense repeated events into reusable knowledge), and **Continuous Improvement** (learned insights feed back into future reasoning). Positioned against Gartner's AI Context Platforms category (Aug 2026 market overview).

## Why it matters for ACI
This is the strongest industry validation yet of ACI's architecture direction: a persistent, graph-structured context substrate that outlives individual agent sessions. The "decision tracking as permanent record" and "skill distillation from repeated events" maps directly onto ACI's memory recall and mission-populated graph plans. It also signals Neo4j is moving up the stack into agent memory — our graph layer should be designed as a portable context service, not locked to one vendor's preview.
