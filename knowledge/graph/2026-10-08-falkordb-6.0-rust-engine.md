# FalkorDB 6.0 — أول إصدار على محرك Rust الجديد (قاعدة بيانات رسومية أصلية لـ GraphRAG)

- التاريخ: 2026-10-08 | الفئة: graph | الإجراء: **مراقبة (watch)**

## ما الذي تغيّر
صدر ~29 سبتمبر 2026. FalkorDB 6.0 أول إصدار مبني على إعادة كتابة كاملة بلغة Rust (17 شهرًا، 80k سطر، 357 PR) لمحرك الرسوميات القائم على المصفوفات المتناثرة. ينفّذ 39% تعليمات CPU أقل من محرك C عبر 300+ استعلام قياسي، ويغلق 226 خللًا (43 عطلًا و6 عيوب سلامة ذاكرة)، ويضيف runtime عموديًا وMVCC — مع الحفاظ على Cypher وواجهة `GRAPH.*` ومكتبات العملاء دون تغيير. يشحن FalkorDB أيضًا FalkorDBLite (نسخة Python مضمّنة) وSDK خاصًا بـ GraphRAG، متموضعًا كبديل GraphRAG-أصلي.

## لماذا يهم ACI
الرسم البياني لدينا حاليًا networkx في الذاكرة + لقطات JSON في Postgres — كافٍ الآن، لكن رسمًا متراكمًا عبر المهام سيتجاوزه. النسخة المضمّنة وSDK الخاص بـ GraphRAG هما أقرب بديل خفيف لخادم Neo4j لرسم خرائط الكيانات/العلاقات في الاستخبارات المؤسسية، وإعادة كتابة 6.0 للاستقرار تعالج مخاوف الأعطال التي أبقت الإصدارات السابقة خارج الاعتبار.
