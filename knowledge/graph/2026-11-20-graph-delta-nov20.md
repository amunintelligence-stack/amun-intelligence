# دلتا الرسوم البيانية — ArcadeDB 26.11.1 وSurrealDB 4.0.1 وTypeDB 3.14.2 إصدارات نوفمبر؛ وسوم Neo4j مضللة (alpha) — اعتمد صفحة الإصدارات (20 نوفمبر 2026)

## 1. إصدارات نوفمبر من محركات متعددة النماذج: ArcadeDB 26.11.1، SurrealDB 4.0.1، TypeDB 3.14.2، OrientDB 3.2.58

- **ما الذي تغيّر:** تتبّع إصدارات نوفمبر 2026 يسجّل: **ArcadeDB 26.11.1**، **SurrealDB 4.0.1**، **TypeDB 3.14.2**، **OrientDB 3.2.58** — كلها إصدارات نوفمبر. وتحديث مقارنة ArcadeDB في **12 نوفمبر** يسجّل تغييرات ترخيص مهمة: LadybugDB يُصدر بنشاط الآن، شروط ArangoDB Community Edition تغيرت في 3.12.5، Memgraph لم يعد ينشر أسعار Enterprise، ترخيص FalkorDB مسمّى (SSPL v1)، وRedis وElastic أضافا خيار AGPL.
- **لماذا يهم ACI:**‏ خريطة الترخيص تتحرك بسرعة: أي محرك يُقترح لطبقة الرسم يجب فحص ترخيصه الحالي لا ترخيص العام الماضي. ArcadeDB (متعدد النماذج، رسم كأحد 6 نماذج) يبقى بديلًا ثانويًا بعد FalkorDB في الخطة؛ SurrealDB 4.0.1 يستحق نظرة واحدة كمحرك رسم+وثائق موحّد إن أُعيد النظر في الطبقة.
- **المصادر:** https://www.peterindia.net/GraphDBs.html (فُحص 20 نوفمبر 2026)؛ https://arcadedb.com/blog/neo4j-alternatives-in-2026-a-fair-look-at-the-open-source-options/ (حدّث 12 نوفمبر 2026)
- **الإجراء: watch** — أضِف ArcadeDB 26.11.1 وSurrealDB 4.0.1 إلى السجل كبدائل موثقة؛ لا تغيير في خطة FalkorDB.

## 2. Neo4j — وسوم GitHub تعيد alpha؛ صفحة الإصدارات ما زالت 2026.10.2

- **ما الذي تغيّر:** GitHub API الليلة على `neo4j/neo4j releases/latest` يعيد **3.2.0-alpha08** — وسم alpha لا يمثل الإصدار المستقر. صفحة الإصدارات/التتبع ما زالت تسجّل **2026.10.2** (2 نوفمبر) الأحدث المستقر. هاكاثون **Relate** (فُتح 11 نوفمبر، شهر كامل) ما زال جاريًا؛ لا أخبار جديدة عنه الليلة.
- **لماذا يهم ACI:**‏ قاعدة منهجية: لمستودعات Neo4j لا تعتمد `releases/latest` وحده — تحقق من صفحة الإصدارات أو الوسوم المستقرة.
- **المصادر:** GitHub API (neo4j/neo4j releases/latest، فُحص 20 نوفمبر 2026)؛ https://www.firmwarely.com/devices/neo4j/
- **الإجراء: watch** — لا تغيير.
