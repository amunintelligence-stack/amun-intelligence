# FalkorDB v6.0.2: إصلاحات محرك Rust + تشديد أمني في صور Docker

## ماذا تغيّر
- إصدار صيانة جديد (أوائل أكتوبر 2026، لاحق لـ 6.0.1 المغطى سابقًا) لمحرك Rust الجديد، أبرز ما فيه:
  - إصلاحات استعلامات: `CALL {}` الفرعية لم تعد تقرأ متغيرات الاستعلام الخارجي؛ إصلاح فهارس النطاق ونتائج vector KNN (تقييد `k` بدل تخصيص مدخلاته)؛ بُعد متجه خاطئ لم يعد يُسقط الكيان من كل فهارس تسميته.
  - **IdSpace** أصبحت المرجع الوحيد لمعرفات العقد والعلاقات — الكتابة تخضع لنفس فحص المعرفات الذي تخضع له النسخ المتماثلة.
  - أمن/تشغيل: صورة Docker تشغّل `redis-server` كمستخدم غير جذري `falkordb` (تجاوز عبر `SKIP_DROP_PRIVS=1`)؛ إضافة فحص Trivy للصور في CI؛ إزالة util-linux من صورة التشغيل.
  - بناء: الانتقال إلى LLVM 23، واعتماد GraphBLAS وLAGraph كـ submodules عبر crate وطني `native-deps`.

## لماذا يهم ACI
- FalkorDB مرشح لمخزن الرسم البياني في ACI (بديل خفيف لـ Neo4j). 6.0.2 يحل محل 6.0.1 كإصدار مرجعي — بما فيه تصحيح Redis CVE-2026-85091 من 6.0.1.
- إصلاحات KNN وتقييد `k` مهمة لأي استخدام هجين (متجهات + رسم بياني) مستقبلًا.
