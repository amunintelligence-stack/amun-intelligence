# GraphIQ — MCP 2.0 وLocations Ontology (14 أكتوبر 2026)

## ماذا تغيّر؟
أطلقت GraphIQ (رسم هوية الشركات التجاري) في **14 أكتوبر 2026**:
- **MCP 2.0:** خادم MCP عن بُعد (https://app.graphiq.ai/mcp) مع **17 أداة للقراءة فقط** عبر 6 مجالات (منظمات، أشخاص، أخبار مكررة التنقية مع تحليل مشاعر، أنطولوجيات قدرات/تقنيات/NAICS/أماكن، بحث ويب حي، أدلة playbooks). **6 أدلة خطوة-بخطوة**: بحث شركات، خرائط سوق، قوائم عملاء محتملين، إيجاد جهات اتصال، مراقبة أخبار، مرجع صياغة الاستعلام.
- **Locations Ontology:** اسم قانوني واحد لكل مكان (دولة/ولاية/مقاطعة/مدينة) عبر الرسم — الأسماء المستعارة تُحسم تلقائيًا.
- الحجم المعلن: 287M منظمة، 393M شخص، 2B+ مقال إخباري. الكشف عن جولات التمويل A–D خلال 24 ساعة من التقديم (من v1.20، فبراير 2026)، كل جولة تُحسم لكيان قانوني واحد.
- القادم: MCP 2.1 (أدلة أكثر) وتحسينات خط إزالة التكرار في سجلات الشركات (Canonical Org pipeline).
- ملاحظة أمنية إيجابية: كل الأدوات للقراءة فقط؛ الكتابة الراجعة (v1.18، ديسمبر 2025) محكومة بحوكمة قراءة/كتابة لكل مساحة عمل.

## لماذا يهم ACI؟
ACI منصة **استخبارات شركات** — رسم هوية بهذا الحجم مع حسم كيانات قانونية وأنطولوجيا أماكن هو مصدر بيانات مرشّح مباشر لمهامنا (خرائط الشركات الأم/الفرعية، تتبع التمويل والاندماج/الاستحواذ). نموذج MCP للقراءة فقط + الأدلة الجاهزة هو أيضًا النمط الذي يجب أن نقلّده عندما نعرض رسمنا الداخلي للوكلاء. العائق: يتطلب حساب MCP مدفوعًا ومفتاح API.
