# مختبر SOC آلي: Wazuh + Shuffle + VirusTotal + Discord (أكتوبر 2026)

- التاريخ: 2026-10-11 | الفئة: soar | الإجراء: **اعتماد (adopt)** — اعتمد نمط خط الإثراء في سير ACI

## ما الذي تغيّر
نُشر في 1 أكتوبر 2026 مختبر SOC آلي مفتوح (tayyab5608/soc-automation-lab) يوثّق خط أنابيب SOAR كاملًا ومُختبَرًا: Wazuh (SIEM) يكتشف مسح nmap ← استجابة نشطة تحظر المهاجم بجدار الحماية ← webhook إلى Shuffle ← سير عمل Shuffle يستخرج IP المهاجم ← **إثراء عبر VirusTotal API** (درجة الخبث وإحصاءات الكشف) ← إشعار Discord بتضمين غني. نسخة موازية (أغسطس 2026) تستخدم Elastic SIEM + Shuffle + VirusTotal + TheHive: التنبيه يُخصَّب ثم يُنشأ كحالة مُثراة في TheHive للمحلل. النمط المشترك: **تنبيه ← استخراج مؤشرات ← إثراء (سمعة IP/نطاق) ← قرار/إشعار ← توثيق الحالة**.

## لماذا يهم ACI
هذا بالضبط نمط "الإثراء" الذي يحتاجه ACI: نتيجة أداة خام (IP/نطاق/بريد) ← استدعاء API إثراء (VirusTotal المجاني، AbuseIPDB، Shodan) ← دمج السياق في التقرير. المختبر يعطي مرجعًا عمليًا لبنية سير عمل الإثراء في Shuffle/n8n، بما فيها معالجة الأخطاء والتنسيق الغني للإشعارات.
