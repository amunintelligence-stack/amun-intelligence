# SOAR: نمط خط إثراء SOC في n8n + لا جديد أمني في 2.45.3 (2026-10-26)

## ماذا تغيّر؟
- **نمط عملي موثّق (15 أكتوبر 2026):** خط أنابيب إثراء SOC خفيف مفتوح المصدر على n8n + Python + VirusTotal — مصادقة بالرمز، ترشيح IP داخلي، بحث في قواعد سمعة خارجية، ثم تنسيق تنبيه. التسلسل: استخراج المؤشر → إثراء مجاني → دمج → إشعار/تقرير. هذا يطابق مبادئ playbook المسجلة لدينا (لا إجراء خارجي لا رجعة فيه بلا موافقة بشرية؛ إثراء آلي كامل قبل أن يرى المحلل أي نتيجة).
- **n8n — لا جديد أمني:** 2.45.3 صدرت 23 أكتوبر كإصدار **ما قبل الإصدار (pre-release)** و1.123.87 على الخط 1.x — كلاهما صيانة، بلا CVE جديد منذ حزمة 14 أكتوبر. إصدارنا 2.43.7 ما زال فوق أرضية الحزمة (2.43.5+)، و2.45.x ما زال مرشح الترقية القادم عند «نفذ» بعد استقرار الخط.
- **سياق التعرض (تأكيد متكرر):** Censys أحصت ~114,000 مثيل n8n مكشوفًا، وثلاثة أرباع المكشوفة تعمل إصدارات فيها ثغرات حرجة معروفة — إثبات إضافي أن وضعنا المحلي فقط (localhost-only) هو الاختيار الصحيح، لا مجرد تفضيل.

## لماذا يهم ACI؟
- نمط الإثراء قابل للاستعارة مباشرةً لتدفقات إثراء ACI في n8n (مؤشر → VirusTotal/مصادر مجانية → دمج → تقرير)، مع إبقاء بوابة الموافقة البشرية قبل أي إجراء خارجي.
- لا إجراء ترقية الليلة: 2.45.3 ما قبل إصدار، ولا CVE يدفعنا للقفز قبل استقرار الخط.
