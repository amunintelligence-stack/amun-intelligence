# Splunk SOAR (Cloud) 8.7.0 — نهاية Python 3.9 (سبتمبر 2026)
- التاريخ: 2026-10-10 | الفئة: soar | الإجراء: **تجاهل** (سياق سوق فقط)

## ما الذي تغيّر
- **Splunk SOAR (Cloud) 8.7.0** صدر **2026-09-02**: إنهاء دعم Python 3.9 نهائيًا — كل الأتمتة (playbooks, custom functions, apps) يجب أن تكون متوافقة مع **Python 3.13** وإلا لن تُنفَّذ.
- توجد ميزة self-service migration داخل الـ UI مع linting tools للترقية التلقائية.
- **Automation Broker High Availability** دخل controlled availability (مجموعات brokers مع failover تلقائي).
- سياق سوق: ES 8.2 دمجت SOAR في Enterprise Security (Premier)؛ Cisco تعيد هيكلة تسعير Splunk؛ لا تقييم SOAR مخصص من Gartner/Forrester منذ 2022.

## لماذا يهم ACI
- ACI لا يستخدم Splunk SOAR، فلا تأثير مباشر — لكن الرسالة المعمارية مهمة: حتى عمالقة الـ SOAR يفرضون Python 3.13 ويهجرون الـ classic playbook editors. أي playbook/automation نبنيه مستقبلًا يجب أن يستهدف Python 3.13+ من اليوم الأول.
- الـ connector ecosystem (splunk-soar-connectors) يعلن Python 3.13 compatibility تباعًا (مثال: sumologic 2026-09-14، slack 2026-09-25).
