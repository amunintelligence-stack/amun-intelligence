# n8n 2.45.0 stable (Oct 20/21) — MCP TS SDK v2 + 2026-07-28 discovery handshake; no 2.46 yet; no new advisories since the Oct 14 batch

**Date found:** 2026-10-22 (2.45.0 tagged 2026-10-20, marked stable 2026-10-21; 2.44.5 patch 2026-10-21)
**Category:** soar / n8n

## What changed
- **n8n@2.45.0** shipped Oct 20 and went stable Oct 21 (the stable promotion itself was covered by the Oct 21 nightly — this file is the *feature delta* for ACI's upgrade calculus). **No 2.46** exists yet as of 2026-10-22.
- **MCP-relevant changes in 2.45.0:**
  - `core: Support the MCP 2026-07-28 discovery handshake on the instance server` — n8n now speaks the current MCP discovery revision (the same 2026-07-28 revision ACI's SEP-2640 Skills work tracks). ACI's n8n MCP trigger/integration surface aligns with the current spec.
  - `core: Upgrade the MCP client to the MCP TypeScript SDK v2` — picks up the TS SDK security fixes from the Sep 28–Oct 5 advisory batch (see mcp/2026-10-22-mcp-sdk-oauth-advisories.md).
  - `Overhaul MCP tool permissions for Agents (#39878)` — broad rework of how agents get MCP tool permissions; "Don't save MCP connections without user approval (#39996)" (anti-rug-pull hygiene baked in); "Describe MCP servers only from user or registry text in Agent Builder" (prompt-injection hardening on server descriptions); "Evict idle mcp-browser sessions" (connection-leak fix).
  - `MCP Trigger Node: Pass through MCP content arrays instead of double-wrapping tool results` (bug fix).
- Other notable 2.45 items: **Kafka Node v2 becomes the default** (with compression options added), **Monday.com Node V2** with full V1 parity as default, **durable scheduler enabled by default**, **budget alerts and stops on sub-agent runs**, apply budget alerts to sub-agent run (#40884), revoked access tokens refused on the inbound pipeline, node/credential type policies on by default.
- **n8n@2.44.5** (Oct 21): patch on the 2.44 beta line only (queue job-outcome keying on shutdown resume, credential-type loading on startup) — no security content.
