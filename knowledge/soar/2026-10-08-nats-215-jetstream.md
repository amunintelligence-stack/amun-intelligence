# NATS Server 2.15 (سبتمبر 2026) — توسع JetStream ونسخ احتياطي v2 للتيارات وإنتاجية نسخ متزامن ~100x

- التاريخ: 2026-10-08 | الفئة: soar | الإجراء: **مراقبة (watch)**

## ما الذي تغيّر
NATS Server 2.15 (وارد في خلاصة التكامل لسبتمبر 2026) يسلّم توسع التيارات/المستهلكين ونقلها وإزالة الأقران إلى تسوية الحالة المرغوبة بقيادة asset leaders، مع فحوصات النسخ واللحاق قبل تغييرات مجموعة الأقران. النسخ الاحتياطي v2 للتيارات يخزّن الرسائل واحدة بواحدة ويدعم فلترة CLI ونطاقات التسلسل/الوقت وتحرير الترويسات والتعتيم دون قفل حصري. تجميع Raft مع إسقاط المزامنات الزائدة لكل رسالة يرفع إنتاجية النسخ بـ `sync: always` بنحو 100x ويخفض زمن الذيل ~40%؛ ورُفع default_max_consumers إلى 1000.

## لماذا يهم ACI
يُحفّز ACI المهام حاليًا عبر webhook في n8n — كافٍ اليوم، لكن لو تجاوز مروحة المهام أو قوائم إعادة المحاولة أو معالجة الرسائل الميتة الـ webhooks يومًا، سيلزم حافلة أحداث. تحسينات NATS 2.15 التشغيلية (عمليات أخف من Kafka، وأنماط DLQ/مستهلك مدمجة، وKV + object store لحمولات claim-check) تقوّي حجة NATS JetStream كتلك الحافلة المستقبلية.
