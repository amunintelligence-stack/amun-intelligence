# n8n: إصدارات 2.44.6 و2.45.2 و2.45.3 (21–23 أكتوبر) — لا CVEs جديدة، إصلاحات تشغيلية مهمة (2026-10-23)

## ماذا تغيّر؟
- **2.44.6** (stable، ‏2026-10-22): إصلاح **Postgres Node: Prevent global pgtypes overwrite** — منع الكتابة فوق `pgtypes` العامة، وهو إصلاح استقرار يمنع تداخل أنواع بيانات Postgres بين تنفيذات متوازية.
- **2.45.2** (pre-release، ‏2026-10-22): نفس إصلاح Postgres + **core: Export the migration report as CSV** + قراءة سياسات الأنواع من الذاكرة عند نقاط التنفيذ.
- **2.45.3** (pre-release، ‏2026-10-23): إصلاح تباين نصي بسيط في المحرر فقط.
- **2.44.5** (stable، ‏2026-10-21): **core: Key queue job outcomes by job on shutdown resume** — تثبيت نتائج مهام الطابور (queue) بالمهمة عند الاستئناف بعد الإغلاق؛ و**editor: Load credential types on startup**.
- **2.45.0** (pre-release، ‏2026-10-20): عدد كبير من الإصلاحات، أبرزها:
  - **API: Apply projectId filter to executions for member API keys** — تشديد أمني: مفاتيح API للأعضاء تُصفّى الآن حسب المشروع (متابعة لنفس محور Oct-14 bulletin حول الوصول العابر للمشاريع).
  - **core: Create an XML parser for each webhook request body** — إنشاء محلل XML جديد لكل طلب webhook (نمط دفاعي ضد تسرب الحالة/هجمات entity expansion — يتقاطع مع CVE-2026-44791 تجاوز تصحيح XML).
  - **core: Evict idle mcp-browser sessions to prevent connection leak** — تسريب اتصالات MCP متصفح (ذو صلة بموضوعنا 2026-10-22 عن mcp-stack).
  - تحديث **vm2** في Code Node لمعالجة **CVE-2023-32313** (حسب changelog عبر Cloudron؛ لم تُعلنه n8n كـ CVE جديد لأنها قديمة).
- **ملاحظة تحقيق:** منتدى Cloudron يذكر "2.46.0" لكنه **غير موجود على صفحة GitHub الرسمية** (الأحدث الرسمي 2.45.3) — يُعامل كشائعة/ترقيم داخلي لمنصة أخرى.

## لماذا يهم ACI؟
n8n v2.43.7 هي طبقة الأتمتة الذاتية الاستضافة لدينا — الترقيعات والإصلاحات التشغيلية قابلة للتنفيذ مباشرة. **لا توجد CVEs جديدة أو نشرات أمنية جديدة** بعد Oct-14 bulletin، لذا لا استعجال. لكن إصلاحين ذوا صلة تشغيلية مباشرة:
1. تثبيت نتائج queue jobs عند الاستئناف (2.44.5) — يؤثر على موثوقية mission pipelines إذا أعدنا التشغيل/التحديث.
2. فلتر projectId لمفاتيح API الأعضاء — تشديد أمني يستحق أن نستفيد منه عند الترقية.
3. إصلاح Postgres pgtypes — ACI يستخدم Postgres، وأي تعارض أنواع بيانات في workflows الذكاء قد يسبب فساد نتائج صامتة.
