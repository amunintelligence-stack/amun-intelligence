# دلتا SOAR — إصدار n8n مستقر جديد ‏2.48.8‏ صدر اليوم؛ بيتا ‏2.49.5‏؛ Shuffle ما زال بلا نهائي؛ وNATS يتخرج من CNCF (23 نوفمبر 2026)

> نطاق الدلتا: التغييرات منذ ملف أمس (2026-11-22-soar-nov22-delta.md). ما ورد في ملف أمس دون تغيير لا يُعاد كجديد — فقط التأكيدات والتفاصيل الجديدة.

## 1. n8n ‏2.48.8‏ مستقر صدر اليوم (23 نوفمبر 2026) — مرشح الترقية الجديد بدل ‏2.48.7‏

- **ما الذي تغيّر:** صفحة GitHub releases (فُحصت 23 نوفمبر 2026، 19:56 UTC) تبدأ بإصدارين جديدين اليوم: المستقر ‏2.48.8‏ وبيتا ‏2.49.5‏ (ثم ‏2.49.4‏ اليوم أيضًا). ‏2.48.8‏ إصلاحات فقط، بلا ميزات كبيرة وبلا إصلاحات أمنية:
  - ‏core‏: منح أدوار المثيل المخصصة (custom instance roles) الوصول إلى Migration Report (‏#44667‏).
  - ‏core‏: رمي خطأ عند بلوغ التعبير حد الذاكرة على محرك quickjs (‏#44687‏).
  - ‏editor‏: شرح آخر حالة تشغيل للـworkflows في Migration Report (‏#44282‏) + إبقاء أدوات التقرير داخل الشاشات الضيقة.
  - الإبلاغ عن فشل تفعيل مشغّل MCP workflow (‏#44589‏).
  - ‏2.49.5‏ بيتا يحمل إصلاحين فقط: تحديث التوكن المخزّن لبيانات اعتماد قابلة للانتهاء أثناء اختبارها (‏#44832‏)، وإرجاع عنصر يحمل قيمة لا يستطيع محرك تعبيرات vm نسخها (‏#44879‏).
- **لماذا يهم ACI:** مرشح الترقية داخل الفرع يتحرك من ‏2.48.7‏ (20 نوفمبر) إلى ‏2.48.8‏ (اليوم) — نفس خط الإصلاحات الأمنية (دفعة 13 نوفمبر مغلقة في كليهما) مع إصلاحات تشغيل إضافية صغيرة. مثيلنا ‏2.43.7‏ ما زال دون حد الإصلاح.
- **المصادر:** https://github.com/n8n-io/n8n/releases (فُحص 23 نوفمبر 2026)؛ https://releases.sh/n8n/n8n (فُحص 23 نوفمبر 2026).
- **الإجراء: adopt** — عند «نفذ»: الترقية المستهدفة تصبح ‏2.48.8‏ بدل ‏2.48.7‏ (نفس خطوات ملف أمس: نسخة احتياطية + تدقيق العقد المهملة + Migration Report).

## 2. تفصيل جديد: ما الذي تحمله بيتا ‏2.49‏ فعلًا (منشور مجتمع 21 نوفمبر)

- **ما الذي تغيّر:** منشور مجتمع n8n (21 نوفمبر 2026) يلخّص أربعة تغييرات عملية في خط ‏2.49‏ بيتا (المستقر ما زال ‏2.48.8‏): (1) قبول معرّفات نماذج مخصصة متوافقة مع OpenAI في وكيل v2 — أي نموذج محلي خلف نقطة نهاية متوافقة مع OpenAI؛ (2) سياق خطأ أغنى عند فشل استدعاء أداة داخل حلقة الوكيل؛ (3) «Always allow» لموافقات أدوات MCP — موافقة مرة واحدة بدل كل تشغيل؛ (4) الـAPI يرفض تعديل عقد بيانات اعتماد للقراءة فقط. وتؤكد ملاحظات ‏2.49.0‏ (17 نوفمبر): قناة webhook للوكلاء، ودعم موافقات، وإدارة وكلاء، وتحرير مهارات، وحواجز حماية للأدوات، وتوسّع API وOAuth.
- **لماذا يهم ACI:** «Always allow» في MCP ونماذج OpenAI المخصصة يمسّان مباشرة أي وكيل ACI يعمل فوق n8n — لكنهما في بيتا فقط؛ لا اعتماد قبل استقرار ‏2.49‏.
- **المصادر:** https://community.n8n.io/t/n8n-2-49-beta-four-changes-im-actually-testing-before-stable-hits/329907 (21 نوفمبر 2026)؛ https://whatsnew.fyi/product/n8n/releases/n8n-2.49.0.
- **الإجراء: watch** — راقب استقرار ‏2.49‏؛ لا قفزة قبل ذلك.

## 3. Shuffle: ‏2.3.1-rc1‏ ما زال الأحدث؛ builds ليلية مستمرة بلا نهائي

- **ما الذي تغيّر:** صفحة GitHub releases (فُحصت 23 نوفمبر 2026) ما زالت تعرض ‏v2.3.1-rc1‏ كأحدث وسم؛ سجل التغييرات يضيف إصلاحات Docker API وتحسينات إيقاف سلس لإجراءات وكلاء AI في hybrid وإصلاح تعطل صفحة — بلا تاريخ نهائي معلن. متتبع طرف ثالث (Sparkpulse، بيانات متزامنة 21 نوفمبر) ما زال يعدّ ستة builds ‏2.3.1‏ منذ 3 نوفمبر (RC4–RC6 وثلاث nightlies) ويرجّح قرب النهائي — **معلومة طرف ثالث غير مؤكدة من المصدر الأول**.
- **لماذا يهم ACI:** لا نستخدم Shuffle (التنسيق عندنا عبر n8n) — لا إجراء؛ لكن النهائي يستحق نظرة عند صدوره.
- **المصادر:** https://github.com/Shuffle/Shuffle/releases (فُحص 23 نوفمبر 2026)؛ https://sparkpulse.io/product/shuffle-automation.
- **الإجراء: watch.**

## 4. طبقة event bus / queue: ‏RabbitMQ 4.4.1‏ (16 نوفمبر)؛ ‏NATS 2.15.3‏ (11 نوفمبر) وتخرّجه من CNCF في 2 نوفمبر

- **ما الذي تغيّر:** ‏RabbitMQ 4.4.1‏ هو أحدث إصدار على GitHub (16 نوفمبر 2026) — إصدار صيانة بعد ‏4.4.0‏ (أكتوبر) الذي وسّع quorum queues وJMS. ‏NATS Server 2.15.3‏ هو الأحدث (11 نوفمبر 2026). وتخرّج NATS رسميًا من مؤسسة CNCF في **2 نوفمبر 2026** (Graduated) — علامة نضج حوكمة للمشروع. ‏Kafka 4.4.0‏ (22 أكتوبر) ما زال الأحدث، بلا إصدار جديد في النافذة.
- **لماذا يهم ACI:** لا تغيير معماري مطلوب؛ تخرّج NATS من CNCF يعزز موقفه كخيار ناقل أحداث خفيف لوكلاء ACI مستقبلًا (مقابل Kafka الأثقل). ‏RabbitMQ 4.4.1‏ صيانة روتينية.
- **المصادر:** https://www.peterindia.net/EventBrokeringSoftware.html (إصدارات GitHub مقروءة نوفمبر 2026)؛ https://cms.selfhost.dev/blog/kafka-alternatives/ (تخرّج NATS من CNCF في 2 نوفمبر 2026)؛ https://encore.dev/articles/event-driven-architecture (إصدارات 16 نوفمبر 2026).
- **الإجراء: watch** — معلومة تخطيط فقط.
