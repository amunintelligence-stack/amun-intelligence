# n8n 2.43.x — تصحيحات أكتوبر (2.43.1–2.43.3): متانة مشغّل المهام وتنقيح MCP

- التاريخ: 2026-10-11 | الفئة: soar | الإجراء: **اعتماد (adopt)** — خطط للترقية مع ملاحظة حظر العقد المهملة

## ما الذي تغيّر
بعد 2.43.0 (مغطاة سابقًا)، أصدر n8n ثلاث تصحيحات بين 7–9 أكتوبر 2026 (لا يوجد 2.44 بعد حتى 2026-10-11):
- **2.43.1** (2026-10-07): تثبيت system prompt لباني الوكلاء لأجل prompt caching، وتجهيز sandbox مهارة Instance AI في الخلفية (تحسين أداء).
- **2.43.2** (2026-10-08): إصلاح Kimi K3 ومزودي المساعد المتوافقين مع OpenAI على الاستضافة الذاتية.
- **2.43.3** (2026-10-09، وأيضًا 2.42.6 على الفرع المستقر): **حظر إنشاء/تحديث سير العمل التي تحتوي عقدًا مهملة (deprecated nodes)** + إضافة نماذج Nano Banana 2.1 و2 Lite لعقدة Google Gemini للصور.
- من ملاحظات 2.43.0 غير المغطاة سابقًا والمهمة تشغيليًا: **"Keep the task runner running on an unhandled promise rejection"** (مرونة مشغّل المهام ضد رفض الوعود غير المعالَج)، **"API: Emit valid schemas for untyped values in the Public API spec"** (تحسين مواصفة الـ Public API)، **"API: Let global members grant variable scopes to API keys"** (تحكم أدق بصلاحيات مفاتيح API)، و**"Redact MCP tool telemetry properties"** (تنقيح بيانات MCP في القياسات).

## لماذا يهم ACI
ACI يعتمد على n8n (v2.42.4 حاليًا) لتشغيل المهام. حظر العقد المهملة في 2.42.6/2.43.3 يعني أن أي سير عمل يستخدم عقدًا قديمة سيفشل عند التحديث — يجب تدقيق سير "ACI — Intelligence Mission Trigger" قبل الترقية. تحسينات مرونة مشغّل المهام تقلل انهيارات التنفيذ، وتنقيح MCP مهم لأمان البيانات عند استخدام أدوات MCP.
