# دلتا SOAR — n8n 2.49 بيتا (وكلاء في API العام)؛ 2.48.7 مستقر مؤكد؛ 3.0 متوقع أوائل ديسمبر (21 نوفمبر 2026)

## 1. n8n 2.48.7 مستقر (20 نوفمبر) — مؤكد الليلة

- **ما الذي تغيّر:** إصلاحان موجهان: memory guard ينهي الاحتجاز عند تحرير بلا ذاكرة (#44463)؛ عقد البرمجة تحفظ بيانات الإدخال الخام في مخرجات الخطأ (#44530). لا استشارات أمنية جديدة منذ دفعة 13 نوفمبر (5 استشارات، أُصلحت في 2.47.6/2.48.3).
- **لماذا يهم ACI:** مرشح الترقية داخل الفرع يبقى 2.48.7 على «نفذ»؛ مثيلنا 2.43.7 ما زال دون حد إصلاح GHSA-gx3v (يحتاج 2.45.5+) — الخطر محدود عمليًا (localhost + محرر موثوق واحد) لكنه حقيقي.
- **المصادر:** https://codebumble.net/insights/n8n-3-0-breaking-changes-docker-migration-prep (20 نوفمبر 2026)؛ https://freedom.tech/project/n8n/
- **الإجراء: adopt** — عند «نفذ»: نسخة احتياطية + تدقيق العقد المهملة + Migration Report ثم الترقية إلى 2.48.7.

## 2. n8n 2.49.0 بيتا (17 نوفمبر) + 2.49.3 بيتا (20 نوفمبر)

- **ما الذي تغيّر:** وكلاء في API العام، قنوات webhook للوكلاء، دعم الموافقات، إدارة الوكلاء، تحرير skills، حواجز حماية للأدوات؛ CSP للتطبيقات على كل الاستجابات؛ صحة مصدر skill واستبدال بيانات الاعتماد؛ قبول معرفات نماذج OpenAI-compatible مخصصة في v2؛ Jira webhook verification؛ إصدار n8n في مواصفات OpenAPI.
- **لماذا يهم ACI:** وكلاء API العام + قنوات webhook تقرّب n8n من طبقة تنسيق الوكلاء — لكن 2.49 بيتا، لا تتبع قبل الاستقرار؛ راقب ترقيته إلى مستقر.
- **المصادر:** https://whatsnew.fyi/product/n8n/releases/n8n-2.49.0 ؛ https://then8nblog.com/ (18 نوفمبر 2026)
- **الإجراء: watch.**

## 3. n8n 3.0: وصول مبكر، والمستقر متوقع أوائل ديسمبر 2026

- **ما الذي تغيّر:** ‏3.0‏ ما زال وصولًا مبكرًا (3.2.0 في 10 نوفمبر، 3.3.0 في 17 نوفمبر ضمن خط الوصول المبكر)؛ Docker-only؛ إزالة 30+ عقدة قديمة؛ مهلة مهمة Code ‏60 ثانية؛ تشديد SSRF. خطة هجرة Docker لـACI ما زالت مطلوبة قبل أي قفزة.
- **المصادر:** https://codebumble.net/insights/n8n-3-0-breaking-changes-docker-migration-prep
- **الإجراء: watch** — لا قفزة 3.x قبل خطة Docker.
