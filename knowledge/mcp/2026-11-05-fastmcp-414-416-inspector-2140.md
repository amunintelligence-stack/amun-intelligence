# FastMCP 4.1.4 / 4.1.6 و MCP Inspector 2.14.0 — تحديثات إطار العمل وأدوات التطوير

## FastMCP 4.1.4 (26 أكتوبر 2026) و4.1.6 (3 نوفمبر 2026)
- **التاريخ:** 4.1.4 صدر 26 أكتوبر 2026؛ 4.1.6 صدر 3 نوفمبر 2026 (PyPI — تحققنا منه مباشرة: أحدث إصدار 4.1.6؛ و4.1.5 موجود أيضًا).
- **ما الذي تغيّر:** 4.1.4 («Token Gesture»، متحقق منه على gofastmcp.com/updates): واجهات CLI المولّدة تحفظ النقل البعيد والمصفوفات الفارغة وأسماء المعاملات المتصادمة؛ الخوادم المثبتة تحترم رؤية الجلسة و`mounted_components_raise_on_load_error`؛ سياق عميل قديم لا يغلق جلسة أحدث؛ أغلفة موفر OAuth تقبل تأكيدات الهوية؛ المهام تقبل موفر بيانات اعتماد redis-py (موفرو البث مرفوضون حتى يتمكن Docket من التحديث بأمان)؛ استُبعد Redis 8.1.0؛ مستخدمو `KeyringStore` المخصص يجب الآن تثبيت `py-key-value-aio[keyring]` صراحةً. 4.1.6 موجود على PyPI (3 نوفمبر 2026) لكن سجل تغييره **لم يكن قابلًا للتحقق**: صفحة التحديثات الرسمية ما زالت تسرد 4.1.4 كأحدث ملخص حتى 3 نوفمبر 16:48 UTC، ولم يتأكد محتوى 4.1.5 أيضًا.
- **لماذا يهم ACI:** FastMCP هو إطار خادم MCP المخطط لـ ACI؛ السجل يثبّت `>=4.1.2`. دعم تأكيد الهوية في 4.1.4 يتناغم مع تدفق Claude كمصدر موثوق (ملف منفصل الليلة). تغيير إضافة keyring قد يكسر تثبيتات تستخدم مخازن رموز مخصصة.
- **المصادر:** https://gofastmcp.com/updates (ملخص 4.1.4، 26 أكتوبر 2026) — https://pypi.org/project/fastmcp/ (4.1.6، 3 نوفمبر 2026) — https://archlinux.org/packages/extra/any/python-fastmcp/ (4.1.6-1 بُني 3 نوفمبر 2026)
- **الإجراء: adopt** — ارفع تثبيت السجل `>=4.1.2` ← `>=4.1.6`، لكن اقرأ ملاحظات إصدار GitHub لـ 4.1.5/4.1.6 أولًا (المحتوى غير متحقق منه وقت البحث). أبقِ ملاحظة certifi `>=2026.10.19`.

## MCP Inspector 2.14.0 — يصلح ثلاث ثغرات مُبلَّغ عنها خصوصًا
- **التاريخ:** 4 نوفمبر 2026 (23:55:33 UTC).
- **ما الذي تغيّر:** ثلاثة إصلاحات، بلا شدة معيّنة في ملاحظات الإصدار: GHSA-2fw8-7jmw-r937 — أنماط regex المقدَّمة من الخادم في مخططات مخرجات الأدوات/الاستنباط في التطبيق تستخدم الآن مطابِقًا خطي الزمن بحدود لكل نمط/مخطط (الأنماط فوق الحد تُبلَّغ «غير متحقق منها» لا تُقيَّم)؛ GHSA-h9j8-vj8g-v3gg — وكيل MCP Apps يفرض سياسة إطار sandbox من منح CSP المعتمدة للتطبيق، مغلقًا الترحيل إن هرب إطار؛ GHSA-rwv7-mh2c-ff2p — استيراد `server.json` يعرض الآن الأمر الدقيق قبل الحفظ ويرفض أسماء متغيرات بيئة غير صالحة/فارغة أو رموزًا غير آمنة؛ استنباطات URL تفتح `http`/`https` فقط؛ CSP لمعاينة HTML نُقل قبل كل ترميز. الخط v1 المهمل أُصلح في v1.0.4 (الأنماط تُجرَّد بدل تقييمها). أيضًا: حقل محرك Node أصبح `^22.23.4 || ^24.22.1 || >=26.12.1`؛ زمن استجابة اختبار الحمل/p99 يحسب الآن الاستدعاءات الناجحة فقط؛ إغلاق التبويب يجمع جلسة الخلفية + ابن stdio؛ مستمع رد OAuth محصور في حالة تدفقه.
- **لماذا يهم ACI:** Inspector هو أداة وقت التطوير في ACI لاختبار خوادم MCP للرسم/RAG المستقبلية. إصلاح نمط فئة ReDoS (GHSA-2fw8-7jmw-r937) تحذير مباشر: خادم علوي خبيث أو مهمل يمكن أن يسلّم أدوات ACI أنماط regex عدائية — نفس فئة المدخلات التي يجب أن تدافع عنها خوادم ACI نفسها عند قبول مخططات طرف ثالث.
- **المصدر:** https://forkast.news/mcp-inspector-2-14-0-fixes-three-privately-reported-vulnerabilities-and-changes-developer-facing-behavior/ (5 نوفمبر 2026، ينقل ملاحظات إصدار GitHub في 4 نوفمبر)
- **الإجراء: adopt** — حدّث أدوات التطوير: `npx @modelcontextprotocol/inspector@latest`.
