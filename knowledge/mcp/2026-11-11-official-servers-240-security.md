# MCP — الخوادم الرسمية v2.4.0: إصدار أمني يصلح 6 ثغرات في 3 خوادم (11 نوفمبر 2026)

## MCP Servers v2.4.0 — صدر اليوم؛ 6 ثغرات أمنية في filesystem وgit وfetch (11 نوفمبر 2026)

- **ما الذي تغيّر:** صدر **MCP Servers v2.4.0** في 11 نوفمبر 2026 (07:07 UTC) كإصدار أمني بالدرجة الأولى — يصلح **6 ثغرات** في ثلاثة خوادم رسمية هي بالضبط الخوادم التي قد يستخدمها أي منصة استخبارات:
  - **`@modelcontextprotocol/server-filesystem` 2.3.0** — (1) **GHSA-p9cv-8g75-4xcg**: سباق TOCTOU — دليل يُستبدل برابط رمزي بين فحص الصلاحية والقراءة فيعيد ملفًا من خارج الدلائل المسموحة؛ القراءة الآن تفتح الملف نسبةً للدليل الذي فُحص (على Windows يضيّق السباق دون إغلاقه). (2) **GHSA-7m4x-rv66-mxhh**: `move_file` كان يمكنه إدخال ملف خارجي إلى الدلائل المسموحة عبر استبدال دليل المصدر برابط رمزي. إضافة: `--read-only-dir` لقراءة فقط لكل دليل، ورفض مسارات NTFS alternate-data-stream وأسماء أجهزة Windows.
  - **`mcp-server-git` 2026.11.11** — (3) **GHSA-6hqx-gqrx-c5r2**: إعدادات Git الخاصة بمستودع غير موثوق (`.git/config`: `core.fsmonitor`، `diff.external`، hooks، فلاتر، توقيع) كانت تجعل استدعاءً للقراءة فقط مثل `git_status` **ينفّذ برنامجًا** بصلاحيات الخادم؛ كل أوامر Git الآن تتجاوز تلك الإعدادات، وGit أقدم من 2.31 مرفوض. (4) **GHSA-q74p-4wrc-q7w6**: حصر `--repository` لم يكن يغطي مخازن كائنات بديلة (`objects/info/alternates`) أو worktrees مرتبطة أو روابط رمزية داخل دليل Git — كلها مرفوضة الآن (junctions على Windows غير مغطاة بعد).
  - **`mcp-server-fetch` 2026.11.11** — (5) **GHSA-3rxj-6jhw-qfv7**: حارس العناوين الخاصة كان يقرأ `fec0::/10` (site-local) كعنوان عام — مرفوض الآن مع أي IPv6 خارج `2000::/3` بلا IPv4 مضمّن (تجاوز SSRF). (6) **GHSA-f9hh-cmx9-2f23**: مطابقة `robots.txt` كانت تُخدع بـ `//private` أو `/x/../private` — الآن تُطابَق ضد المسار الذي سيحلّه الموقع أيضًا.
  - تحسينات أمنية عامة: خادم `everything` 2.3.0 يربط HTTP transports بـ loopback افتراضيًا؛ كل صور Docker تعمل الآن كمستخدم غير root؛ حدّ لحجم جسم الاستجابة أثناء القراءة في fetch.
- **لماذا يهم ACI:** ACI **لا يشغّل خوادم MCP اليوم** — فلا ثغرة نشطة في المكدس ولا تنبيه حرج. لكن هذه هي بالضبط الخوادم الثلاثة (ملفات، Git، جلب ويب) التي ستكون أساس أي طبقة MCP مستقبلية فوق أدوات OSINT CLI — وثغرة git وحدها (تنفيذ كود عبر مستودع غير موثوق يُفحص) هي نمط الهجوم الأول على منصة استخبارات تستقبل مستودعات أهداف. **الحد الأدنى الجديد لأي استخدام مستقبلي: filesystem ‏2.3.0، git ‏2026.11.11، fetch ‏2026.11.11** — وأي نسخة أقدم مرفوضة في التقييم.
- **فخّ ترقية موثّق:** خوادم TypeScript انتقلت من إصدارات تاريخية (2025.x/2026.x) إلى semver في 1.0.0 — مديرو الحزم يرتّبون 2.3.0 **أدنى** من كل إصدار تاريخي، فلن يُعرض كترقية. التثبيت الصريح مطلوب: `npm install @modelcontextprotocol/server-filesystem@2.3.0`.

## Responsive Fall 2026 — MCP يتجاوز الاسترجاع إلى مهام منسّقة بإذن المستخدم (11 نوفمبر 2026)

- **ما الذي تغيّر:** أعلنت **Responsive** في 11 نوفمبر 2026 توسيع قدرات MCP (بناءً على إصدارها الأول في مايو 2026): فرق تستخدم ChatGPT وMicrosoft Copilot وClaude للوصول إلى المعرفة الموثوقة والتعاون ونقل أعمال الاستجابة دون مغادرة مساعد الذكاء الاصطناعي. أكثر من **198,000 استدعاء أداة** منذ إطلاق الخادم. النقطة التصميمية: خادم MCP يطبّق **أذونات مستوى المستخدم** — ما يراه المستخدم ويفعله في المساعد يطابق ما يراه ويفعله في Responsive.
- **لماذا يهم ACI:** نمط «أذونات مستوى المستخدم تنتقل عبر MCP» هو المعيار الذي سجّلناه لخوادم MCP الآمنة (قوائم مُدقَّقة + بوابة مصادقة) — Responsive مثال حيّ على تطبيقه في منتج إنتاجي. لا صلة مباشرة بمهام ACI.
