# ثغرات حقن موجّه (prompt injection) في خادم Git الرسمي المرجعي لـ MCP (مكتشفة بواسطة Cyata)

- التاريخ: 2026-10-09 | الفئة: mcp | الإجراء: **مراقبة (watch)**

## ما الذي تغيّر
3 ثغرات في `mcp-server-git` الرسمي من Anthropic تسمح — عبر README خبيث أو وصف issue مسموم يُقرأ بواسطة المساعد — بتنفيذ كود (عند الاستخدام مع خادم filesystem)، وحذف ملفات اعتباطية، وتحميل ملفات اعتباطية في سياق النموذج. تعمل "خارج الصندوق" في التثبيتات الافتراضية لجميع النسخ قبل 8 ديسمبر 2025، بدون حاجة لبيانات اعتماد. التاريخ الدقيق للنشر الأولي غير مؤكد — يُعامل كإفصاح حديث (أُعيد تداوله ~7 أكتوبر 2026).

## لماذا يهم ACI
التطبيق المرجعي الرسمي نفسه مصاب — أي خادم MCP نعتمده (حتى الرسمي) يجب عزله وتقييده؛ لا تمنح خوادم MCP صلاحيات نظام ملفات واسعة بجانب أدوات تنفيذ.
