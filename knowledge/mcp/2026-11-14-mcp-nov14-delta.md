# دلتا MCP — خادم MCP من Schwab (وساطة مالية)؛ GSC MCP 0.4.41؛ شائعة مواصفة v1.2 غير مؤكدة (14 نوفمبر 2026)

## 1. Charles Schwab يطلق خادم MCP للوساطة — نموذج موافقة بشرية على التداول (12 نوفمبر 2026)

- **ما الذي تغيّر:** أعلنت **Charles Schwab** في 12 نوفمبر 2026 خادم MCP خاصًا بها يتيح للعميل ربط نموذج لغوي — بدءًا بـ Claude من Anthropic — بحساب الوساطة الخاص به. الخادم في **مرحلة تجريبية** لمجموعة مختارة من مستخدمي Claude، مع وصول أوسع ومنصات ذكاء اصطناعي إضافية موعودة خلال الأشهر القادمة. النقطة التصميمية المعلنة: **Claude يجهّز الصفقة، والعميل ما زال يوافق على كل تداول** — النموذج لا ينفّذ بلا موافقة بشرية. الأدوات للعملاء الأفراد فقط حاليًا (مستشارو الاستثمار المسجَّلون مستثنَون). Schwab تدير 13.33 تريليون دولار أصول عملاء و10.7 مليون تداول يوميًا في المتوسط (الربع الثالث 2026).
- **لماذا يهم ACI:** ليس أداة استخبارات، بل **مرجع تصميمي من الدرجة الأولى** لطبقة MCP المستقبلية في ACI: مؤسسة مالية منظَّمة تنشر خادم MCP على بيانات حساسة (أموال عملاء) بنمط «تحضير + موافقة بشرية إلزامية» — وهو بالضبط النمط الذي تحتاجه ACI لأي أداة MCP تكتب أو تنفّذ (مقابل القراءة فقط). يعزز أيضًا قاعدة «اقرأ أولًا، واكتب فقط بموافقة موقَّعة» المسجلة بعد دراسة MCP-FSD. وهو أول خادم MCP من وسيط مالي كبير يُعلن — مؤشر تبنّي مؤسسي للبروتوكول خارج شركات التقنية.
- **المصادر:** https://aiagentupdate.com/post/schwab-mcp-server-2026-11-13 (13 نوفمبر 2026، عن إعلان Schwab عبر Business Wire في 12 نوفمبر)
- **الإجراء: watch** — سجّل نمط «تحضير + موافقة بشرية» في قائمة فحص تصميم MCP لـ ACI؛ لا اعتماد (تجريبي، ولعملاء Schwab فقط).

## 2. Google Search Console MCP v0.4.41 — سلامة أدلة أقوى (نوفمبر 2026)

- **ما الذي تغيّر:** أُصدر **v0.4.41** من خادم Google Search Console MCP (المشروع `AKzar1el/mcp-gsc`): تحسينات في معالجة البيانات لملخصات Search Console الأسبوعية عند غياب البيانات المجمّعة (بدأت في 0.4.40) + تحسينات سلامة أدلة، مع محاذاة إصدار موثّقة عبر CI (الالتزام المصدر `4b14b6f`، نشر npm عبر OIDC موثوق قبل نشر مستند السجل). الإصدارات السابقة: 0.4.39 تحديث أمني، 0.4.38 يعكس تغييرات حصة Google Indexing API في 16 أكتوبر 2026 (200 طلب نشر/يوم افتراضيًا لكل مشروع، وإزالة نموذج موافقة الحصة القديم).
- **لماذا يهم ACI:** خادم MCP مجتمعي يقرأ بيانات Search Console (تحليلات بحث، فحص URL، فهرسة، خرائط موقع، تقارير SEO) — ذو صلة مباشرة بفئة data-sources/seo في ACI. لكنه مشروع فردي (AKzar1el)، لا Google الرسمية، ويتطلب بيانات اعتماد Google — يُقيَّم كأداة تطوير/قراءة فقط، لا كمصدر مهمات، حتى يُدقَّق نطاق بيانات الاعتماد والتخزين.
- **المصادر:** https://undercodenews.com/google-search-console-mcp-v0441-just-updated-with-stronger-evidence-safety-and-seo-analytics-reliability-video/ (14 نوفمبر 2026)
- **الإجراء: watch** — قيّم في التطوير لمصدر SEO؛ لا بيانات اعتماد إنتاجية قبل التدقيق.

## 3. ⚠️ شائعة: «مواصفة MCP v1.2 أُنجزت» — غير مؤكدة، لا تعتمدها

- **ما الذي تغيّر (ادعاء):** موقع `luiscore.com/mcp-watch` (صفحة مراقبة آلية، حُدّثت 14 نوفمبر) يدّعي أن «هيئة الإشراف على MCP أنجزت ملاحظات إصدار v1.2» مع «مصافحات اكتشاف قدرات إلزامية»، وأن «مقدّمي السحابة الكبار نفّذوها فورًا»، وأن اتصالات MCP النشطة ارتفعت ~15% منذ بداية الأسبوع.
- **لماذا هي شائعة:** لا مصدر أولي يؤكدها — لا modelcontextprotocol.io ولا مستودع المواصفات ولا إعلان Agentic AI Foundation؛ المقال المرجعي الأحدث (umairirshad.dev، حُدّث 14 نوفمبر 2026) ما زال يسمّي **2026-07-28** المواصفة الحالية ويذكر إهمال roots/sampling/logging فيها. الأرقام («15%») بلا مصدر أو منهجية. النمط مطابق لتحذير 2 نوفمبر عن منشورات تضخيم MCP.
- **المصادر:** https://www.luiscore.com/mcp-watch (ادعاء، 14 نوفمبر 2026)؛ https://www.umairirshad.dev/blog/mcp-for-product-teams (المواصفة 2026-07-28، حُدّث 14 نوفمبر 2026)
- **الإجراء: ignore** — لا تغيّر أي تثبيت مواصفة؛ أعد الفحص فقط إذا ظهر إعلان من modelcontextprotocol.io أو Agentic AI Foundation.
