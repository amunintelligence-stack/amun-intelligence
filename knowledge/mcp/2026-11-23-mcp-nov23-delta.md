# دلتا MCP — FastMCP 4.2.5 يطبّق امتداد Events تجريبيًا؛ خادما MCP جديدان لا يخصّان الاستخبارات (23 نوفمبر 2026)

## 1. FastMCP 4.2.5 «Smoke Signals» — امتداد Events يصل إلى التنفيذ التجريبي (23 نوفمبر 2026)

- **ما الذي تغيّر:** الإصدار 4.2.5 (رفع PyPI في 23 نوفمبر 2026، 07:42 UTC — تحقق عبر PyPI الليلة): أول تنفيذ فعلي لامتداد Events (SEP-3415) في إطار من الفئة الأولى، تحت `fastmcp.experimental.events` مع تسليم Poll وPush وواجهة سطر أوامر `fastmcp experimental events list|watch` — تجريبي صراحةً وقد يتغيّر API دون فترة إهمال. كذلك: `subscriptions/listen` يعمل افتراضيًا على اتصالات 2026-07-28 (الخادم يعلن `listChanged` و`resources.subscribe`، و`notify_tools_changed()` وإخوتها تدفع الأحداث إلى العملاء المستمعين؛ حتى 1024 دفق استماع لكل عملية خادم). إضافة `UsageMiddleware` اختياري يسجّل الاستخدام لكل مستخدم ولكل أداة كمقياس OpenTelemetry (`mcp.server.operation.duration`). وتشديد أمني واسع في OAuth وOpenAPI: مستند CIMD للعميل لم يعد يوسّع النطاقات التي يسمح بها الخادم (بدون `valid_scopes` ولا `required_scopes` لا نطاقات إطلاقًا)؛ مطابقة الاستعلام في التحقق من redirect URI ومنع الـfragment؛ إبطال refresh token يُنهي access tokens الخاصة بالمنحة نفسها، وإعادة استخدام refresh token مدوَّر بعد أكثر من 60 ثانية تُنهي المنحة كلها كسرقة مشتبهة؛ `client_registration_ttl_seconds` جديد لانتهاء تسجيلات العملاء الديناميكية غير المستخدمة؛ إيقاف تمرير رؤوس نقل MCP إلى خلفيات OpenAPI (مع خيار `forward_client_headers`)؛ وترميز قيم ملفات تعريف الارتباط (cookies) في OpenAPI بالمئة.
- **لماذا يهم ACI:** هذا هو التحوّل من «المواصفة على الورق» (دلتا 22 نوفمبر: SEP-3415 وصل إلى Final) إلى «تنفيذ يمكن تجربته» خلال ثلاثة أيام — أسرع مما هو معتاد في المنظومة. نمط «المهمة تُطلَق بحدث» في ACI يقترب خطوة من التنفيذ العملي، لكنه ما زال تجريبيًا. النقطة التشغيلية الأهم الليلة: `subscriptions/listen` مفتوح افتراضيًا ويُبقي دفقًا مفتوحًا لكل اتصال — على خوادم بلا خادم (serverless) أو بمجموعة عمال صغيرة قد يكون ذلك مكلفًا؛ الإيقاف عبر `FASTMCP_ENABLE_SUBSCRIPTIONS_LISTEN=false` قبل الاستيراد. تشديدات CIMD وrefresh token تهم أي نشر مستقبلي لخوادم MCP خلف OAuth في ACI.
- **المصادر:** https://github.com/jlowin/fastmcp/releases/tag/v4.2.5 (23 نوفمبر 2026)؛ https://pypi.org/pypi/fastmcp/json (رفع 4.2.5 في 23 نوفمبر 07:42 UTC)
- **الإجراء: watch** — لا اعتماد للإصدار التجريبي من Events؛ عند أي ترقية مستقبلية إلى FastMCP 4.2.5+ راجع إعداد `enable_subscriptions_listen` وسياسات `valid_scopes` لـCIMD قبل النشر.

## 2. خادما MCP جديدان اليوم — لا صلة بالاستخبارات (22–23 نوفمبر 2026)

- **ما الذي تغيّر:** أطلقت DataGroomr خادم MCP (23 نوفمبر 2026) يجلب إدارة جودة بيانات Salesforce إلى المساعدين (Agentforce وClaude وChatGPT وغيرها) عبر محادثة بلغة طبيعية لتحديد مشكلات جودة البيانات وحلّها؛ متاح لعملاء Trial وEnterprise، ومدرج في دليل موصلات Claude. وفي 22 نوفمبر أطلقت دار النشر الأسترالية Man of Many خادم MCP عامًا مجانيًا للقراءة فقط يتيح للمساعدين الإجابة من أدلة الشراء والمراجعات بمقتطفات ونسبة المصدر.
- **لماذا يهم ACI:** لا أثر مباشر — الأول أداة Salesforce تجارية، والثاني ناشر محتوى تحريري. القيمة الوحيدة هي تأكيد الاتجاه: الناشرون والبائعون ينشرون MCP كقناة توزيع محتوى/بيانات، وهو نفس النمط الذي قد تستخدمه ACI يومًا لنشر مخرجاتها الاستخباراتية عبر MCP بدل السحب اليدوي.
- **المصادر:** https://www.morningstar.com/news/pr-newswire/20261123ph04503/datagroomr-introduces-mcp-server-to-bring-salesforce-data-quality-management-into-ai-assistants (23 نوفمبر 2026)؛ https://wisevoter.com/world/au/2026/11/23/man-of-many-launches-public-mcp-server (23 نوفمبر 2026)
- **الإجراء: ignore** — لا اعتماد؛ سجّل نمط «الناشر عبر MCP» كمرجع تصميمي فقط.
