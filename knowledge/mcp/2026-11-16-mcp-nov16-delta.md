# دلتا MCP — خادم Google Ads MCP يكتسب أدوات كتابة مفعّلة افتراضيًا بينما وثائقه تقول «قراءة فقط»؛ موجة خوادم مؤسسات جديدة (16 نوفمبر 2026)

## 1. ⚠️ أمني — Google Ads MCP v0.0.6: أربع أدوات كتابة مفعّلة افتراضيًا، والتوثيق ما زال يقول «قراءة فقط» (2 نوفمبر 2026، ظهرت 9 نوفمبر)

- **ما الذي تغيّر:** أصدرت Google الإصدار **0.0.6** من خادم Google Ads MCP مفتوح المصدر في **2 نوفمبر 2026** (GitHub، الالتزام 7452a9d؛ PyPI في اليوم نفسه 15:48 UTC)، ومعه أول أدوات في تاريخ المشروع تستطيع **تغيير حساب Google Ads**. الأدوات الأربع الجديدة:
  - `create_asset` — إنشاء أصول نصية/صور/فيديو YouTube/روابط موقع/دعوات/مقتطفات منظمة؛
  - `upload_video_asset` — رفع فيديو محلي إلى YouTube عبر Google Ads API (مهمة خلفية)؛
  - `manage_labels` — إنشاء/تحديث/حذف تسميات الحساب؛
  - `manage_label_associations` — ربط التسميات بالحسابات والحملات والمجموعات الإعلانية والكلمات المفتاحية.
  - كل كتابة تمر بتدفق «اقتراح ثم تأكيد» من خطوتين: استدعاء أول بـ `validate_only=true` (تشغيل تجريبي) يعيد عناصر تغيير + **checksum**، واستدعاء ثانٍ بنفس المعاملات والـ checksum يثبّت التغيير. **الأدوات مفعّلة افتراضيًا** (`labels: true` و`assets: true` في `tools_config.yaml` المضمّن).
- **لماذا هو أمني، لا مجرد ميزة:** ثلاث حقائق مجتمعة:
  1. **دليل التكامل الرسمي من Google (آخر تحديث 30 أكتوبر) ما زال يصف الخادم بأنه «قراءة فقط حصرًا»** — أي فريق وافق على الأداة بناءً على ذلك الوصف يشغّل الآن أداة كتابة دون أن يعلم، ولم يصدر أي إعلان عن الإصدار.
  2. **نطاق OAuth نفسه كان يسمح بالكتابة منذ البداية**: الخادم يصادق بنطاق `https://www.googleapis.com/auth/adwords` الوحيد؛ لا يوجد نطاق قراءة فقط منفصل. ما كان يجعله للقراءة فقط هو مجموعة الأدوات المعرّضة، لا الصلاحية — والآن تغيّرت مجموعة الأدوات.
  3. **الـ checksum ليس ضمان موافقة بشرية**: هو تجزئة SHA-256 من معرّف العميل والمعاملات بلا مفتاح سرّي ولا انتهاء صلاحية؛ يثبت أن المعاملات لم تتغير بين الخطوتين، لا أن تشغيلًا تجريبيًا حدث أو أن إنسانًا وافق. رسالة «اعرض على المستخدم وانتظر الموافقة» تعليمة للنموذج، لا قيد يفرضه الخادم. وطريقة التثبيت الموصى بها في الدليل (`pipx run --spec git+https://github.com/googleads/google-ads-mcp.git`) تسحب فرع main دائمًا، فيصل أي أداة كتابة مستقبلية دون تثبيت إصدار.
  - ما زال خارج المتناول: إنشاء/تعديل الحملات والمجموعات والإعلانات، وتغيير الميزانيات والعروض والحالات، وإضافة الكلمات المفتاحية، وربط الأصول بحملة (الأصول تهبط في المكتبة فقط).
- **لماذا يهم ACI:**‏ هذا هو بالضبط نمط الفشل الذي تحذّر منه قواعد تقسية MCP لدى ACI: أداة وُثّقت كقراءة فقط تتحول إلى كتابة بصمت، وافتراضي-مفعّل، وتثبيت غير مثبّت الإصدار. أي ربط مستقبلي لخادم Google Ads MCP (أو أي خادم MCP «للقراءة فقط») يجب أن يمر عبر قائمة سماح صريحة + تعطيل الكتابة في الإعداد + تثبيت وسم إصدار.
- **المصادر:**
  - https://ppc.land/google-ads-mcp-server-gains-4-write-tools-still-cant-change-budgets/ (9 نوفمبر 2026، تغطية مفصلة مع قراءة الشيفرة المنشورة)
  - إصدار GitHub v0.0.6 (2 نوفمبر 2026، الالتزام 7452a9d) — عبر التغطية أعلاه؛ لم تُفتح صفحة الإصدار مباشرة الليلة (GitHub API محدود المعدل)
- **الإجراء: adopt (كقاعدة تقسية)** — أضف إلى معايير ربط MCP لدى ACI: (1) لا تثبيت من فرع main أبدًا — ثبّت وسم إصدار؛ (2) افترض أن أي خادم MCP قد يكتسب أدوات كتابة في أي إصدار — راجع سجل التغييرات قبل كل ترقية؛ (3) للقراءة فقط الصريحة، عطّل الكتابة في `tools_config.yaml` (`labels: false` و`assets: false`) ولا تعتمد على وصف «قراءة فقط» في الوثائق. الخادم نفسه: **watch** — لا ربط قبل حاجة حقيقية وتقييم معزول.

## 2. موجة خوادم MCP مؤسساتية — كلها خارج نطاق ACI (12–16 نوفمبر 2026)

- **ما الذي تغيّر:**
  - **Masttro MCP Server** (أُعلن 16 نوفمبر): خادم MCP للثروات العائلية — قراءة فقط، معطّل افتراضيًا، يتطلب تفعيلًا وتصريحًا صريحًا من العميل؛ متاح من اليوم للعملاء المؤهلين دون تكلفة إضافية.
  - **Charles Schwab MCP Server** (أُعلن 12 نوفمبر): تجريبي لمجموعة مختارة من مستخدمي Claude؛ يتيح لـ Claude إعداد التداولات، والموافقة البشرية ما زالت مطلوبة لكل صفقة؛ تجزئة فقط الآن.
  - **Iterable hosted MCP server** (أُعلن 12 نوفمبر، ضمن إطلاق الشتاء): خادم MCP مستضاف يربط Claude/ChatGPT/Cursor بمنصة التسويق؛ الطرح الأوسع 2 ديسمبر؛ تجربة عبر الممثلين.
  - **Oviond MCP Server** (تدوينة محدّثة 16 نوفمبر): خادم مستضاف بـ 125 أداة فوق 100+ منصة تسويق؛ 300 طلب/دقيقة؛ يبدأ من 50 دولارًا/شهر (10 عملاء كحد أدنى).
- **لماذا يهم ACI:** لا شيء مباشر — كلها منتجات مدفوعة/تجريبية خارج نطاق الاستخبارات الشركاتية. لكن النمط يستحق التسجيل: **Masttro يطبّق النمط الصحيح** (قراءة فقط + معطّل افتراضيًا + تصريح صريح)، بينما Schwab يطبّق «إعداد من الوكيل + موافقة بشرية» — النموذجان مرجعان لتصميم أي واجهة MCP حساسة في ACI.
