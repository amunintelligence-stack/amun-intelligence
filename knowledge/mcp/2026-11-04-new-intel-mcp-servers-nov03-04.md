# خوادم MCP جديدة ذات صلة بالاستخبارات في 3–4 نوفمبر 2026 — Keytomic وفحص أسماء الشبكات الاجتماعية وReddit Buddy

## ما الجديد

- **Keytomic MCP Server (أُعلن 3 نوفمبر 2026، Naperville، الولايات المتحدة):** منصة Keytomic لأتمتة SEO أطلقت خادم MCP أصليًا يجعل أدوات SEO الكاملة متاحة داخل Claude وChatGPT وCursor وClaude Code وOpenAI Codex وGemini CLI وWindsurf — بحث كلمات مفتاحية، نشر محتوى، تدقيقات فنية، وإدارة تقويم المحتوى من اتصال واحد. معه أُطلق أيضًا AI Visibility Tracker (مراقبة ذِكر العلامة التجارية عبر ChatGPT وClaude وGemini وGoogle AI Mode ومقارنتها بالمنافسين) وReddit AI Agent (مسح Reddit بحثًا عن نقاشات ذات صلة وتوليد مسودات ردود يراجعها الإنسان قبل النشر).
- **Social Media Handle Checker MCP Server (ظهر في سوق LobeHub بتاريخ 4 نوفمبر 2026):** خادم MCP للتحقق من توافر أسماء المستخدمين عبر YouTube وTikTok وThreads وX وInstagram، دون ملفات بيانات خارجية. المعلومة المتاحة حتى الآن على مستوى إدراج السوق فقط؛ لم يُتحقق من مستودعه أو ترخيصه بعد.
- **Reddit Buddy MCP (ظهر في سوق LobeHub بتاريخ 3 نوفمبر 2026):** خادم MCP خفيف لتصفح منشورات Reddit والبحث في المحتوى وتحليل المستخدمين.
- ملاحظة عن المصدر: إعلان Keytomic بيان صحفي من الشركة نفسها عبر EIN Presswire (لم يتحقق منه تحريريًا مستقلًا)، وإدراجا LobeHub هما قوائم سوق وليستا مراجعات أمنية.

## لماذا يهم ACI

- **فحص أسماء الشبكات الاجتماعية** يطابق مباشرة حاجة OSINT في ACI: التحقق من هوية/وجود كيان عبر المنصات الخمس الكبرى هو خطوة روتينية في أي مهمة استخبارات شركات. إذا ثبت أن الخادم موثوق، فهو مرشح أداة صغير واضح.
- **Keytomic** ذو صلة بفئة `data-sources/seo` في ACI، وبفكرة جديدة أهم: تتبّع الظهور في بحث الذكاء الاصطناعي (AI Visibility) — أي كيف تظهر شركة ما في إجابات ChatGPT وClaude وGemini، وهو بُعد جديد لاستخبارات السمعة لا يغطيه SEO التقليدي.
- **Reddit Buddy** و**Reddit AI Agent** من Keytomic يخدمان بُعد الاستماع الاجتماعي (social listening) — Reddit مصدر متزايد الأهمية لأن نماذج الذكاء الاصطناعي وخوارزميات Google تُبرز نقاشاته كمصادر موثوقة.
- التحذير: كل هذه أدوات خارجية تتعامل مع بيانات عامة فقط؛ لا تُمرَّر عبرها أي بيانات مهمة حساسة قبل مراجعة سياسة الخصوصية والترخيص لكل أداة.
