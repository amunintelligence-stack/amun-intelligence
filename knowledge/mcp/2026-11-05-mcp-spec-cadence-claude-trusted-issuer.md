# مواصفات MCP واتجاهاتها — إيقاع نصف سنوي، Claude كمصدر موثوق، إضافات ChatGPT

## إيقاع مواصفات نصف سنوي؛ المواصفة التالية 30 مارس 2027 (SEP-3398)
- **التاريخ:** SEP-3398 اقتُرح 17 سبتمبر 2026؛ قُبل 14 أكتوبر 2026.
- **ما الذي تغيّر:** MCP ينتقل إلى إيقاع إصدار نصف سنوي (الثلاثاء الأخير من مارس وسبتمبر). الإصدار المخطط لديسمبر 2026 نُقل إلى 30 مارس 2027 (رهن التأكيد).
- **لماذا يهم ACI:** يقين تخطيطي: 2026-07-28 يبقى الأساس ~5 أشهر أخرى؛ خصّص دورة مراجعة مواصفات واحدة لأواخر مارس 2027.
- **المصدر:** أُبلغ عنه في https://tech-insider.org/au/build-stateless-mcp-server-python-2026/ (3 نوفمبر 2026)؛ تاريخ قبول SEP-3398 في 14 أكتوبر 2026 حسب ذلك المقال — لم يُجلب SEP نفسه.
- **الإجراء: watch** — ملاحظة تقويم فقط.

## Claude كمصدر موثوق: الإضافات تتصل تلقائيًا، بلا OAuth في المتصفح (3 نوفمبر 2026)
- **ما الذي تغيّر:** يمكن للمستخدمين الآن الاتصال تلقائيًا بالإضافات عند تسجيل الدخول إلى Claude، على خوادم MCP التي تقبل Claude كمصدر موثوق. مبني على Enterprise Managed Auth (Claude Team/Enterprise): Claude يقدم تأكيد هوية موقّعًا (JWT) بدل إعادة توجيه/صفحة موافقة في المتصفح؛ الخادم يبدّله برمز وصول في طلب خلفي واحد. وضعا توقيع: موفر هوية المنظمة، أو — جديد، في beta — Claude نفسه (`identity.anthropic.com/issuers/<org-id>`). متطلبات الخادم: سجّل Claude مسبقًا (بلا تسجيل عميل ديناميكي)، وثق بـ URL المصدر **الدقيق** لكل عميل (لا تطابق بادئة أبدًا)، وطابق مستخدمي Claude الموقّعين بالبريد الإلكتروني المتحقق منه. فجوة إلغاء: إزالة مستخدم توقف التأكيدات الجديدة، لكن رموز الوصول الصادرة أصلًا تبقى صالحة حتى انتهائها — عمر الرمز يحدّ الوصول المتبقي.
- **لماذا يهم ACI:** مدخل تصميمي مباشر لتعريض MCP البعيد المخطط لـ ACI للرسم/RAG: إن قبل ACI عملاء Claude يومًا، فهذا مسار المصادقة — URLs مصدر دقيقة لكل مساحة عمل، أعمار رموز قصيرة، بلا DCR. كما يعزز تثبيت `expectedIssuer` الموجود في السجل (CVE-2026-104850) باعتباره المبدأ نفسه من الطرف الآخر.
- **المصدر:** https://cellcog.ai/blog/claude-plugin-auto-connect/ (3 نوفمبر 2026؛ ثانوي — يلخص وثائق Enterprise Managed Auth في Anthropic؛ لم تُجلب وثائق Anthropic مباشرة)
- **الإجراء: watch** — لا بناء بعد؛ سجّل كملاحظة تصميم مصادقة لتعريض MCP البعيد المستقبلي.

## إضافات ChatGPT «Plugins»؛ مسار MCP Apps ينضج
- **التاريخ:** DevDay في 29 سبتمبر 2026؛ وثائق OpenAI حالية حتى 2 نوفمبر 2026.
- **ما الذي تغيّر:** منذ 9 يوليو 2026، تطبيقات ChatGPT توزَّع كـ «plugins» (دليل إضافات مشترك بين ChatGPT وCodex)؛ الإضافة حزمة مهارات + خادم MCP مع واجهة اختيارية. DevDay (29 سبتمبر) أضاف تجارب الشريط الجانبي ولوحات تفاعلية وعارضات ملفات مخصصة ومواصفة **MCP Events** المقترحة للأتمتة القائمة على المشغّلات. GPTs المخصصة تتقاعد 11 ديسمبر 2026 (مسار الترحيل: الإضافات). بشكل منفصل، إضافة MCP Apps الرسمية (SEP-1865) مستقرة عند v2026-01-26، وChatGPT متوافق معها بالكامل منذ 22 فبراير 2026.
- **لماذا يهم ACI:** إن واجهت خوادم MCP في ACI مستخدمي ChatGPT/Codex يومًا، فغلاف الإضافة (خادم MCP + واجهة اختيارية) هو مسار التوزيع — ونتائج الرسم/RAG في ACI هي بالضبط نوع المخرجات الذي يستفيد من لوحة تفاعلية بدل نص عادي. مواصفة MCP Events المقترحة تستحق التتبع لتنبيهات استخبارات الدفع. تقاعد GPT المخصص لا يؤثر على ACI.
- **المصادر:** https://reflektlab.ai/blog/chatgpt-apps/ (نوفمبر 2026) — https://mcp.so/blog/mcp-apps-guide (الحالة حتى أكتوبر 2026) — https://www.airanklab.com/blog/chatgpt-apps-for-brands (2 نوفمبر 2026)
- **الإجراء: watch** — لا إجراء حتى يوجد تعريض MCP في ACI.

## Ruby SDK يصبح SDK من المستوى الأول؛ Claude Code 2.1.318؛ Kiwi TCMS؛ مسودة MCP عبر MOQT
- **Ruby SDK مستوى أول** (أُكّد المستوى في سبتمبر 2026؛ أُعلن في نوفمبر 2026): الـ gem الرسمي `mcp` الآن مستوى أول، منضمًا إلى TypeScript وPython وC# وGo وRust. v1.2.0+ يدعم مواصفة 2026-07-28 بالكامل (دورة حياة بلا حالة، `server/discover`، اشتراكات/استماع، طلبات متعددة الجولات، تلميحات تخزين مؤقت)؛ مطابقة 100% على مجموعتَي متطلبات 2025-11-25 و2026-07-28. ACI بايثون — لا أثر مباشر. إشارة منظومة فقط: ستة SDKs من المستوى الأول تغطي الآن المواصفة بلا حالة، فـ 2026-07-28 آمن كأساس ACI. **الإجراء: ignore.**
  - المصدر: https://releasebot.io/updates/modelcontextprotocol (نوفمبر 2026، يعيد نشر مدونة MCP)
- **Claude Code 2.1.318** (3 نوفمبر 2026): `claude mcp add/remove` تحترم الآن قفل الإعدادات (سابقًا إسقاط صامت على منازل شبكية مشتركة)؛ خوادم MCP من نوع stdio التي تخرج عند فحص الإصدار لا تُعاد فحصها عند كل بدء وتُثبَّت على المصافحة القديمة 7 أيام؛ `/mcp` في جلسات السحابة يعدّ فقط الأدوات التي يمكن للنموذج استخدامها؛ إدخالات URL في `deniedMcpServers` تحظر الآن أيضًا خوادم/موصلات مقدمة من Anthropic مطابقة لذلك URL؛ أخطاء أدوات MCP قبل التحميل تعيد مخطط الإدخال. نظافة أدوات تطوير فقط. **الإجراء: ignore.**
  - المصدر: https://www.havoptic.com/r/claude-code-2.1.318 (3 نوفمبر 2026؛ متتبع سجل تغيير ثانوي)
- **Kiwi TCMS Enterprise v17.0-mt+** (5 نوفمبر 2026): يكشف نقطة نهاية MCP على `https://<tenant>.<host>/mcp/`، ينفذ مواصفة 2026-07-28 مع توافق رجعي إلى 2024-11-05، 130+ أداة (واجهة إدارة الاختبار الكاملة)، OAuth 2.1 مع PKCE وتسجيل عميل ديناميكي. غير ذي صلة بالاستخبارات (إدارة حالات اختبار)، لكنه دليل على انتشار اعتماد 2026-07-28 في SaaS المؤسسات — إشارة مفيدة عندما يختار ACI عصر المواصفة المستهدف. **الإجراء: ignore.**
  - المصدر: https://kiwitcms.org/blog/kiwi-tcms-team/2026/11/05/feature-spotlight-model-context-protocol/
- **مسودة IETF: MCP عبر Media over QUIC Transport** (نوفمبر 2026، draft-jennings-agentproto-mcp-over-moqt-01، تنتهي 5 مايو 2027): تعيين رسائل MCP (أدوات، موارد، مطالبات، طلبات متعددة الجولات، إضافة المهام) على كائنات/مسارات MOQT؛ مرحّلات MOQT تخزّن مؤقتًا محتوى MCP المعلَّم عامًا عبر العملاء وتدع الردود تعيش بعد اتصالها. بلا أثر الآن — مسودة نقل مبكرة بلا تنفيذات. **الإجراء: ignore.**
  - المصدر: https://datatracker.ietf.org/doc/html/draft-jennings-agentproto-mcp-over-moqt-01
