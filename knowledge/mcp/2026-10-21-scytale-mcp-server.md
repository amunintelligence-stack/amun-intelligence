# Scytale تطلق خادم MCP لبيانات الامتثال (13 أكتوبر 2026)

**Date found:** 2026-10-21 (nightly dev researcher)

## What changed
أعلنت **Scytale** في **13 أكتوبر 2026** عن إطلاق خادم MCP رسمي: الاستعلام عن بيانات الامتثال الحية بلغة طبيعية من أي عميل متوافق مع MCP (Claude Code/Desktop، Cursor…). التفاصيل الأمنية: المصادقة عبر **OAuth**، الاتصالات مقيدة النطاق لشركة واحدة، وكل الاستدعاءات **مسجَّلة تدقيقيًا**.

## Why it matters for ACI
بيانات الامتثال/التدقيق كمصدر MCP هي مرجع نمط لكيفية وصول البيانات المنظمة إلى الوكلاء بأمان — OAuth مقيد النطاق + سجل تدقيق يطابق قواعد التصليب لدينا. ليس مصدر استخبارات نحتاجه الآن، لكنه يُراقَب كنمط تجاري (بجانب Radware MCP Protection من ملف 14 أكتوبر).
