# خوادم MCP استخباراتية جديدة — 5 نوفمبر 2026

## yente-mcp — خادم OpenSanctions الرسمي (24 سبتمبر 2026)
- **ما الذي تغيّر:** `yente-client` هو مجموعة أدوات Python الرسمية لمحرك المطابقة المفتوح في OpenSanctions، تجمع SDK مكتوبًا وCLI وخادم MCP (`yente-mcp`) يعرض `match()` و`search()` كأدوات قابلة للاستدعاء من الوكلاء عبر 320+ قائمة عقوبات وشخصيات مكشوفة سياسيًا (OFAC، الاتحاد الأوروبي، الأمم المتحدة، UK HMT وغيرها). يعمل كخدمة محلية على بنيتك أولًا (لا نقطة نهاية مستضافة بعد)؛ yente المستضاف ذاتيًا لا يحتاج مفتاح API، وAPI المستضاف يحتاج مفتاحًا مجانيًا.
- **لماذا يهم ACI:** فحص العقوبات/PEP للأشخاص والشركات والسفن عمل استخباراتي شركاتي أساسي وخطوة مهمة طبيعية في ACI — وهذا الخادم الرسمي لا غلاف طرف ثالث. المحلية أولًا تناسب وضع ACI المستضاف ذاتيًا.
- **المصدر:** https://www.opensanctions.org/articles/2026-09-24-yente-client/ (24 سبتمبر 2026). (يوجد أيضًا غلاف مجتمعي منفصل `scka-de/opensanctions-mcp` على Glama — فضّل الرسمي.)
- **الإجراء: adopt (مرشح)** — قيّم لخانة بيانات العقوبات؛ تحقق من الإصدار الحالي على PyPI/GitHub قبل التوصيل.

## xposedornot-mcp — بحث تسريبات مجاني بلا مفتاح (13 أكتوبر 2026)
- **ما الذي تغيّر:** XposedOrNot (فهرس تسريبات مفتوح المصدر مجاني) نشر نقطة نهاية MCP عبر HTTP بلا حالة على `https://api.xposedornot.com/mcp` — بلا مفتاح API، بلا تسجيل، بلا تثبيت محلي. ست أدوات للقراءة فقط (`check_email_breaches`، `get_breach_analytics`، `domain_breach_summary` وغيرها)؛ `domain_breach_summary` يعيد أعدادًا مجمّعة فقط لا رسائل بريد فردية؛ كل الأدوات موسومة `readOnlyHint`/`idempotentHint`؛ بلا جلسات/SSE، حسب تصميم 2026-07-28 بلا حالة. أمر واحد لـ Claude Code: `claude mcp add --transport http xposedornot https://api.xposedornot.com/mcp`.
- **لماذا يهم ACI:** فحوص التعرض للتسريبات خطوة مهمة روتينية في ACI؛ صفر عبء بيانات اعتماد يجعل هذا أرخص مصدر استخبارات ممكن للتجربة. ملخصات النطاقات المجمّعة التي تحفظ الخصوصية تناسب تعامل ACI مع بيانات طرف ثالث.
- **المصدر:** https://www.clawdbytes.com/article/2026-10-13-my-ai-assistant-kept-guessing-about-data-breaches-so-i-gave-it-one-free-url-mcp- (13 أكتوبر 2026)
- **الإجراء: adopt (مرشح)** — تحقق من أن نقطة النهاية حية وافحص حدود المعدل قبل التوصيل في المهام.

## darknet-mcp-server — خادم استخبارات الويب المظلم بـ 66 أداة (badchars)
- **التاريخ:** نوفمبر 2026 (مدونة OffSec؛ تاريخ إنشاء/إصدار المستودع الدقيق **غير متحقق منه**).
- **ما الذي تغيّر:** `badchars/darknet-mcp-server`، TypeScript، MIT، 66 أداة MCP عبر بحث بيانات التسريبات، تتبع مواقع تسريب برامج الفدية/الضحايا، مراقبة سجلات السارقين، وموارد Tor/`.onion`، لـ Claude وعملاء MCP آخرين. ~445 نجمة حسب المقال.
- **لماذا يهم ACI:** مراقبة التسريبات/برامج الفدية/سجلات السارقين عمل استخباراتي شركاتي عالي القيمة (بيانات اعتماد موظفين مكشوفة، إنذار مبكر لمواقع التسريب) — ملاءمة مباشرة لمهام ACI إن كان الخادم نظيفًا. لكنها أدوات مزدوجة الاستخدام تلامس أنظمة إجرامية؛ تحتاج مراجعة قانونية/امتثال ونشرًا محكومًا (ضبط خروج، إنسان في الحلقة، سجلات تدقيق).
- **تحذير (مهم):** مقال OffSec يذكر أن تحليله مشتق من بيانات المستودع فقط — README لم يكن متاحًا وقت الكتابة. مخططات الأدوات والخدمات العليا ومتطلبات بيانات الاعتماد **غير متحقق منها**.
- **المصدر:** https://www.offsecblog.com/2026/11/darknet-mcp-server-for-dark-web.html (نوفمبر 2026)
- **الإجراء: watch** — فحص أولًا: اقرأ مخططات الأدوات الفعلية، حدّد الخدمات العليا/المفاتيح، مراجعة قانونية؛ لا توصّل إلى ACI قبل ذلك.

## mcp-cyberbro — خادم MCP لتحليل مؤشرات الاختراق (v0.0.6، 18 أكتوبر 2026)
- **ما الذي تغيّر:** خادم MCP يغلّف Cyberbro: `analyze_observable` للعناوين IP/النطاقات/URLs/الهاشات عبر محركات Cyberbro (VirusTotal، Google، GitHub وغيرها)؛ نقل stdio/SSE/streamable-http؛ تدفقات تقرير OSINT حتى 10 تحليلات متسلسلة.
- **لماذا يهم ACI:** إثراء مؤشرات الاختراق خطوة مهمة معيارية في ACI، لكن هذا الخادم مفيد فقط إن استُضيف Cyberbro نفسه ذاتيًا — إنه واجهة أمامية لا مصدر بيانات.
- **المصدر:** https://pypi.org/project/mcp-cyberbro/0.0.6/ (18 أكتوبر 2026)
- **الإجراء: watch** — ذو صلة فقط إن استضاف ACI Cyberbro ذاتيًا يومًا.

## sherlock-mcp-server — تعداد أسماء مستخدمين Sherlock كخادم MCP
- **التاريخ:** غير متحقق منه (قائمة Glama زُحفت في نوفمبر 2026؛ بلا تاريخ إصدار مؤكد).
- **ما الذي تغيّر:** غلاف FastMCP لأداة OSINT Sherlock: `search_username` عبر 400+ منصة اجتماعية؛ يتطلب تثبيت `sherlock-project` محليًا.
- **لماذا يهم ACI:** تعداد أسماء المستخدمين/المقابض عبر المنصات خطوة OSINT روتينية في ACI، وSherlock موجود أصلًا في عائلة أدوات ACI.
- **المصدر:** https://glama.ai/mcp/servers/Burnsedia/sherlock-mcp (قائمة فقط — عاملها كخيط لا كإصدار متحقق منه)
- **الإجراء: watch** — تحقق من المستودع والإصدار وحالة الصيانة قبل الاعتماد.
