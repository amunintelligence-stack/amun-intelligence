# نمط عملي: تدقيق أمني قراءة-فقط عبر CrowdStrike falcon-mcp من نافذة محادثة (حالة PHP2Shell، 22 أكتوبر 2026) + خادم MCP لأداة FalconEye OSINT

## ماذا تغيّر؟
- نشر باحث OSINT (OSINTPH) في 22 أكتوبر 2026 تقريرًا عمليًا بعنوان "PHP2Shell: Auditing Eight Servers Through Falcon MCP": استخدم **خادم falcon-mcp مفتوح المصدر من CrowdStrike** داخل Claude Desktop لتدقيق 8 مضيفات Linux ضد ثغرتَي **PHP2Shell** (CVE-2026-109618 وCVE-2026-109619 — RCE غير موثّقة في محرك PHP نفسه، رُقّعت 21 أكتوبر 2026، والاستغلال في البرية تأكد خلال ساعات).
- النمط الأمني المهم: شغّل الخادم بوحدتَي `hosts` و`rtr` فقط، وكشف **مجموعة أوامر قراءة-فقط** (`ls`, `cat`, `ps`, `filehash`, `netstat`, `env`, `users`) — دون `runscript` أو `put` أو أوامر إدارية. كل أمر يُنفَّذ بهوية Falcon الخاصة به و**يُسجَّل في سجل تدقيق RTR مع session ID** — أي أثر تدقيق أفضل من جلسة SSH تقليدية. في ~30 دقيقة و~40 أمرًا قراءة-فقط وجد PHP مخفيًا في مكانين كان يظن أنه لا يعمل فيهما.
- في السياق نفسه: أداة **FalconEye** (عدّة OSINT مجانية مفتوحة المصدر، 19 تبويبًا: تتبع تصيّد، attack surface، تتبع عملات، Telegram OSINT، تعداد أسماء المستخدمين، ملفات شركات...) **تشحن خادم MCP خاصًا بها لـ Claude** — أي أدوات OSINT بدأت فعليًا تُوزَّع كخوادم MCP جاهزة.

## لماذا يهم ACI؟
- هذا **أول نموذج عملي موثّق لحالة استخدام MCP في عمل أمني/OSINT حقيقي**: خادم MCP رسمي من بائع EDR كبير (CrowdStrike) بأدوات مقيّدة قراءة-فقط + تدقيق كامل = النموذج الذي يجب أن نطبّقه على أي خادم MCP نبنيه لمهام ACI (أدوات استطلاع قراءة-فقط، كل استدعاء مسجّل بهوية، لا أوامر كتابة).
- FalconEye مثال حي على الاتجاه الذي نتتبعه: **مصادر OSINT تُشحن كخوادم MCP** — مرشّح للمراجعة عندما نبدأ اعتماد MCP في ACI.
- ملاحظة جانبية من التقرير: باحثو JFrog وثّقوا **مستودعات PoC مزيّفة** حول PHP2Shell — تذكير بمخاطر supply-chain عند جلب أدوات MCP/سكربتات من GitHub دون تحقق.

## الإجراء المقترح: راقب (مع تبنّي النمط لاحقًا)
لا تثبّت شيئًا الآن. عند بناء أول خادم MCP لـ ACI: انسخ هذا النمط — أدوات قراءة-فقط، هوية مسماة لكل استدعاء، سجل تدقيق كامل، ولا أوامر تنفيذ/كتابة في خادم الاستطلاع. وقيّم FalconEye كخادم MCP مرشّح لاحقًا.
