# Azure MCP Server 3.0 — إصدار مستقر (12 أكتوبر 2026)

**التاريخ:** 2026-10-15
**الفئة:** mcp

## ما الذي تغيّر
- أصدرت Microsoft الإصدار المستقر **Azure MCP Server 3.0** في 12 أكتوبر 2026 (مدونة Azure SDK).
- الإصدار يبني على دعم الاستضافة الذاتية عن بُعد في 2.0، ويضيف قدرات تشغيلية يومية أكثر على Azure (من مراجعة حماية النسخ الاحتياطي إلى تقييم تغييرات البنية التحتية)، مع عقود أدوات أوضح وافتراضات أمنية أشد للموارد الجديدة.
- الإصدار هو ثالث إصدار رئيسي، وجمع 50 تكرارًا تجريبيًا ومئات المساهمات.

## لماذا يهم ACI
- خادم MCP رسمي من مزود سحابي كبير بهذا الحجم هو مرجع لما يجب أن تبدو عليه عقود الأدوات الجيدة: أسماء وأوصاف مثبتة، وافتراضات أمنية افتراضية، ودعم الاستضافة عن بُعد.
- لا نستخدم Azure MCP Server مباشرة في ACI، لكن عند تعريض وظائف ACI عبر MCP لاحقًا، يجب نسخ نمط «عقد أداة واضح + أمان افتراضي» بدل تعريض أدوات فضفاضة.
