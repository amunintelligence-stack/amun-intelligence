# خوادم MCP جديدة: Airbyte (28 أكتوبر) + Refersion + Rapid Indexer — وتحذير NVIDIA الافتراضي

**التاريخ:** 2026-10-28 | **الفئة:** mcp | **الحالة:** إصدارات جديدة + نمط أمني يستحق النسخ

## ما الذي تغيّر
- **Airbyte MCP Server — 28 أكتوبر 2026 (اليوم):** واجهة لغة طبيعية لمراقبة خطوط أنابيب Airbyte وتشخيص الأعطال وإصلاحها، مع طبقة سياق جديدة تستعلم Snowflake وBigQuery مباشرة من بيانات مزامنة من +50 موصّل مصدر. يعمل مع ChatGPT وClaude وVS Code وغيرها، مع حوكمة تمنع سلوكًا مارقًا وسجل تدقيق لكل إجراء منشؤه MCP. التوسّع المخطط: إدارة المصادر والوجهات والاتصالات والمهام والمستخدمين ومساحات العمل.
- **Refersion MCP Server — 27 أكتوبر 2026:** إدارة برامج التسويق بالعمولة من داخل المساعد — مراجعة التحويلات، اعتماد المسوّقين، إصلاح العمولات المفقودة — بأذونات دقيقة. كل نقطة API تصبح أداة تلقائيًا.
- **Rapid Indexer MCP Server — 25 أكتوبر 2026:** إرسال صفحات وروابط خلفية إلى Googlebot والتحقق من الفهرسة من داخل المساعد — مثال على أتمتة SEO كاملة داخل المحادثة.
- **تحذير أمني (نمط، ليس أداة ACI): NVIDIA App 11.0.9.565 (13 أكتوبر)** شحنت خادم MCP محليًا مع مفتاح "السماح لوكلاء الذكاء الاصطناعي بالتحكم في NVIDIA App" **مفعّلًا افتراضيًا** بعد التحديث — 12 أداة (6 قراءة، 6 مغيّرة: التقاط فيديو، تشغيل تطبيقات، تطبيق ملفات تحسين). الخادم loopback فقط (127.0.0.1:13508) ولا يتصل بخدمة خارجية من تلقاء نفسه، لكن الافتراضي المفعّل هو المشكلة: أي وكيل محلي متوافق يتصل دون موافقة صريحة جديدة.

## لماذا يهم ACI
- Airbyte وRefersion وRapid Indexer ليست أدوات ACI — قيمتها نمطية: حوكمة + سجل تدقيق + أذونات دقيقة (Airbyte/Refersion) هي المواصفات التي يجب أن تُطلب من أي خادم MCP يُربط بمهام ACI مستقبلًا.
- درس NVIDIA ينسجم مباشرة مع قواعد ACI الأمنية (قائمة سماح فقط، لا أدوات مغيّرة دون موافقة): **أي خادم MCP يُقيَّم يجب أن يُفحص مفتاحه الافتراضي** — "مفعّل افتراضيًا" = رفض حتى يُعاد ضبطه يدويًا، خصوصًا للأدوات المغيّرة.
- خوادم المرجع MCP 2.0.0 (19 أكتوبر، 2026-07-28) ما زالت الخطة المرجعية؛ هذه الإصدارات الجديدة لم تُختبر ضدها الليلة.
