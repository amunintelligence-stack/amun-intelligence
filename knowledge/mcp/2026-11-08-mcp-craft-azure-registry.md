# MCP — Craft CMS 5.12 يُدخل MCP في النواة + بوابة MCP من Azure + السجل يتجاوز 60 ألف خادم (8 نوفمبر 2026)

## Craft CMS 5.12 — MCP في النواة لكل الإصدارات (3 نوفمبر 2026)
- **ما الذي تغيّر:** أطلقت Craft CMS الإصدار **5.12** في 3 نوفمبر 2026 وفيه MCP داخل النواة، متاح في كل الإصدارات (لا إضافة مدفوعة). ثلاثة خوادم: خادم HTTP موثَّق بـ OAuth مع 2FA وشاشة موافقة، وخادم HTTP عام يعرض فقط المحتوى الذي وافق عليه مدير، وخادم stdio للاستخدام المحلي. الإصدار 5.12.0.1 يعرّف **68 أداة** تغطي الإدخالات والمسودات والمراجعات والأصول والأقسام والحقول والمستخدمين والأذونات والإضافات وإعدادات المشروع.
- **لماذا يهم ACI:** نمط يستحق الملاحظة لا اعتمادًا مباشرًا: أنظمة إدارة المحتوى الكبرى باتت تشحن MCP افتراضيًا — أي موقع مبني على Craft يصبح مصدر بيانات قابلًا للاستعلام الوكيلي بلا وسيط. لمهام استخبارات المحتوى/المنافسين: إن كان هدف يستخدم Craft 5.12+، فخادم MCP العام (المحتوى المعتمد فقط) مصدر منظم محتمل؛ والخادم الموثَّق لا يُلمس بلا اعتماد.
- **المصادر:** https://dev.to/aimeos/best-mcp-cms-2026-11-cms-with-model-context-protocol-compared-1lfj (قُرئ 2026-11-08؛ قارن 11 خادم CMS — تسعة من عشرة أنظمة لديها الآن خادم MCP رسمي)
- **الإجراء: watch** — نمط «MCP في نواة CMS» للتقييم عند بناء موصلات محتوى مستقبلية.

## Azure — بوابة MCP في Application Gateway for Containers (معاينة عامة، 4 نوفمبر 2026)
- **ما الذي تغيّر:** أتاحت Azure معاينة عامة لبوابة MCP في Application Gateway for Containers عبر مورد `MCPRoute` المخصص: نشر خوادم MCP خلف اسم مضيف ومسار مستقرين مع TLS مركزي، وتحقق JWT، وجدار WAF، ومراقبة صحة الخلفية، وسياسات توجيه. يدعم التوجيه المباشر لخادم واحد **وتجميع عدة خوادم مستقلة خلف نقطة نهاية منطقية واحدة**.
- **لماذا يهم ACI:** مرجع تصميمي مباشر لأي تعريض مستقبلي لخادم MCP خاص بـ ACI: البوابة تفرض الهوية والـ WAF والتجميع قبل وصول العميل إلى الخادم — نفس فلسفة Cloudflare Access MCP Portals (دورة 7 نوفمبر) لكن داخل Azure. لا اعتماد سحابي في ACI اليوم، فسجّل كمرجع فقط.
- **المصادر:** https://www.cloudpulsebriefs.com/briefs/576388/ (نُشر 4 نوفمبر 2026، عن تحديث Azure)
- **الإجراء: watch** — مرجع تصميمي لبوابة MCP.

- **ما الذي تغيّر:** خادم **apify/apify-mcp-server** (استخراج بيانات من وسائل اجتماعية وبحث عبر وكلاء) عند 15 ألف نجمة على GitHub مع **+1.1 ألف نجمة في 7 أيام** — الأسرع نموًا في دليل MCP هذا الأسبوع. وجديد كليًا: **shanselman/sandbox-mcp** (أجهزة Windows افتراضية مؤقتة للاختبار عبر MCP) مع +203 نجوم في يوم واحد.
