# OpenOSINT: وكيل OSINT بالذكاء الاصطناعي مع خادم MCP أصلي (20 أداة)

- التاريخ: 2026-10-11 | الفئة: mcp | الإجراء: **مراقبة**

## ما الذي تغيّر
مشروع openosint (noorgx/openosint على GitHub) نُشّط مؤخرًا (آخر تحديث قبل ~12 يومًا، أي أواخر سبتمبر 2026): وكيل OSINT تفاعلي (REPL) وواجهة ويب وسطر أوامر، مع **خادم MCP أصلي** يعرّض 20 أداة لأي عميل متوافق (Claude Code/Desktop وغيرهما) دون إعداد إضافي. الأدوات تشمل: بريد إلكتروني، أسماء مستخدمين، تسريبات، WHOIS، IP، نطاقات فرعية، dorks، لصاقات (pastes)، هواتف، Shodan، VirusTotal، Censys، IP2Location، AbuseIPDB، GitHub، DNS، بحث dork حي، وكشط URLs. يعمل مع Claude أو Ollama المحلي أو أي endpoint متوافق مع OpenAI، ويدعم التنفيذ المتوازي وتقارير PDF/Markdown تلقائية.

## لماذا يهم ACI
هذا بالضبط نموذج «الأدوات كخوادم MCP» الذي نريد لمهام ACI: حزمة OSINT جاهزة يمكن توصيلها بوكلائنا عبر MCP بدل إعادة بناء كل تكامل. كونه يدعم نماذج محلية (Ollama) يفتح باب التشغيل الرخيص/الخاص. يحتاج تقييمًا أمنيًا قبل أي استخدام (تسميم أدوات، مفاتيح API).
