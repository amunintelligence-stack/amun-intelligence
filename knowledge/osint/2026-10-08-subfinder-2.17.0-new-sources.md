# Subfinder v2.17.0 — مصدران جديدان بدون مفاتيح (crtname و subdomaincenter)

- التاريخ: 2026-10-08 | الفئة: osint | الإجراء: **اعتماد (adopt)**

## ما الذي تغيّر
أصدرت ProjectDiscovery الإصدار v2.17.0 من subfinder بتاريخ 2026-10-08 — وهو نفس الإصدار المثبت لدينا، فلا حاجة للترقية. الجديد: مصدران سلبيان جديدان لا يحتاجان مفاتيح API (`crtname` و `subdomaincenter`)، وفلترة النتائج بتعبيرات نمطية (`-match-regex` / `-filter-regex`)، وتقييد التزامن عند تعداد عدة نطاقات، وترقية `golang.org/x/net` و `x/text` لإصلاح ثغرات HIGH. للسياق: v2.14.0 أزال مصدر Facebook (Meta CT) بعد أن أوقفت Meta الـ API upstream، وv2.15.0 أضاف مصدر Sub.md.

## لماذا يهم ACI
مهام تعداد النطاقات الفرعية عبر subfinder تكسب مصدرين مجانيين بدون مفاتيح — زيادة مباشرة في التغطية بلا تكلفة. إصلاحات x/net/x/text تبقي ثنائية التعداد نظيفة أمنيًا.
