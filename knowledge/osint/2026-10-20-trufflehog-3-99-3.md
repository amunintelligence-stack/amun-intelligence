# TruffleHog v3.99.3 — SonarQube token detector + GitHub comment-scan fix

## What changed
trufflesecurity/trufflehog released v3.99.3 on 2026-10-19. Notable changes: a new SonarQube Server token detector (extends its ~700 verified credential detectors), a fix for GitHub comment scans stopping early on large repositories, GithubOauth2 detector now rotates only on specific error messages, and several security dependency bumps (grpc 1.83.2, go-archive, OpenTelemetry, edwards25519, rabbitmq amqp091). Prior nightlies covered trufflehog? No — not in the ACI knowledge store; this is its first entry.

## Why it matters for ACI
TruffleHog is secret/leak discovery — a passive recon source that finds exposed credentials in repos, gists and Docker images belonging to a target organization. Its GitHub comment-scan fix directly affects coverage quality for GitHub-source missions. It's not in the ACI tools registry yet; worth evaluating as a leak-intel source alongside our existing recon set.
