# Consensus-OSINT — أداة موحدة جديدة لبحث أسماء المستخدمين والإيميلات والهواتف من 19 مشروعًا (8 أكتوبر 2026)

## ماذا تغيّر؟
- مشروع جديد كليًا: **OSINT-Experts-Society/Consensus-OSINT** — أُنشئ على GitHub بتاريخ 8 أكتوبر 2026، وجمع 169+ نجمة و24 fork خلال أسبوعين، مع 11 إصدارًا (الأحدث 0.4.10 مُختبر على Windows وLinux).
- الفكرة: أداة بحث موحدة تجمع **9,700+ فحص وقاعدة موقع من 19 مشروعًا مفتوح المصدر** — Maigret، User Scanner، Aliens Eye، WhatsMyName، Sherlock، FindMe، DetectDee، Nexfil، GoSearch، Vesper، Sreg، Holehe، Linkook، UserJoo، Socialscan، Numint، Ignorant، Mailcat، SherlockV2 — مع إزالة التكرار وتوحيد النتائج في تثبيت واحد.
- الصيانة: فريق خبراء يراجع المشاريع الـ19 أسبوعيًا — آخر مراجعة مكتملة بتاريخ 16 أكتوبر 2026 أضافت 13 وحدة + 1,782 قاعدة موقع، والوحدات المكسورة تُستبعد صراحةً.
- الميزات: بحث bulk، توليد صيغ أسماء المستخدمين، استخراج بيانات الملفات (bios، صور، تواريخ انضمام، حسابات مرتبطة)، بحث متكرر يتبع الخيوط الجديدة تلقائيًا، تقارير HTML/PDF/CSV/JSON، رسوم بيانية للأدلة (مع تصدير Neo4j وXMind)، ودعم MCP للمساعدات الذكية.
- الترخيص: GPL-3.0. التثبيت: `pip install "consensus-osint[modules,pdf]"` أو مثبت Windows جاهز.

## لماذا يهم ACI؟
- نستخدم sherlock وmaigret منفصلين؛ Consensus يحل مشكلة صيانة قواعد المواقع المتكسرة بمرور الزمن — مقارنة المشروع نفسه تُظهر أن Sherlock لم يُحدَّث منذ 28 أبريل 2026 بينما Maigret وUser Scanner وWhatsMyName نشطة — أي أنه **بديل عملي موحد لمحرك بحث الهوية** في ACI.
- ملاحظة تحفظ: الأداة حديثة جدًا (أسبوعان فقط) والـ 19 مشروعًا مدمجة بلا مراجعة مستقلة منا بعد — **التقييم قبل الاعتماد**.
- نقطة قوة لبيئتنا: تعمل عبر HTTPS على المصادر العامة مباشرة، مناسبة لنا (DNS محلي مسموم بالبروكسي، ونفضل المصادر السلبية عبر HTTPS).
