# OpenOSINT v2.35.0 — وكيل OSINT مفتوح (21 أداة + خادم MCP أصلي)

**Date found:** 2026-10-21 (nightly dev researcher)

## What changed
OpenOSINT (رخصة MIT) وصل إلى **v2.35.0** في أكتوبر 2026 (README على GitHub يؤكد «v2.35.0 — October 2026»؛ مدرج على EveryDev منذ 16 أكتوبر). الجديد مقابل آخر تقييم لنا (v2.33.1 في ملف 10 أكتوبر):
- **21 أداة** تحقيق معيارية خلف واجهة لغة طبيعية؛ 4 واجهات: REPL تفاعلي، CLI مباشر، واجهة ويب، و**خادم MCP أصلي**.
- تصميم «التوقف الصلب» (hard stop): النموذج لا يولّد نتائج الأدوات أبدًا — ينفذ الثنائي الحقيقي (holehe، sherlock، sublist3r…) وتعود المخرجات الفعلية فقط، فاستحالة الهلوسة في نتائج الأدوات هيكلية.
- تكاملات: holehe، sherlock، sublist3r، phoneinfoga، HaveIBeenPwned، Shodan، VirusTotal، Censys، ipinfo.io، AbuseIPDB، GitHub API، Bright Data، GDELT، Apify.
- وحدة **رسم بياني للكيانات** مع إزالة تكرار same_as بمراجعة بشرية + تقرير تعرّض النطاقات الخارجي بتقدير A–F (تجريبي).
- المشرف: Tommaso Bertocchi؛ التثبيت: `pip install openosint`.

ملاحظة أمنية سابقة من ملف 12 أكتوبر: الإصدار 2.29.1 أصلح ثغرة واجهة الويب المحلية، و2.30.0 يربط Docker على 127.0.0.1:8080 — درس الاعتماد: الواجهات المحلية ≠ معزولة، اربط loopback فقط.

## Why it matters for ACI
خادم MCP الخاص بـ OpenOSINT موجود أصلًا في سجلنا كمرشح تقييم (eval). إصدار v2.35.0 يضيف إزالة تكرار الكيانات بمراجعة بشرية — ذا صلة مباشرة بخطط entity resolution لدينا، وتصميم «النتائج من تنفيذ حقيقي» يطابق قواعد النزاهة لدينا. الحالة تبقى eval؛ لا تثبيت على الـ VM بدون «نفذ».
