# otinstaller — واجهة موحدة لتثبيت وتشغيل أدوات OSINT (أكتوبر 2026)

## ماذا ظهر؟
أداة جديدة مفتوحة المصدر اسمها **otinstaller** (من فريق OSINT Ambition، أُعلن عنها ~**12 أكتوبر 2026**) تحل مشكلة قديمة: كل أداة OSINT تتثبت بطريقة مختلفة وتتعارض تبعياتها مع بعضها.

ما تفعله:
- `pipx install otinstaller` ثم `ot install --all` يثبّت **47 أداة** OSINT (منها sherlock وholehe وtheHarvester وdnstwist…).
- كل أداة في **virtualenv مستقل** تحت `~/.otinstaller/` — لا كسر متبادل للتبعيات أبدًا.
- `ot doctor` يفحص المتطلبات الناقصة، و`ot init` ينشئ الإعدادات.
- صيغة تشغيل موحدة حسب نوع الهدف بدل حفظ أعلام كل أداة:
  - `ot run sherlock -- u:janedoe` (اسم مستخدم)
  - `ot run holehe -- e:jane@example.com` (بريد إلكتروني)
  - `ot run dnstwist -- d:example.com` (نطاق)
- كل النتائج تُحفظ في مكان واحد قابل للاسترجاع.

## لماذا يهم ACI؟
ACI يعاني من نفس المشكلة بالضبط: أدوات بايثون متعددة بتبعيات متعارضة (holehe **مكسور حاليًا** بسبب تعارض `httpx`!)، وتركيب يدوي لكل أداة. otinstaller قد يكون حلًا عمليًا لمشكلة التبعيات، ويستحق التقييم — خصوصًا أنه يوحّد أيضًا صيغة الاستدعاء مما يسهّل بناء وكلاء فوق الأدوات.
