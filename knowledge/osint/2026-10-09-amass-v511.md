# OWASP Amass v5.1.1 — أحدث خط v5 مع Engine REST API

- التاريخ: 2026-10-09 | الفئة: osint | الإجراء: **اعتماد (adopt)** — تقييم الترحيل إلى v5 + الـ REST API

## ما الذي تغيّر
v5.1.1 هو الأحدث (v5.0.0 في أغسطس، v5.0.1 في 4 سبتمبر): إعادة كتابة كاملة بمسار وحدة `v5`، قاعدة بيانات أصول جديدة (asset-db v0.24.4)، **أول نسخة من Engine REST API**، dispatcher بطابور دائم (durable backlog)، وتحسينات أداء. (ملاحظة: عرض التاريخ في صفحة GitHub كان مشوّهًا، لكن ترتيب الإصدارات وتثبيت خارجي لـ v5.1.1 بتاريخ 16 سبتمبر 2026 يؤكدان أنه ضمن النافذة تقريبًا.)

## لماذا يهم ACI
الـ REST API الجديد يعني إمكانية تشغيل Amass كخدمة تُستدعى من الباكند بدل الـ CLI — أنظف بكثير لخط أنابيب المهمات. (v4.2.0 ما زال المستقر التقليدي.)
