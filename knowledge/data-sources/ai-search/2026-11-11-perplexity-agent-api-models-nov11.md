# بحث ذكاء اصطناعي — Perplexity Agent API يضيف نموذجين اليوم؛ Decisions API يضيف تأريضًا ويب حيًا (11 نوفمبر 2026)

## Perplexity Agent API — نموذجا Gemini 4 Carbon وClaude Fable 5.2 أُضيفا اليوم (11 نوفمبر 2026)

- **ما الذي تغيّر:** تتبّع تغييرات توثيق Perplexity (docswatch) رصد في **11 نوفمبر 2026** إضافة نموذجين إلى Agent API: **Gemini 4 Carbon** و**Claude Fable 5.2**. التفاصيل (أسعار/حدود/مستويات جهد) لم تُنشر في ملخص التغيير — يُعاد فحص سجل تغييرات API الرسمي قبل أي استخدام.
- **لماذا يهم ACI:** Agent API مصدر بحث مرشح لمهام ACI (مستوى ultra سُجّل 9 نوفمبر)؛ نموذجان جديدان قد يغيّران خيار النموذج/التكلفة — لكن بلا تفاصيل لا قرار الليلة.
- **المصادر:** https://docswatch.stevetoth.ai/perplexity/perplexity-api-changelog/2026-11-06/ (يذكر تغيير 11 نوفمبر في قائمة الإصدارات) — https://docs.perplexity.ai/docs/resources/changelog
- **الإجراء: watch** — أعد فحص التفاصيل في الدورة القادمة؛ لا اعتماد.

## استدراك — Decisions API: تأريض ويب حي + جلب URL (4–5 نوفمبر؛ لم تُسجَّل من قبل)

- **ما الذي تغيّر:** في **4–5 نوفمبر 2026** أضافت Perplexity إلى **Decisions API** وضع `web_grounding`: قبل أن يجيب النموذج، يُنفَّذ بحث سريع (Fast Search) لكل سؤال (حتى 100 سؤال/طلب، 10 متزامنة، حد ثانية لكل بحث و3 ثوانٍ إجمالًا)؛ ويمكن تمرير URL صفحة كـ state فيُجلب طازجًا أولًا. التكلفة: **$0.001 لكل بحث أو جلب** فوق رموز الإدخال (بحد أقصى $0.10 بحثًا/طلب)؛ النموذج `pplx-decider-v1.2` بـ $0.02/مليون رمز إدخال (flash بـ $0.01)، ورموز الإخراج مجانية.
- **نتيجة دقة (ادعاء مورّد):** على 328 ادعاء صحيح/خاطئ من أخبار أكتوبر 2026 وحقائق ويكيبيديا نادرة، قفزت الدقة من **56.4% بلا تأريض إلى 97.3% معه**، والأخطاء من 143 إلى 9؛ زمن الوسيط من 139ms إلى 366ms. اختبار مستقل (Parallel Web Systems، 100 سؤال علني): ‏86/100 صحيح مع التأريض — الأعلى في لوحتهم المنشورة وقتها. كل الأرقام من المورّد أو من لوحة طرف واحد؛ بلا تحقق مستقل كامل.
- **لماذا يهم ACI:** Decisions API يجيب أسئلة مغلقة (نعم/لا، اختيار متعدد، احتمالات معايرة) عن نص وصور — مع التأريض الحي يصلح للتحقق من حقائق متغيرة (منصب تنفيذي حالي؟ أحدث إصدار مستقر لحزمة؟ هل ما زال حدث مجدولًا؟) داخل سير عمل التحقق في المهام، بتكلفة هامشية ($0.001/سؤال). قيد: مكتبتا Python ‏0.44.0+ وTypeScript ‏0.39.0+ لا تعرضان بعدُ نوعَي `mode` و`search_results`.
- **المصادر:** https://docswatch.stevetoth.ai/perplexity/perplexity-api-changelog/2026-11-05/ (رُصد 5 نوفمبر 2026) — https://www.unite.ai/perplexity-adds-live-web-grounding-to-its-decisions-api/ (4 نوفمبر 2026)
- **الإجراء: watch** — قيّم Decisions API مع `web_grounding` كمصدر تحقق سريع في المهام؛ الأرقام ادعاء مورّد حتى تحقق مستقل.
