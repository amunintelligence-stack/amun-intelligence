# Perplexity Decisions API — وضع `web_grounding` الجديد (أقوى أداة الليلة)

- **التاريخ:** أُعلن **2026-11-05** (تشغيلات معايير 29 أكتوبر / 4 نوفمبر 2026).
- **ما الذي تغيّر:** **Decisions API** في Perplexity (تعيد احتمالات لا نثرًا — نعم/لا، اختيار متعدد، تسجيل) تدعم الآن **`"mode": "web_grounding"`**: البوابة تشغّل بحثًا سريعًا واحدًا لكل سؤال، وترفق عنوان الصفحة/رابطها/جسمها كدليل قبل أن يجيب نموذج القرار؛ ويمكن أن تكون الحالة أيضًا URL لجلب طازج. الدقة على اختبار Perplexity نفسه من 328 ادعاءً: **56.4% ← 97.3%** (الأخطاء 143 ← 9)؛ على معيار PWS-Decisions العام: **51% ← 86%**، زمن استجابة وسيط ~370ms (مقابل 139ms بلا تأسيس). التكلفة: **$0.001 لكل بحث مكتمل** + رموز الإدخال (الدليل يُحسب كرموز)؛ حتى 100 سؤال/طلب. عناصر سجل تغيير ذات صلة: **Analytics API تسقط تفصيل مصدر الاعتماد** (3 نوفمبر)؛ **Agent API تعيد الآن حتى 4,000 رمز/صفحة** (30 أكتوبر، مضاعفة من 2,000).
- **لماذا يهم ACI:** هذه أقوى أداة جديدة في مسح الليلة. مصنّف نعم/لا رخيص وسريع ومؤسَّس على الويب هو بالضبط ما يحتاجه وكلاء المقيّم/المتحقق في ACI (التحقق من الادعاءات، تأكيد المصادر، تسجيل العملاء المحتملين) عند ~$0.001/بحث. تغيير Agent API إلى 4,000 رمز/صفحة يحسّن أيضًا عمق استرجاع الأدلة.
