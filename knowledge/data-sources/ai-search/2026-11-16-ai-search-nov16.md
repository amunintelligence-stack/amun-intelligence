# بحث ذكاء اصطناعي — Perplexity Agent API: دعم Gemini 4 Hydrogen + افتراضي 128K رمز إخراج (12–14 نوفمبر 2026)

## 1. Perplexity Agent API — دعم Gemini 4 Hydrogen (14 نوفمبر) وافتراضي 128K رمز إخراج (12 نوفمبر)

- **ما الذي تغيّر:** سجل تغييرات Perplexity API (كما التقطه AI Docs Watch):
  - **14 نوفمبر:** Agent API يدعم الآن **Gemini 4 Hydrogen** (نموذج بحث/وكيل جديد من Google في منظومة Perplexity).
  - **12 نوفمبر:** مستويات جهد Agent API **تفترض الآن 128K رمز إخراج** (ارتفاعًا من حد أدنى سابق) — تغيير افتراضي يؤثر على طول الاستجابة والتكلفة.
  - **13 نوفمبر:** الأسماء المستعارة لـ Decisions API تشير الآن إلى **v1.3** (مغطاة في ملف 13 نوفمبر — لا تُعاد هنا).
  - **11 نوفمبر:** Agent API أضاف **Gemini 4 Carbon وClaude Fable 5.2** (مغطاة في ملف 11 نوفمبر).
  - **6 نوفمبر:** جهد **ultra** للأبحاث الطويلة (مغطى في ملف 9 نوفمبر).
- **لماذا يهم ACI:**‏ إن استخدمت ACI واجهة Perplexity Agent API في مهام البحث، فالافتراضي الجديد 128K يرفع سقف الإخراج (وتكلفة الرموز المحتملة) دون تغيير إعدادات؛ وHydrogen خيار نموذج جديد يجب تثبيته صراحةً قبل الاعتماد عليه في قياسات.
- **المصادر:** https://docswatch.stevetoth.ai/perplexity/perplexity-api-changelog/2026-10-30/ (قائمة التغييرات: Hydrogen 14 نوفمبر، 128K في 12 نوفمبر)؛ https://docs.perplexity.ai/changelog
- **الإجراء: watch** — ثبّت النموذج والجهد صراحةً في أي استدعاء Perplexity Agent API لدى ACI؛ لا تعتمد على الافتراضيات الجديدة قبل قياس التكلفة.
