# بحث الذكاء الاصطناعي كـAPI: إطلاق Exa 3.0 + تغييرات Perplexity (أكتوبر 2026)

## ماذا تغيّر؟

**1) إطلاق Exa 3.0 Search API (~20 أكتوبر 2026):**
Exa أطلقت الجيل الثالث من واجهة البحث الخاصة بها، وتدّعي — وفق اختباراتها الخاصة (أكتوبر 2026) — التفوق على Perplexity وBrave وParallel في 8 معايير (BrowseComp: ‏91.8% مقابل 91.5% لـPerplexity؛ WebCode: ‏75.5% مقابل 69.9%). الأسعار: **$7 لكل 1,000 طلب** (نسخة Lite بـ$4). ميزة مهمة لـACI: Exa مصمم للبحث البرمجي/الاستخباري (استخراج الكيانات: متوسط 15.4 كيان شركة و7.6 كيان شخص لكل مهمة — الأعلى بين المُختبرين).

**2) تغييرات Perplexity API (أكتوبر 2026):**
- إعدادات `low` و`medium` و`high` في Agent API أصبحت تستخدم **Fast Search** افتراضيًا: التكلفة المعلنة للبحث انخفضت من **$2.50 إلى $1.00 لكل 1,000 استدعاء**، وزمن الاستجابة أقل بنحو **800ms**. الإعداد `xhigh` بقي على البحث القياسي، ويمكن فرضه صراحة بـ`search_type: "web"`.
- **تقاعد Sonar Chat Completions API**: أُعلن في 13 أغسطس، والموعد المجدول للإيقاف كان **27 سبتمبر 2026** — أي تكامل قديم مع Sonar يجب اختباره الآن لا افتراض عمله.

## لماذا يهم ACI؟
مصادر `ai-search/` هي بوابة ACI للبحث الدلالي الحي. Exa 3.0 مرشح قوي كمصدر بحث برمجي (دقة أعلى في استخراج الكيانات — مفيد مباشرة لمهام الاستخبارات عن الشركات والأشخاص)، بينما تغييرات Perplexity تعني: (أ) تكلفة أقل للبحث السريع لكن بجودة مصادر **غير مضمونة التكافؤ** — يجب مقارنة الجودة قبل الاعتماد؛ (ب) أي كود قديم يستخدم Sonar endpoint قد يكون ميتًا الآن.

## الإجراء المقترح: راقب (watch)
1. قيّم Exa 3.0 (نسخة Lite بـ$4/1K) مقابل Perplexity/Brave على عينة مهام ACI حقيقية — خاصة استخراج كيانات الشركات.
2. إن كان أي جزء من ACI يستخدم Perplexity API: حدّد `search_type` صراحةً في الكود (لا تعتمد على الافتراضي)، واختبر أن Sonar endpoint لا يزال يعمل أو اهجره إلى Agent API.
