# بحث ذكاء اصطناعي — Perplexity Agent API: تخفيضات تكلفة + مستوى Ultra جديد (6 نوفمبر 2026)

## Perplexity Agent API — تكلفة أقل في كل مستوى، ومستوى Ultra للبحث الواسع (5–6 نوفمبر 2026)

- **ما الذي تغيّر:** أعلنت Perplexity في 5 نوفمبر 2026 أن كل مستوى جهد (effort) في Agent API أصبح أقل تكلفة لكل استعلام مع جودة مساوية أو أعلى: مستوى medium تحسّن من 55% إلى 77% على BrowseComp وDSQA بينما انخفضت تكلفته ~90%؛ ومستوى xhigh حافظ على درجة WANDR عند 76.5% بنحو 25% من تكلفة أغسطس 2026. ومستوى جديد **ultra** للبحث الواسع وجمع البيانات حيث الاكتمال أهم من زمن الاستجابة: يستخدم `anthropic/claude-opus-5-5`، ويعيّن المشكلة نفسها لثلاثة وكلاء متوازيين يجمع كلٌّ منهم الأدلة مستقلًا، ويدعم الوضع الخلفي (background) للتشغيلات الطويلة؛ وتبلغ Perplexity عن 85.9% على WANDR بـ $21.71 لكل مهمة (أعلى نتيجة اختبروها). تغييرات مصاحبة: كل بحث يعيد حتى **4,000 رمز** من النتائج بدل 2,000، ومحرك مقتطفات جديد يختار نصًا أقرب مطابقة، وFast Search بسعر $1.00 لكل 1,000 طلب؛ و`fetch_url` يستخلص المقاطع ذات الصلة عبر نموذج أصغر (نحو 50% رموز إدخال أقل عند مستوى high). تذكير: Decisions API web grounding (5 نوفمبر) سُجّل في دورة 5 نوفمبر.
- **لماذا يهم ACI:** Perplexity Agent API مرشح استدعاء بحثي لمهام ACI التي تحتاج بحث ويب متعدد الخطوات مع استشهادات: تكلفة medium انخفضت ~90% مع جودة أعلى، وultra خيار جديد للمهام البحثية الواسعة (جمع أدلة عن شركة/منافس) — لكن $21.71/مهمة سعر مرتفع يُحجز للمهام الكبيرة فقط. ملاحظة منهجية: كل الأرقام من Perplexity نفسها (WANDR مجموعة تقييم خاصة بها، 500 مهمة) — بلا تحقق مستقل.
