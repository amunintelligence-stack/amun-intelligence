# بحث ذكاء اصطناعي — Perplexity تُنهي Sonar (27 سبتمبر) وتقلّص قائمة المصادر إلى 10؛ You.com تطلق Extract API وMCP بلا مفتاح (16–19 نوفمبر)؛ Genspark تطلق TeamBrain (5 نوفمبر) (22 نوفمبر 2026)

> دلتا عن ملف أمس (2026-11-21-ai-search-nov21.md): لا نكرر معيار الـ8 APIs ولا لقطة الأسعار؛ الجديد هو تقاعد Sonar وتغيير الاستشهادات في Perplexity، وسلسلة إصدارات You.com في 16–19 نوفمبر، وإطلاقات Genspark، ونهاية نماذج البحث العميق المسماة.

## 1. Perplexity تُنهي Sonar نهائيًا (27 سبتمبر 2026) — والبديل Agent API

- **ما الذي تغيّر:** أنهت Perplexity دعم Sonar chat-completions API، بما فيه `sonar-deep-research`، في 27 سبتمبر 2026. صفحة أسعارها لم تعد تسرد رسوم Sonar، ودليل الترحيل يسمّي Agent API الترقية: إجابة نثرية موثقة من نماذج طرف ثالث (OpenAI وAnthropic وGoogle وغيرها)، تُحاسَب بالرموز + رسوم أدوات (أداة بحث الويب ‏$2.50/1,000 استدعاء‏، ‏$1.00 في المسار السريع). الإغلاق كان غير متساوٍ عن قصد: استدعاءات Sonar المتزامنة والمتدفقة ما زالت تعمل لأن Perplexity تعيد صياغتها كطلبات Agent API، لكن طلبات Sonar غير المتزامنة — الطريقة المعتادة لتشغيل مهمة بحث متعددة الدقائق — توقفت عن العمل تمامًا. `sonar-deep-research` يصبح مستوى الجهد `high` في Agent API؛ وتوفر Agent API ستة إعدادات من `fast` إلى `ultra`، وتوصي الوثائق بـ`xhigh` للبحث المتقدم. وفي التوازي: أغلقت OpenAI نموذجي `o3-deep-research` و`o4-mini-deep-research` في 23 يوليو 2026، والبديل المسمى هو `gpt-5.6-sol`؛ وGoogle تبيع وكلاء (`deep-research-preview-04-2026` على Gemini 3.1 Pro).
- **لماذا يهم ACI:** أي تكامل ACI مع Perplexity مبني على Sonar — خاصة غير المتزامن — مكسور الآن؛ الترحيل إلى Agent API إلزامي. والأهم: جودة البحث العميق صارت دالة «ميزانية البحث/مستوى الجهد» لا اسم النموذج، فمهام التقييم يجب أن تسجّل مستوى الجهد.
- **المصادر:** https://websearchapi.space/blog/parallel-vs-perplexity-sonar (أسعار فُحصت 14–15 نوفمبر 2026)؛ https://www.llms.blog/posts/the-deep-research-button-has-no-model-number-anymore (فُحص 21 نوفمبر 2026)
- **الإجراء: adopt** — أوقف أي استخدام Sonar في ACI؛ ووثّق Agent API (مستويات `fast`–`ultra`) كمسار Perplexity الحالي.

## 2. Perplexity تقلّص قائمة المصادر الظاهرة إلى 10 كحد أقصى (حوالي 6 أكتوبر 2026)

- **ما الذي تغيّر:** تقرير Meltwater «AI search visibility report for October 2026» (نُشر 13 نوفمبر 2026؛ 120,000 موجه، 12.7 مليون إجابة، 88.6 مليون استشهاد عبر 8 منصات) يرصد أن Perplexity بدأت تسرد 10 مصادر كحد أقصى حوالي 6 أكتوبر، نزولًا من ~24. في الموجهات المتتبعة: استشهادات LinkedIn انخفضت ~99%، وYahoo ‏~30%‏ (وما زالت المصدر الأول بـ484,272 استشهادًا)، وForbes فقدت نحو ثلثيها؛ وحصة Reddit ارتفعت من 0.9% إلى 1.4%. تحذيران: التقرير لا يقول ما إذا أكدت Perplexity التغيير، وسجل تغييرات Perplexity العام في API لا يحوي أي إدخال عن عدد المصادر في سبتمبر–نوفمبر 2026؛ كما أن مجموعة الموجهات اتسعت من ~4,000 إلى 120,000 فالأرقام «غير قابلة للمقارنة مع الأشهر السابقة».
- **لماذا يهم ACI:** قياس ظهور العلامة عبر Perplexity صار أضيق: علامة كانت تظهر عبر LinkedIn أو Forbes قد تختفي من القائمة لا من الظهور الفعلي. مهام الظهور يجب أن تفسّر انخفاض الاستشهادات في Perplexity بعد 6 أكتوبر كتغيّر في العرض أولًا.
- **المصادر:** https://aiseoshift.com/blog/perplexity-source-limit-what-changed-for-ai-citations/ (فُحص 18 نوفمبر 2026، يستشهد بتقرير Meltwater 13 نوفمبر 2026)
- **الإجراء: watch** — أضف تحذير «قائمة مصادر Perplexity ≤10 منذ 6 أكتوبر» إلى مرجع قياس الظهور.

## 3. You.com: ‏Extract API‏ وأداة MCP ‏`you-extract`‏ ووصول MCP بلا مفتاح (16–19 نوفمبر 2026)

- **ما الذي تغيّر:** سجل تغييرات You.com الرسمي: في 16 نوفمبر أُطلقت ‏Extract API‏ — تجلب أي صفحة ويب أو PDF وتحللها إلى Markdown أو HTML نظيف عبر `POST https://ydc-index.io/v1/extract`. في 17 نوفمبر: ‏Python SDK 3.7.0‏ يضيف `you.extract()` و`you.extract_async()`؛ وخادم MCP يعرض أداة `you-extract` (صفحة أو PDF واحد لكل استدعاء، مع تحكم في التخزين المؤقت ومهلة طلب وجهد تحليل PDF) — وهي مفعّلة افتراضيًا وتحل محل `you-contents` المهملة (ما زالت تعمل مع تحذير يسمّي البديل)؛ ومسار مخصص للملف المجاني `https://api.you.com/mcp/free` يمنح عملاء بلا مفتاح `you-search` و`you-extract` و`you-discover` بلا مفتاح API أو تسجيل OAuth (100 استعلام مجاني يوميًا). في 19 نوفمبر: Otari 0.52.0 يستخدم You.com للبحث والجلب. وتفاصيل دفع إضافية (فُحصت 13 نوفمبر): ‏$10 رصيد عند التسجيل + $90 عند التحقق، بلا بطاقة، صالحة 60 يومًا‏؛ وx402 (USDC على Base أو Solana) وMPP للدفع لكل استدعاء بلا حساب. وحزمة You.com Agent Skills (7 مهارات، 4 خوادم MCP) متاحة عبر `npx ... add youdotcom-oss/agent-skills`.
- **لماذا يهم ACI:** You.com صار أرخص مسار تقييم بلا بطاقة وأسهله لوكلاء ACI: بحث + استخراج صفحة عبر MCP بلا مفتاح، و100 استعلام مجاني يوميًا — مثالي لمهام الجلب والاستشهاد الخفيفة. و`you-contents` المهملة يجب استبدالها بـ`you-extract` في أي تكامل قائم.
- **المصادر:** https://you.com/docs/changelog (إدخالات 16–19 نوفمبر 2026 — مصدر أولي)؛ https://www.anchorterminal.com/compare/firecrawl-mcp-vs-you-com-api (أُعيد التقييم 13 نوفمبر 2026)؛ https://serverdex.io/server/io-github-youdotcom-oss-mcp (فحص 22 نوفمبر 2026)
- **الإجراء: adopt** — سجّل `https://api.you.com/mcp/free` (‏you-search/you-extract/you-discover‏ بلا مفتاح) كمسار جلب/بحث افتراضي خفيف لوكلاء ACI؛ واستبدل `you-contents` بـ`you-extract`.

## 4. Genspark: ‏TeamBrain‏ (5 نوفمبر) وMedia Studio (27 أكتوبر) — وVoicePad أجهزة تُتجاهل

- **ما الذي تغيّر:** أطلقت Genspark ‏TeamBrain‏ في 5 نوفمبر 2026: طبقة سياق تنظيمي مشتركة تحوّل المستندات والبريد ومحاضر الاجتماعات والمحادثات المبعثرة إلى سياق منظم في الخلفية، وتُعلِم التناقضات ليحسمها إنسان؛ توسّع فوق Second Brain (الشخصي، يوليو 2026) إلى جانب AgentBase وGenTeam. وشراكة مع KDDI Biz Edge لدعم التبني التجاري الياباني (خدمة قناة الشركاء تبدأ يناير 2027). وفي 27 أكتوبر أُطلقت ‏Media Studio‏: مساحة إنتاج فيديو بوكيل تدمج 70+ نسخة نموذج من 20+ مصنعًا، يكتب فيها LLM النصوص ويجدول نماذج الفيديو والصورة والصوت. وفي 21–22 نوفمبر كُشف ‏SecondBrain VoicePad‏: جهاز إدخال (مفاتيح + إملاء صوتي) بسعر ‏$169‏ (‏$119–149‏ في Kickstarter الذي يبدأ 24 نوفمبر) — أجهزة استهلاكية، لا صلة لها بـACI.
- **لماذا يهم ACI:** TeamBrain نموذج مرجعي لطبقة ذاكرة/سياق تنظيمية لوكلاء ACI (هيكلة خلفية + كشف تناقضات + حسم بشري) — يستحق الدراسة المعمارية لا الاعتماد. وMedia Studio لا يتصل بمهمة البحث.
- **المصادر:** https://eigenradar.com/en/ai/briefs/2026-11-06/genspark-teambrain-shared-context/ (إعلان 5 نوفمبر 2026)؛ https://theproofdesk.com/genspark-review (مراجعة نوفمبر 2026)؛ https://mezha.net/eng/news/mezha-992f5c4130f857c0195551ca_genspark-s_secondbrain_voicepad/ (21 نوفمبر 2026)
- **الإجراء: watch** — ادرس TeamBrain كمرجع معماري لطبقة سياق ACI؛ وتجاهل VoicePad.

## 5. Perplexity Pro ‏$17/شهر‏ وMax ‏$167/شهر‏ سنويًا (فُحص 20 نوفمبر)؛ ومسارات API محدّثة

- **ما الذي تغيّر:** صفحة خطط Perplexity في 20 نوفمبر 2026: ‏Pro $17/شهر سنويًا‏ (4,000 رصيد إضافي، وصول Computer موسع، بحث عميق، اختيار نموذج) و‏Max $167/شهر سنويًا‏ (35,000 رصيد إضافي + 10,000 رصيد شهري). وPro يوجّه عبر GPT-6.2 Sol وGemini 4 Neon وClaude Sonnet 5.5 وKimi K3 وGLM 5.3 وGrok 4.7، ويسحب من مصادر مرخصة مثل PitchBook وStatista. وحدة الحساب انتقلت من «عمليات بحث Pro يوميًا» إلى الأرصدة. وللبناء: ‏Perplexity Search API ‏$5/1,000 طلب، Fast ‏$1/1,000‏ (كما سُجّل أمس)؛ وYou.com ‏$5/1,000‏؛ وExa ‏$10 مجاني/شهر‏؛ وBrave Search API ‏$5/1,000 مع $5 مجاني شهريًا‏.
- **لماذا يهم ACI:** تأكيد أن Pro لم يعد «بحثًا» بل توجيهًا متعدد النماذج + مصادر مرخصة — قيّم مقابل حاجة ACI لمصادر PitchBook/Statista. وأسعار API أمس ما زالت صالحة.
- **المصادر:** https://www.aitoolscollective.com/guides/perplexity-alternative/ (صفحة خطط فُحصت 20 نوفمبر 2026)
- **الإجراء: watch.**
