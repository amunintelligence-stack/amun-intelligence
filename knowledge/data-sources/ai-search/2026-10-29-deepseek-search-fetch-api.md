# DeepSeek Search & Fetch API (17 أكتوبر): محرك بحث داخلي مفتوح للمطورين — مرشح تأريض ويب لـACI

## ما الذي تغيّر
- **17 أكتوبر 2026:** فتحت DeepSeek واجهتي Search وFetch للجميع، مدعومتين بمحركها الداخلي (مئات مليارات الصفحات، متعدد اللغات، بتصفية لرسائل SEO غير المرغوب فيها و«GEO manipulation» والمحتوى المولّد بالذكاء الاصطناعي منخفض الجودة — ادعاءات بلا قياس مستقل).
- **الواجهتان:** Search عبر `POST /v1/tools/search` (استعلام 1–128 حرفًا، معاملات `site:` و`-site:` وعبارات مقتبسة و`lang:` و`after:`/`before:`، عدد النتائج 1–50، افتراضي 10)؛ Fetch عبر `POST /v1/tools/fetch` (صفحة واحدة بصيغة Markdown، يرفض العناوين غير العامة والبيانات الثنائية).
- **حقول جودة مميزة في نتائج البحث:** `rerank_score` (0–3، ≥1.5 جودة عالية) و`authority` (درجة 0–4، −1 غير معروف، ≥3 مصدر عالي السلطة) — قابلة للاستخدام كمرشحات جودة مباشرة في خط أنابيب استرجاع.
- **التسعير:** 0.75 دولار لكل 1,000 طلب ناجح لكل واجهة؛ الطلبات الفاشلة أو بلا نتائج أو المنتهية بالمهلة لا تُحاسب. الاستدعاءات عبر أدوات server-side في DeepSeek Harness وClaude Code وCodex كانت مجانية حتى **1 نوفمبر 2026** (أي: النافذة المجانية تنتهي بعد يومين من كتابة هذا الملف). حدود المعدل المذكورة: 5 QPS للحساب في تقرير، و100 QPS للبحث و25 للجلب في تقرير آخر — **تضارب غير محسوم، تحقق من التوثيق الرسمي قبل الاعتماد**.
- **في نفس اليوم:** تحديث النموذج إلى V4.1-Flash-1017 (MIT على Hugging Face، نافذة سياق 1M token) عبر الاسم المستعار `deepseek-flash` دون خطوة ترحيل — أي مستهلك للاسم المستعار امتصّ التغيير قبل ظهور التوثيق.

## لماذا يهم ACI
- ACI يقارن أدوات تأريض الويب (Exa 3.0 Lite مغطى في 27 أكتوبر). DeepSeek Search مرشح إضافي: سعر منخفض (0.75 دولار/1k)، ودرجات سلطة/إعادة ترتيب جاهزة للترشيح، وجلب Markdown مدمج — لكنه يحتاج مفتاح DeepSeek، وادعاءات جودة المحرك غير متحقق منها، وحدود المعدل متضاربة.
- درس جانبي: التحديث الصامت عبر الاسم المستعار (Flash-1017) مثال على مخاطر تثبيت أسماء النماذج غير المثبتة — ثبّت إصدار النموذج في مهام ACI.

## الإجراء: WATCH
- مرشح تأريض ويب ثانٍ بعد Exa؛ قيّم عند الحاجة بمقارنة جودة على استعلامات ACI بالعربية والإنجليزية، وتحقق من حدود المعدل الرسمية أولًا.
