# DeepSeek تطلق Search & Fetch API بسعر $0.75 لكل ألف طلب (2026-10-17)

## ماذا تغيّر؟

أطلقت DeepSeek — بالتزامن مع تحديث V4.1 Flash في ~17 أكتوبر 2026 — واجهتين جديدتين للوصول إلى الويب من الوكلاء:

- **Search API:** بحث ويب يعيد عناوين/مقتطفات/ملخصات نموذجية — **$0.75 لكل 1,000 طلب ناجح** (الطلبات الفاشلة والمهلات والنتائج الفارغة لا تُحاسَب، وعدد النتائج المطلوبة لا يغيّر السعر).
- **Fetch API:** تحويل أي URL إلى Markdown — نفس السعر $0.75/1k.
- **مجاني مؤقتًا:** الاستدعاءات عبر أدوات الخادم (server tools) في DeepSeek Harness وClaude Code وCodex مجانية **حتى 00:00 بتوقيت بكين في 1 نوفمبر 2026**.
- **الحدود:** 5 طلبات/ثانية لكل حساب (البحث والجلب منفصلان)، حد لكل دومين في الجلب، استعلامات بحد أقصى 128 حرفًا.
- مقارنة الأسعار (أكتوبر 2026): Tavily الأساسي $8/1k، Exa من $4 إلى $12/1k، Brave Search API بـ $5/1k — أي أن DeepSeek أرخص بمرتبة كاملة، لكنه مغلق المصدر والخوادم في الصين، ولا توجد تصريحات SOC 2 / zero-data-retention في الوثائق المقتبسة.

## لماذا يهم ACI؟

- ACI يبني وكلاء بحث ويب (recon agents). تكلفة البحث عبر API هي بند تشغيلي مباشر في كل mission — فرق $0.75 مقابل $5–$8 لكل ألف طلب يغيّر اقتصادية التشغيل على نطاق واسع.
- النافذة المجانية (حتى 1 نوفمبر) فرصة اختبار جودة النتائج والمقتطفات مقابل Exa/Tavily بتكلفة صفر قبل أي التزام.
- التحفظات: الخوادم في الصين (اعتبارات سيادة البيانات لمهام استخباراتية)، وحد 5 QPS لا يناسب أحمال متزامنة عالية، ولا توجد ضمانات علنية للاحتفاظ بالبيانات.
