# NYT تقاضي Brave بسبب Search API — علامة مخاطر قانونية على مصدر مرشح

- **التاريخ:** رُفعت **2026-11-02** (قضيتا SDNY رقم 26-cv-9549 و26-cv-9554).
- **ما الذي تغيّر:** صحيفة نيويورك تايمز (إضافة إلى Daily News وChicago Tribune وOrlando Sentinel في دعوى موازية) **قاضت Brave Software**، واصفة **Brave Search API بأنه «مصدر غير مشروع» لمحتوى محمي بحقوق نشر بلا ترخيص**. الشكاوى تستهدف نقاط نهاية البحث على الويب وبحث الأخبار و**سياق LLM** والإجابات، وتزعم فهرسًا من 30B+ صفحة بناه زاحف غير محدد لا يمكن للناشرين حظره، وتسمي **Anthropic وPerplexity وMistral وxAI وCohere كعملاء دافعين** (لا أحد منهم مدعى عليه). لم ترد Brave علنًا حتى 3 نوفمبر. News Corp رفعت دعوى كشط خاصة ضد Brave في يوليو 2026. أسعار Brave Search API بلا تغيير ($5/1,000 طلب؛ الإجابات $4/1,000 + $5/M رمز).
- **لماذا يهم ACI:** **علامة مخاطر قانونية لا كسر.** Brave مصدر مرشح (لا حالي) لبحث الويب في ACI؛ إن اعتمده ACI، فهذا التقاضي مخاطر سلسلة توريد يجب تسعيرها — حكم سلبي قد يغيّر توفر/تسعير نقطة نهاية سياق LLM التي يريدها ACI أكثر. كما يشير إلى اتجاه التقاضي بين الناشرين وبحث AI عمومًا (NYT قاضت OpenAI وPerplexity أصلًا على ادعاءات مشابهة). لا شيء ينكسر اليوم.
