# بحث ذكاء اصطناعي — Perplexity: تأريض ويب مدفوع لـ Decisions API؛ Computer محلي على Mac وإصدار Teammates؛ Vercel يضيف بحث/جلب DeepSeek (15 نوفمبر 2026)

## 1. Perplexity Decisions API — وضع تأريض ويب مدفوع ($0.001 لكل بحث/جلب)

- **ما الذي تغيّر:** رصد متعقّب تغييرات الوثائق (AI Docs Watch) تغييرًا في صفحة أسعار Perplexity API بين 28 أكتوبر و5 نوفمبر 2026، لم يُغطَّ في ملف أمس: **وضع `web_grounding` جديد في Decisions API** — يفعّل بحثًا سريعًا (Fast Search) واحدًا لكل سؤال قبل الإجابة (حتى 100 سؤال للطلب الواحد)، ويمكنه جلب صفحة من URL أولًا؛ كل بحث وكل جلب ناجح يكلف **$0.001** فوق رموز الإدخال (أي حتى $0.10 بحثًا للطلب الواحد كحد أقصى). الأسئلة التي تنتج استعلام البحث نفسه تشترك في بحث واحد. ويمكن ضبط حد أقصى لعمر الصفحة؛ نسخة مخزنة أقدم تُطلق زحفًا جديدًا. Decisions API يجيب على أسئلة نعم/لا ومتعددة الخيارات ومقيَّمة باحتمالات معايَرة (النموذج pplx-decider-v1.2). ملاحظة تسعير منفصلة رُصدت 14 نوفمبر: **Search API ما زال يُفوتر لكل طلب ناجح** مهما بلغ حجم النص المستخرج ($5/1,000).
- **لماذا يهم ACI:** Decisions API صار مصدر تحقق مؤرَّضًا رخيصًا لمهام ACI: سؤال تحقق واحد مع بحث ويب يكلف أجزاءً من السنت بدل استدعاء بحث كامل + نموذج. سقف $0.10 للطلب الواحد يجعل التكلفة متوقعة. التغيير موثّق في صفحة الأسعار الرسمية نفسها (عبر متعقّب تغييرات الوثائق).
- **المصادر:** https://docswatch.stevetoth.ai/perplexity/api-pricing/2026-11-05/ (رُصد 5 نوفمبر 2026)؛ https://droidsi.net/forum/post/p405z6j376h6h (7 نوفمبر 2026)؛ https://docs.perplexity.ai/changelog
- **الإجراء: watch** — قيّد `web_grounding` كخيار تحقق مؤرَّض رخيص في مهام ACI؛ تحقق من صفحة الأسعار قبل أي اعتماد.

## 2. Perplexity Computer — إصدار 6 نوفمبر: Teammates لـ Max ووضع محلي كامل على Mac

- **ما الذي تغيّر:** في **6 نوفمبر 2026** أصدرت Perplexity دفعة تغييرات لـ **Computer** (وكيلها متعدد الخطوات للتقارير والمستندات والتطبيقات): **Teammates لـ Max**؛ **وضع Computer محلي بالكامل على أجهزة Mac بمعالجات Apple silicon** لـ Pro وMax وEnterprise؛ وحدود أدوار Enterprise على جهد وسرعة Computer. من إصدار 19 أكتوبر المرتبط: **Ultrafast** (إعداد سرعة لنموذجي GPT-6 Astra وGPT-6.1 Sol — لمشتركي Max فقط) و**Gemini 4 Argon في Computer لـ Pro وMax** (في Search ما زال Max فقط). مهام Computer تُفوتر بالرصيد؛ عمليات البحث العادية Ask لا تستهلك رصيدًا. Pro بلا مخصص رصيد شهري — مكافأة لمرة واحدة 4,000 رصيد للجدد تنتهي خلال ~30 يومًا.
- **لماذا يهم ACI:** وضع Computer المحلي على Mac يهم أي تشغيل وكيل بحث على أجهزة محلية (بيانات لا تغادر الجهاز)؛ Teammates وحدود الأدوار تهم الاستخدام الجماعي/المؤسسي. كلها ضمن نافذة الـ30 يومًا ولم تُغطَّ في ملفات الأيام السابقة.
- **المصادر:** https://promptwises.com/news/perplexity-computer-ultrafast-update (محدَّث 7 نوفمبر 2026)
- **الإجراء: watch** — قيّد الوضع المحلي على Mac كخيار تشغيل وكيل بحث حساس؛ لا اعتماد جديد الليلة.

## 3. Vercel AI Gateway — أداتا بحث وجلب DeepSeek (6 نوفمبر 2026)

- **ما الذي تغيّر:** في **6 نوفمبر 2026** أضافت **Vercel AI Gateway** أداتي **DeepSeek Search وDeepSeek Fetch**: البحث يعيد صفحات بعناوين وروابط وملخصات؛ والجلب يسحب محتوى صفحة كـ Markdown ليقرأه النموذج. كلاهما يُفوتر كمكوّنات مترية قابلة للتبديل بين المزوّدين — نفس اتجاه Perplexity أعلاه: البحث والجلب يصيران لبنات بناء رخيصة للوكلاء بدل خدمات متكاملة.
- **لماذا يهم ACI:** مصدر بحث بديل محتمل لمهام ACI عبر بوابة واحدة (تبديل المزوّد دون إعادة بناء)، بأسعار مترية. ذو صلة مباشرة بتوصية 13 نوفمبر (مقارنة محركات البحث للوكلاء: Exa الأكثر موثوقية؛ Brave LLM Context بدل البحث الخام).
- **المصادر:** https://droidsi.net/forum/post/p405z6j376h6h (7 نوفمبر 2026)؛ https://vercel.com/changelog/ai-gateway-adds-deepseek-search-and-fetch-tools
- **الإجراء: watch** — قيّد DeepSeek Search/Fetch كبديل محتمل في مقارنة مصادر البحث؛ تحقق من الأسعار قبل أي اعتماد.

## بلا تغيير آخر

- **You.com:** سجل التغيير الرسمي آخر إدخال فيه **26 أكتوبر 2026** (Inference Router لطلبات متوافقة مع OpenAI/Anthropic مع أداتي `web_search` و`web_extract`) — لا إدخال جديد منذ ذلك الحين. **Genspark:** لا إصدار منتج جديد الليلة (مراجعة مقارنة محدَّثة 15 نوفمبر ليست تغيير منتج). **Perplexity Decisions API v1.3** ما زال الأحدث (أسماء مستعارة تشير إلى v1.3 منذ 13 نوفمبر — مغطى أمس). **Cloudflare AI Search:** فوترتها أُجّلت إلى **1 ديسمبر 2026** (إدخال 2 نوفمبر)؛ D1 كمصدر بيانات (بيتا، 12 نوفمبر) وإدارة النطاقات عبر Terraform (13 نوفمبر) — بلا اعتماد ACI حالي.
- **تذكير: إغلاق Google Custom Search JSON API يقترب** — الإغلاق أمام العملاء الجدد سارٍ؛ العملاء الحاليون يجب أن ينتقلوا قبل **1 يناير 2027**. البدائل: Serper وSerpApi وDataForSEO (نتائج Google) أو Brave وExa وParallel (فهارس مستقلة).
- **جدول أسعار نوفمبر 2026 يقف** (Exa ‏$4–$7/1,000؛ Tavily ~$8/1,000؛ Brave ‏$5/1,000؛ Perplexity Search ‏$5/1,000 والبحث السريع $1/1,000) — أعد التحقق من صفحة الأسعار قبل أي اعتماد جديد.
- **الإجراء: ignore** — لا تغيير بحث ذكاء اصطناعي آخر الليلة.
