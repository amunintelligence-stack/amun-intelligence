# بحث ذكاء اصطناعي — Perplexity Monitor API (16 نوفمبر)؛ Orchestrator API (17 نوفمبر)؛ Brain يولّد مهارات تلقائيًا (18 نوفمبر)؛ Genspark TeamBrain (5 نوفمبر) (18 نوفمبر 2026)

## ⭐ 1. Perplexity Monitor API — مراقبة مواضيع وصفحات مجدولة عبر Webhook بسعر $1 لكل 1,000 تشغيل (16 نوفمبر 2026)

- **ما الذي تغيّر:** أطلقت Perplexity في **16 نوفمبر 2026** واجهة **Monitor API** الجديدة: مراقبة ويب مُدارة بالكامل تحل محل سكربتات الاستطلاع المخصصة:
  - **نوعان:** مراقب بحث (Search monitor) — استعلام واحد يجد نتائج ويب وأخبار جديدة عن موضوع/شركة/سؤال؛ ومراقب صفحة (Page monitor) — يراقب حتى 10 روابط معروفة ويعيد فروق نص حتى 24 KiB بعد خط أساس أولي.
  - **التصفية:** نموذج **Perplexity Decider** يقيّم كل نتيجة/تغيير جديد مقابل هدف مراقبة مكتوب بلغة طبيعية («تغيرات في أسعار المؤسسات») ويمرّر ذا الصلة فقط — لا ضجيج.
  - **الجدولة والتسليم:** كل 15 دقيقة، كل ساعة، يوميًا، أسبوعيًا، أو cron مخصص، أو عند الطلب؛ التسليم عبر **webhook موقّع v1** مع إعادة محاولة، أو قراءة نتائج التشغيل عبر API. سجل التشغيل يُحتفظ به **90 يومًا**.
  - **السعر:** **$1 لكل 1,000 تشغيل بحث ناجح** ($0.001 للتشغيل) و$1 لكل 1,000 رابط يُجلب في مراقب الصفحة — أي مراقب موضوع كل ساعة يكلف **~$0.72/شهر**. نفس مفتاح API لواجهات Search وContext وAgent؛ بلا رسوم توجيه.
  - **قيود:** استعلام حتى 1,000 حرف، حتى 20 نتيجة، وفلاتر نطاقات include/exclude حتى 20 مضيفًا. **المنظمات التي تتطلب احتفاظًا صفريًا بالبيانات لا يمكنها إنشاء مراقبات أو تشغيلها** — قيد مادي لبيئات صارمة.
  - تقول Perplexity إن Monitor قدّم أحدث النتائج وأكثرها صلة عبر أوسع نطاق مواضيع في تقييم 8 ساعات مقابل موفري بحث آخرين.
- **لماذا يهم ACI:**‏ هذا أقرب ما ظهر حتى الآن إلى **«مراقب استخباري دائم» جاهز**: مراقب لكل شركة/شخص/موضوع هدف يرسل تغييرات مصفاة عبر webhook إلى ACI — بتكلفة زهيدة (~$0.72/شهر للمراقب الساعي) وبلا سكربتات استطلاع أو إدارة حالة أو إزالة ازدواج (كلها مدمجة). يلائم بوابة المراقبة المستمرة في ACI مباشرة، ويتكامل مع Decider (المغطى 17 نوفمبر) كطبقة تصفية.
- **المصادر:** https://www.perplexity.ai/hub/blog/introducing-perplexitys-monitor-api (16 نوفمبر 2026، مصدر أولي)؛ https://www.unite.ai/perplexity-launches-monitor-api-to-automate-web-change-detection/ (16 نوفمبر 2026)؛ https://fourweekmba.com/ai-perplexity-monitor-tracks-a-topic-hourly-for-072-a-month/ (17 نوفمبر 2026)؛ https://docs.perplexity.ai (التوثيق)
- **الإجراء: adopt** — قيّم Monitor API في مهمة تجريبية: مراقب بحث واحد لشركة هدف + مراقب صفحة لصفحة هدف، عبر webhook إلى نقطة استقبال ACI؛ وثّق التكلفة الفعلية وجودة التصفية قبل التوسع. انتبه لقيد الاحتفاظ الصفري إن كانت البيانات حساسة.

## 2. Perplexity Orchestrator API — بوابة نماذج موحدة: 45+ نموذجًا، مفتاح واحد، وفشل تلقائي لنفس النموذج (17 نوفمبر 2026)

- **ما الذي تغيّر:** أطلقت Perplexity في **17 نوفمبر 2026** واجهة **Orchestrator API** (معاينة خاصة منذ 9 نوفمبر؛ كانت Gateway API في أغسطس ثم Router API):
  - **45+ نموذجًا** من Anthropic وOpenAI وGoogle وxAI وZ.AI وDeepSeek وMoonshot AI خلف نقطة نهاية واحدة `https://api.perplexity.ai/orchestrator/v1` ومفتاح Perplexity API نفسه، بفوترة موحدة وبلا رسوم توجيه.
  - **توجيه مزود تلقائي:** بعد اختيار النموذج، توزّع المنصة الحركة بين نشراته حسب معدلات الخطأ والسعة وزمن الاستجابة؛ وعند فشل مزود أو حد معدل أو مهلة، **تُعاد المحاولة على نشرة أخرى لنفس النموذج** (مثلًا طلب Claude من Anthropic ينتقل إلى AWS Bedrock ويبقى Claude) — دون تغيير النموذج المُجيب.
  - **توجيه نموذج اختياري (معاينة):** `perplexity/auto` يستدعي نموذج قرار يختار النموذج لكل طلب من وصف مهام بلغة طبيعية (نموذج افتراضي + 1–5 مسارات)؛ كل طلب يُوجَّه مستقلًا، فمحادثة واحدة قد تستخدم نماذج مختلفة بين الأدوار.
  - **توافق:** يقبل صيغ OpenAI Chat Completions وResponses وAnthropic Messages — نفس SDK مع تغيير المفتاح والعنوان ومعرّف النموذج. الفوترة حسب النموذج المُجيب بأسعاره المنشورة. بلا حالة (stateless): كل طلب يحمل المحادثة كاملة.
  - **الطبقات:** نماذج Google وxAI والمفتوحة الأوزان متاحة في كل الطبقات؛ OpenAI وAnthropic تتطلب الطبقة 1+؛ وClaude Opus 5/5.5 وFable تتطلب الطبقة 2+. مثال سعر: GLM-5.3 Flash ‏$0.15 إدخال / $0.50 إخراج لكل مليون رمز.
  - تقول Perplexity إن طلبات Claude وGPT عبر Orchestrator (4 أكتوبر–2 نوفمبر) نجحت أكثر من أي مزود منفرد قاسته، مع تقلبات يومية أقل أثناء الأعطال (نتائج الشركة نفسها).
- **لماذا يهم ACI:**‏ بوابة واحدة بمفتاح واحد وفشل تلقائي تحل مشكلة موثوقية استدعاءات النماذج في مهام ACI الطويلة (لا كود توجيه مخصص، ولا تبديل مزود يدوي عند الأعطال)، وتفتح نماذج مفتوحة الأوزان مستضافة (Kimi K3، GLM 5.3، DeepSeek) بأسعار منخفضة. `perplexity/auto` مرشح مستقبلي لتوجيه مهام ACI (تصنيف رخيص مقابل تحليل عميق) لكنه ما زال معاينة.
- **المصادر:** https://www.unite.ai/perplexity-launches-orchestrator-api-with-same-model-failover/ (17 نوفمبر 2026)؛ https://docs.perplexity.ai/docs/orchestrator/routing-and-reliability (محدّث 17 نوفمبر 2026)؛ https://cryptobriefing.com/perplexity-launches-orchestrator-api/ (17 نوفمبر 2026)
- **الإجراء: watch** — قيّم Orchestrator كبديل لبوابة النماذج في ACI في مهمة تجريبية (فشل تلقائي + فوترة موحدة)؛ لا تعتمد على `perplexity/auto` قبل خروجه من المعاينة.

## 3. Perplexity Brain — توليد وتحديث مهارات وكيل شخصية تلقائيًا من الخبرة (18 نوفمبر 2026، اليوم)

- **ما الذي تغيّر:** أعلنت Perplexity اليوم **18 نوفمبر 2026** أن **Brain** (نظام تخصيص وكيل Computer) يستطيع الآن **إنشاء مهارات قابلة لإعادة الاستخدام وتحديثها تلقائيًا** من خبرة الاستخدام: كتب Brain أكثر من **80,000 مهارة شخصية لأكثر من 20,000 مستخدم** (1 أغسطس–14 نوفمبر 2026)، وأجرى +100,000 تحديث تلقائي لأكثر من 30,000 مهارة موجودة (4 سبتمبر–14 نوفمبر). في اختبار إنتاج عشوائي 8 أسابيع: 72.9% من المستخدمين مع التحسين التلقائي حصلوا على مهارة جديدة واحدة على الأقل مقابل 6.5% في المجموعة الضابطة. وفي تجربة SkillLearnBench: نجاح المهام ارتفع من 43.8% بلا مهارات إلى 62.5% بمهارات مولّدة. **متاح لمشتركي Max في الولايات المتحدة**؛ وتخطط Perplexity لتوسيعه إلى مهارات يكتبها المستخدم ومهارات مشتركة داخل مشاريع ومهارات منظمات.
- **لماذا يهم ACI:**‏ مرجع نمطي مباشر: «مهارات تتعلم من الخبرة» هي نفس فكرة ذاكرة مهارات ACI — Perplexity تثبت أن التوليد التلقائي للمهارات يرفع نجاح المهام ~19 نقطة مئوية. ليس منتجًا يُعتمد (Max، أمريكا فقط)، لكنه دليل تجريبي يقوّي حجة بناء طبقة مهارات متعلمة في ACI.
- **المصادر:** https://www.unite.ai/perplexity-brain-creates-and-updates-agent-skills-from-experience/ (18 نوفمبر 2026)
- **الإجراء: watch** — مرجع نمطي فقط؛ سجّل أرقام SkillLearnBench (43.8% ← 62.5%) في ملاحظات تصميم ذاكرة المهارات.

## 4. Perplexity — إيراد سنوي يتجاوز $1 مليار؛ وطرح عام محتمل في الربع الأول 2027 (16–17 نوفمبر 2026)

## 5. Genspark — TeamBrain للمعرفة المؤسسية (5 نوفمبر)؛ وشراكة KDDI Biz Edge للجوال (5 نوفمبر؛ المبيعات يناير 2027)

- **ما الذي تغيّر:** (لحاق بفائت من 5 نوفمبر لم يُغطَّ سابقًا): أطلقت Genspark **TeamBrain** في **5 نوفمبر 2026** لعملاء خطة المؤسسات — منصة معرفة تجمع بيانات المنظمة المبعثرة (مستندات، بريد، ملاحظات اجتماعات، محادثات) في حوض أصول مشترك تستفيد منه وكلاء الذكاء الاصطناعي. وفي اليوم نفسه أعلنت شراكة مع **KDDI Biz Edge** (ذراع الأعمال لـ KDDI اليابانية) لخدمة **Mobile Work AI** — تنفيذ مهام عمل من الهاتف عبر وكلاء Genspark؛ تبدأ المبيعات في **يناير 2027**. وفي السياق: «الدردشة غير المحدودة» للمشتركين القدامى تنتهي **31 ديسمبر 2026**؛ ومن 1 يناير 2027 النماذج الأساسية حتى سقف والرائدة بالأرصدة.
- **لماذا يهم ACI:**‏ TeamBrain نمط منافس لـ RAG المؤسسي في ACI (حوض معرفة مشترك للوكلاء) — يستحق المقارنة عند تقييم طبقة المعرفة. وشراكة KDDI إشارة إلى أن Genspark يتجه للتوزيع المؤسسي الياباني لا لأدوات البحث وحدها.
