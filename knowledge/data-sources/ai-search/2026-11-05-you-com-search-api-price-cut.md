# You.com — خفض أسعار واجهة البحث (19 أكتوبر 2026)

- **التاريخ:** **2026-10-19** (ساري فورًا؛ الاستخدام منذ 12 مارس 2026 يُفوتر بالأسعار الجديدة حسب المنشور).
- **ما الذي تغيّر:** خفّضت You.com **واجهة بحث الويب إلى $5/1,000 استدعاء ثابتة** (كانت $6.25 لـ 1–50 نتيجة، $8 لـ 50–100) مقابل **حتى 100 نتيجة لكل استدعاء، كل منها بمحتوى الصفحة الكامل مضمّنًا** — بحث + استخراج في استدعاء واحد. **واجهة المحتويات خُفّضت إلى $1/1,000 صفحة** (كانت $10). المستوى المجاني: **100 استعلام/يوم عبر MCP، بلا مفتاح API**. أسعار واجهة البحث بلا تغيير ($12–$1,200/1,000 حسب العمق)؛ اعتماد تسجيل $100 ($10 + $90 بعد التحقق).
- **لماذا يهم ACI:** عند $5/1k مع 100 نتيجة + محتوى كامل لكل استدعاء، أصبحت You.com منافسة سعريًا مع Brave/Perplexity لطبقة بحث الويب في ACI، والمستوى المجاني عبر MCP بلا مفتاح يسمح بتجربة بلا تكلفة. تستحق المقارنة مع Exa ($4–7/1k، 10 نتائج بنص) لجودة استرجاع المهام.
- **المصادر:** https://you.com/resources/lower-search-api-cost (نُشر 2026-10-19) — https://exa.ai/alternatives/you-com-api (حُدّث 19 أكتوبر 2026) — https://costbench.com/software/ai-chatbots/you/
- **الإجراء: watch** (قارن مع Exa/Perplexity على استعلامات بأسلوب ACI قبل أي تبديل)
- **السجل:** أضف `you-com-search-api` — نوع ai-search، الحالة watch، يحتاج مفتاحًا (مجاني 100/يوم عبر MCP بلا مفتاح) — «بحث ويب $5/1k، حتى 100 نتيجة بمحتوى كامل؛ محتويات $1/1k صفحة؛ خفض سعر 19 أكتوبر 2026»
