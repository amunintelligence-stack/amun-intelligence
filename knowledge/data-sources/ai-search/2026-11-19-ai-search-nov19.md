# بحث ذكاء اصطناعي — Perplexity Decider v1.3 (12 نوفمبر): نماذج قرار مفتوحة الأوزان تستخرج نصًا حرفيًا؛ Multiagent وContext API في 17 نوفمبر؛ Genspark وYou.com بلا جديد (19 نوفمبر 2026)

## ⭐ 1. Perplexity Decider v1.3 (12 نوفمبر 2026) — نماذج قرار مفتوحة الأوزان (Apache 2.0) مع استخراج نص حرفي

- **ما الذي تغيّر:** أصدرت Perplexity في **12 نوفمبر 2026** نموذجَي قرار مفتوحَي الأوزان تحت رخصة **Apache 2.0**: **pplx-decider-v1.3** (مبني على Qwen3.8-27B، ~49GB للأوزان BF16) و**pplx-decider-flash-v1.3** (مبني على Qwen3.5-4B). ليست روبوتات محادثة: تجيب بـنعم/لا واختيار متعدد وتقييم **باحتمالات** بدل جمل، والجديد في v1.3 نوع أسئلة **locate** يستخرج **مقاطع نصية حرفية** (أسماء، رموز خطأ) مع مواضعها الدقيقة (حتى 128 سؤال locate لكل طلب). متاحة على Hugging Face وعبر OpenRouter وواجهة Decisions API من Perplexity. وتستخدمها Perplexity نفسها لمراجعة سجلات أمن وكلاء الذكاء الاصطناعي.
- **لماذا يهم ACI:**‏ أقوى مرشح تقني الليلة: نموذج قرار مفتوح الأوزان قابل للاستضافة الذاتية يحوّل **التحقق من الأدلة** (هل يدعم النص الادعاء؟ ما الاسم/الرمز الحرفي؟) إلى احتمالات ومواضع دقيقة — يناسب مباشرة طبقة التحقق من الأدلة في ACI ومراجعة السجلات. الحجم (49GB للكبير) يعني أن Flash-4B هو المرشح العملي للتجربة المحلية.
- **المصادر:** https://tokenstrom.com/posts/perplexity-decider-v1-3-open-weight-models-that-make-decisions-instead/؛ https://www.scriptbyai.com/perplexity-ai-timeline/ (12 نوفمبر 2026)
- **الإجراء: watch** — أضِف إلى السجل كمرشح تقني: جرّب Flash محليًا على مهمة تحقق (ادعاء ← نص الدليل) وقارن دقته مع الحكم بالنموذج الحالي قبل أي اعتماد.

## 2. Perplexity Computer Multiagent + Context API (17 نوفمبر) — مغطى في ملف الأطر؛ التذكير هنا لمصدر البيانات

- **ما الذي تغيّر:** في 17 نوفمبر: **Multiagent** (وكيل قائد + حتى 16 وكيلًا على نماذج منافسة، لمشتركي Max) و**Context API** (استرجاع حتى 10 روابط لكل طلب، يعيد Markdown نظيفًا وروابط ومقاطع ذات صلة، مع تحكم في حداثة النسخة المخزنة أو طلب جلب حي).
- **لماذا يهم ACI:**‏ Context API نمط استرجاع ويب نظيف يمكن استعارته لخطوة «اجلب الصفحة ونظّفها» في مهام ACI؛ وMultiagent مغطى بالتفصيل في ملف multi-agent الليلة.
- **المصادر:** https://www.scriptbyai.com/perplexity-ai-timeline/ (17 نوفمبر 2026)
- **الإجراء: watch** — لا اعتماد منتج (Max $200/شهر)؛ استعِر نمط Context API عند تصميم جالب الصفحات.

## 3. Perplexity Frontier Research (16 نوفمبر) — مبادرة بحث لبناء عالم آلي

- **ما الذي تغيّر:** أطلقت Perplexity في 16 نوفمبر **Frontier Research** بقيادة Andrew Gordon Wilson: مبادرة لتطوير خوارزميات وتقييمات لأنظمة ذكاء اصطناعي تنفذ بحثًا علميًا ذاتيًا.
- **لماذا يهم ACI:**‏ مبادرة بحثية لا منتج؛ قيمتها كمصدر مستقبلي لمنهجيات بحث ذاتي يمكن استعارتها في مهام ACI الطويلة.
- **المصادر:** https://i10x.ai/news/company/perplexity
- **الإجراء: watch** — راقب مخرجاتها (أوراق/تقييمات) لا المبادرة نفسها.
