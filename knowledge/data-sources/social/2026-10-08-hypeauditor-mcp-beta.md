# HypeAuditor أطلقت خادم MCP (مجاني أثناء البيتا، سبتمبر 2026)؛ Semrush تحت Adobe بسلّم أسعار جديد حول AI-search

- التاريخ: 2026-10-08 | الفئة: data-sources/social | الإجراء: **مراقبة (watch)**

## ما الذي تغيّر
مقارنة MCPs للتسويق بالمؤثرين (سبتمبر 2026) تُدرج خادم HypeAuditor MCP (أكثر من 220M ملف شخصي، 3 منصات، 6 أدوات + 12 workflow، بيانات جمهور) كخدمة ذاتية مجانية أثناء البيتا، بجانب Influencers.club وModash وMeltwater وFavikon. لا تغييرات breaking معلنة من HypeAuditor/Modash/Social Blade في النافذة. separately: Semrush (استحوذت عليها Adobe في 2026-04-28) طرحت سلّم أسعار جديدًا مبنيًا حول رؤية AI-search في أكتوبر 2026 (Free / SEO بـ $139 / Starter "Semrush One" بـ $199 مع وصول MCP / Pro+ بـ $299 / Advanced بـ $549)؛ الوصول للـ API ما زال محصورًا بطبقة Advanced ($549/شهر)؛ وأطلقت Semrush موصل Claude رسميًا في 2026-08-26.

## لماذا يهم ACI
خادم HypeAuditor MCP يمنح ACI مسارًا قابلًا للاستدعاء من الوكيل لبيانات صناع المحتوى/الجمهور دون خطة $299/شهر — يتماشى مع اتجاه MCP الذي نتتبعه. موصل Claude من Semrush سطح بيانات حية جديد، لكن الـ API يبقى مؤسسيًا فموصل Semrush لدينا يبقى stub حتى توفر مفتاح.
