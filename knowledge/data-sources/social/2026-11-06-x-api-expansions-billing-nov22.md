# X API — فوترة التوسعات (expansions) تبدأ 22 نوفمبر 2026؛ التكلفة تتضاعف ~3.4×

## ما الذي يتغيّر في 22 نوفمبر 2026
- **ما الذي تغيّر:** أعلنت X في منتدى المطوّرين في **23 أكتوبر 2026** أن الكائنات المُعادة عبر **expansions** (المؤلف، المنشور المقتبس/المردود عليه، الوسائط، الاستطلاعات، الأماكن) ستبدأ في احتساب فوترة الدفع-حسب-الاستخدام في **22 نوفمبر 2026** — حتى ذلك التاريخ تركب مجانًا. بعدها كل كائن موسَّع يُفوتر بسعر المورد القياسي نفسه كاستدعاء مباشر: قراءة منشور $0.005، قراءة مستخدم $0.010. مثال موثّق: صفحة بحث من 100 منشور مع التوسعات الكاملة تكلف $0.50 اليوم و~**$1.72 من 22 نوفمبر** (3.4×)؛ سيناريو شهري ثقيل قُدّر بـ $5,145 بدل ~$1,500. الأسعار نفسها لا تتغير — فقط ما يُفوتر.
- **لماذا يهم ACI:** أي مهمة تسحب منشورات X مع توسعات المؤلف/الاقتباس ستدفع ~3.4× أكثر بعد 22 نوفمبر إن استخدمت X API الرسمي مباشرة. قلّل التوسعات إلى الضروري (author_id فقط عند الحاجة)، أو قيّم مجمّعات طرف ثالث (مثال موثّق: ~$0.15 لكل 1,000 تغريدة عبر TwitterAPI.io — مورّد غير متحقق منه مستقلًا، قيّمه قبل أي اعتماد).
- **المصادر:** https://www.twitterapis.com/blogs/x-api-expansions-billing-2026 — https://futuretweets.com/x-api-expansions-billing-change-2026/
- **الإجراء: watch** — قبل 22 نوفمبر: دقّق أي استدعاءات X API في مهام ACI وقلّص التوسعات؛ لا اعتماد على مجمّع طرف ثالث دون تقييم.

## سياق: X API v2 دفع-حسب-الاستخدام بالكامل (أكتوبر 2026)
- **ما الذي تغيّر:** وثائق X (حُدّثت 22 أكتوبر، أُعيد تأكيدها 2 نوفمبر) تصف X API v2 على أرصدة دفع-حسب-الاستخدام بلا اشتراكات ولا حد أدنى للإنفاق؛ سقف شهري 3M قراءة منشور، وبعده Enterprise. **X Activity API (XAA)** يحل رسميًا محل Account Activity API للنشاط الفوري (webhooks، فوترة لكل حدث). **Powerstream** (21–22 أكتوبر) بث عام بأدنى زمن استجابة. نقاط نهاية Articles حُدّثت 2 نوفمبر (إنشاء مسودات بمحتوى غني). لا طبقة مجانية فعلية للاستدعاءات الحقيقية (رصيد $20 لمرة واحدة عند أول بطاقة + مطابقة أول شحن تلقائي حتى $50).
- **لماذا يهم ACI:** المراقبة الاجتماعية عبر X الرسمي مدفوعة بالكامل الآن — ضع ميزانية لكل مهمة تسحب X؛ بدائل التجريف الذاتي (twscrape وغيرها) انكسرت مرارًا في أكتوبر–نوفمبر 2026 وتحتاج حسابات حقيقية.
