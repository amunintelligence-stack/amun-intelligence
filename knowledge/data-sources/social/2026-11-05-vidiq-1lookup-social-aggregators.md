# vidIQ يتوسع خارج YouTube و1Lookup — مجمّعات اجتماعية جديدة

## vidIQ يتوسع إلى Instagram AI Coach وبحث TikTok الشاذ
- **التاريخ:** 2026 (مُبلَّغ عنه حاليًا حتى أكتوبر–نوفمبر 2026).
- **ما الذي تغيّر:** vidIQ لم يعد YouTube فقط: **Instagram AI Coach** (أضف مقبضًا عامًا، يراقب أحدث 6 Reels، يقيّم على إطار من 5 أجزاء) و**بحث TikTok الشاذ عبر MCP** مباشران، على كل الخطط بما فيها المجانية (150 اعتمادًا/شهر). الجانب Instagram هو Reels فقط، حسابات عامة فقط. (موصل vidIQ Claude نفسه غُطي في 4 نوفمبر — هذا توسع المنصة.)
- **لماذا يهم ACI:** vidIQ يصبح مصدر استخبارات منشئين رخيصًا عبر المنصات (كشف Reels/TikTok الشاذ) لمهام اجتماعية، بلا مفتاح API للاستخدام الأساسي.
- **المصدر:** https://www.bukcil.com/prep/vidiq-alternative-instagram.html
- **الإجراء: watch**

## 1Lookup — مجمّع API اجتماعي جديد
- **التاريخ:** حالي حتى أغسطس–أكتوبر 2026 (بلا تاريخ إطلاق واحد وُجد).
- **ما الذي تغيّر:** **1Lookup** مجمّع أحدث يعتمد API أولًا: فحوص ملفات على **10 شبكات** (منها X وLinkedIn وThreads وBluesky وReddit وPinterest — كلها غائبة عن API الخاص بـ Social Blade)، إضافة إلى بحث المنشورات و**نصوص الفيديو** و**بحث مكتبة الإعلانات** بمفتاح واحد. اعتمادات مدفوعة مسبقًا، حد أدنى $50 (100 اعتماد). يتموضع كأرخص لكل فحص ملف من حزم Social Blade API.
- **لماذا يهم ACI:** مصدر مفتاح واحد يغطي ملفات اجتماعية + نصوص + بحث مكتبة إعلانات قد يبسّط طبقة البيانات الاجتماعية في ACI — لكنه مورّد صغير شاب؛ الدقة والموقف من شروط الخدمة غير متحقق منهما.
- **المصدر:** https://www.1lookup.io/alternatives/social-blade (أسعار متحقق منها أغسطس 2026)
- **الإجراء: watch**
- **السجل:** أضف `1lookup` — نوع social-aggregator، الحالة watch، يحتاج مفتاحًا — «API لملفات/منشورات/نصوص/مكتبة إعلانات على 10 شبكات؛ مدفوع مسبقًا بحد أدنى $50؛ مورّد شاب، دقة غير متحقق منها».

## لا جديد في social/
- **Social Blade وHypeAuditor وModash:** بلا إصدارات منتجات أو تغييرات API أو أسعار جديدة في آخر 30 يومًا (مقالات جولات/مقارنات فقط). Modash Essentials ما زال $299/شهر شهريًا / $199 سنويًا؛ HypeAuditor فحوص مجانية + مدفوعة.
- **Reddit:** إغلاق RSS في 13 نوفمبر غُطي في 3 نوفمبر؛ بلا أخبار Reddit API أخرى.
