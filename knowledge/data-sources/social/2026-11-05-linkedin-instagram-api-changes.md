# تغييرات واجهات LinkedIn وInstagram — نوفمبر 2026

## LinkedIn Marketing API — الإصدار 202511 يُغلق في 16 نوفمبر 2026
- **التاريخ:** الإغلاق **2026-11-16** (أُعلن في إصدار أكتوبر 2026).
- **ما الذي تغيّر:** إصدار LinkedIn Marketing API ‏202511‏ يُغلق في 2026-11-16؛ الاستدعاءات التي تسميه تعيد أخطاء. أحدث إصدار هو **202610** (أكتوبر 2026). أيضًا: نافذة ترحيل قوائم الناشرين تنتهي 2026-12-15 (يمكن للحملات بعدها استخدام قوائم يتطابق سطح وضعها مع LAN/CTV فقط). Company Intelligence API يبقى مغلقًا أمام المتقدمين الجدد.
- **لماذا يهم ACI:** أي جمع بيانات إعلانات/شركات LinkedIn يجب أن يثبّت `Linkedin-Version: 202610` (أو أحدث) — إصدار مثبَّت قديم ينكسر بصمت في 16 نوفمبر. ذو صلة بمسار مكتبة إعلانات LinkedIn/استخبارات الإعلانات المتتبَّع أصلًا.
- **المصادر:** https://learn.microsoft.com/en-us/linkedin/marketing/versioning?view=li-lms-2026-10 — https://learn.microsoft.com/en-us/linkedin/marketing/integrations/recent-changes?view=li-lms-2026-10
- **الإجراء: watch** (ثبّت الإصدار 202610 في أي موصل LinkedIn؛ بلا قدرة جديدة)

## Instagram Graph API — تطبيق أكثر صرامة لصيغة حد معدل حالة الاستخدام التجاري (2026)
- **التاريخ:** 2026 (بلا تغيير واحد مؤرخ؛ تشديد تطبيق مُبلَّغ عنه عبر 2026).
- **ما الذي تغيّر:** Instagram Basic Display API ميت تمامًا (منذ 4 ديسمبر 2024)؛ المسار الرسمي الوحيد هو **Instagram Graph API** لحسابات الأعمال/المنشئين. في 2026 تفرض Meta **صيغة حد المعدل لحالة الاستخدام التجاري (4,800 × مرات الظهور / 24 ساعة)** بصرامة أكبر — الحسابات منخفضة مرات الظهور تصل الحدود sooner. بلا بثوث هاشتاغ عامة أو ملفات منافسين أو قوائم متابعين أو اكتشاف واسع عبر الواجهات الرسمية.
- **لماذا يهم ACI:** يؤكد أن جمع استخبارات منافسي Instagram لا يمكن أن يعتمد على الواجهات الرسمية — فقط حساباتك المصرَّح بها، أو أدوات بيانات عامة. أي تصميم استخبارات Instagram يجب أن يفترض الكشط/مجمّعات الطرف الثالث، مع مخاطرها القانونية/شروط الخدمة.
- **المصادر:** https://agentsapis.com/instagram-api/ — https://storrito.com/resources/instagram-api-2026/
- **الإجراء: watch**
