# اجتماعي — YouTube: عدّ مشاهدات التلفاز المشتركة من 16 نوفمبر + Posts API تجريبي؛ Reddit ينهي API العام في مارس 2027؛ X: فوترة التوسعات تبدأ 22 نوفمبر (19 نوفمبر 2026)

## 1. YouTube — ثلاثة تغييرات دخلت حيز التنفيذ في 16 نوفمبر 2026

- **ما الذي تغيّر:** حسب سجل تغييرات API الاجتماعية:
  - **YouTube يعدّ مشاهدات التلفاز المشتركة (TV co-views) في أعداد المشاهدات العامة من 16 نوفمبر 2026** — تغيير كاسر لأي مقارنة تاريخية لأعداد المشاهدات.
  - **عمليات الرفع لم تعد افتراضيًا «بلا وضع منتج مدفوع»** من 16 نوفمبر — يؤثر على بيانات الإفصاح عن الإعلانات في الفيديوهات.
  - **YouTube Data API تضيف مورد posts** (منشورات نصية وصورية) — شركاء تجريبيون فقط حاليًا.
  - سابقًا في نوفمبر: **Studio Analytics أصبح Insights** مع ملخصات بلغة بسيطة في 13 نوفمبر، وتبويب Trends أصبح Research (فيديوهات شاذة تتفوق على متوسط قناتها)؛ و**صور مصغرة مخصصة لـShorts عبر API** في 3 نوفمبر؛ ورفع قاعدة «خاص فقط» للمشاريع غير الموثقة في 2 نوفمبر.
- **لماذا يهم ACI:**‏ أعداد مشاهدات YouTube قبل/بعد 16 نوفمبر **غير قابلة للمقارنة مباشرة** — أي تحليل اتجاهات لقناة منافسة يجب أن يضع خطًا فاصلًا عند هذا التاريخ. مورد posts التجريبي يفتح لاحقًا مصدر منشورات نصية للمراقبة.
- **المصادر:** https://schedulesocialmedia.com/api-changes/ (فُحص 19 نوفمبر 2026)؛ https://blog.karata.world/page/2/
- **الإجراء: watch** — ضع خطًا فاصلًا 16 نوفمبر في أي سلسلة مشاهدات YouTube؛ راقب تعميم posts API.

## 2. Reddit — الوصول العام إلى API ينتهي في مارس 2027

- **ما الذي تغيّر:** أوقف Reddit قبول طلبات API العامة الجديدة في **31 أكتوبر 2026**، والوصول العام المتبقي **ينتهي في مارس 2027**.
- **لماذا يهم ACI:**‏ يغلق مصدرًا اجتماعيًا مفتوحًا لمراقبة المجتمعات والمناقشات حول الشركات؛ أي جامع Reddit مستقبلي يحتاج وصولًا مدفوعًا أو وسيطًا.
- **المصادر:** https://sociality.io/blog/social-media-apis/ (فُحص 15 نوفمبر 2026)
- **الإجراء: watch** — سجّل الموعد النهائي مارس 2027 (مغطى أيضًا في ملف OSINT الليلة).

## 3. LinkedIn — تحليلات منشئين جديدة + Boost API؛ وX وInstagram وBluesky

- **ما الذي تغيّر:**
  - **LinkedIn**: تحليلات منشئين جديدة — جدول أداء المنشورات (مرات الظهور والمشاهدات ووقت المشاهدة لكل منشور)، والمتابعون الذين جلبهم كل منشور، والحفظ والإرسال، والوصول داخل الشبكة مقابل خارجها. و**LinkedIn Boost API 202611** (استهداف مخصص، إدارة تعزيز، فوترة مستضافة)؛ وإصدار Marketing API 202511 انتهى في 16 نوفمبر.
  - **X**: فوترة التوسعات تبدأ **22 نوفمبر** (بعد 3 أيام — مغطى أمس)؛ وأداة قصّ أصلية تتيح لأي شخص قصّ مقطع من فيديو أطول مع رابط للفيديو الأصلي؛ ومسارات Livestream API للمستخدم تُزال في **1 يناير 2027**.
  - **Instagram**: أغلق تبويب «الأخيرة» للهاشتاغ في 10 نوفمبر (بحث `type=recent` يعيد الآن نفس الخلاصة المرتبة)؛ وحماية محتوى جديدة تبحث عن نسخ من فيديوهات المنشئين على Instagram وFacebook.
  - **Bluesky**: مساحات AT Protocol في ألفا، والبيتا العامة في **1 ديسمبر 2026**.
- **لماذا يهم ACI:**‏ تحليلات LinkedIn الجديدة (الحفظ/الإرسال/داخل مقابل خارج الشبكة) مقاييس تفاعل أدق لتقييم حضور تنفيذي/شركة؛ وتغييرات X/Instagram تؤثر على أدوات المراقبة الاجتماعية (SocialCrawl وغيره).
- **المصادر:** https://www.stellarmediamarketing.com/post/stellar-weekly-digest-november-6-2026؛ https://schedulesocialmedia.com/api-changes/؛ https://blog.karata.world/page/2/
- **الإجراء: watch** — لا إطلاق منتج جديد من Social Blade أو HypeAuditor أو Modash أو VidIQ الليلة.

## بلا تغيير — تحقق الليلة

- **Social Blade / HypeAuditor / Modash / VidIQ**: بلا إطلاقات منتج جديدة؛ مراجعات أسعار نوفمبر فقط.
