# X API — التوسعات تُفوتر اعتبارًا من 22 نوفمبر 2026 (~3.4× للمكالمات الثقيلة بالتوسعات)

- **التاريخ:** أُعلن 2026-10-23، ساري **2026-11-22**.
- **ما الذي تغيّر:** توسعات X API (`includes.users` و`includes.tweets` والوسائط والاستطلاعات والأماكن) ستُفوتر الآن **لكل كائن موسّع** بالأسعار القياسية للدفع حسب الاستخدام (قراءة منشور $0.005، قراءة مستخدم $0.010). سابقًا كانت التوسعات مجانية. مثال عملي: صفحة بحث من 100 منشور مع توسعات المؤلف + المنشورات المرجعية تنتقل من ~$0.50 إلى ~$1.72 (**~3.4×**). أسعار كل مورد نفسها بلا تغيير؛ سقف الخدمة الذاتية يبقى 3M قراءة منشور/شهر، ثم Enterprise.
- **لماذا يهم ACI:** أي استماع اجتماعي مستقبلي عبر X/Twitter بالواجهة الرسمية يصبح أغلى ماديًا بالضبط عندما يستخدم ACI التوسعات (ملفات المؤلفين + المنشورات المقتبسة هي حمولة الاستخبارات). ضع ميزانية أي جمع X عند ~3× التقدير القديم؛ بائعو الطرف الثالث يبدون الآن أرخص بالمقارنة.
