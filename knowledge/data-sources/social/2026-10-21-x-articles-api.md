# X تطلق Articles API (3 أكتوبر 2026) — نشر طويل بدون جدولة

**Date found:** 2026-10-21 (nightly dev researcher)

## What changed
أطلقت X نقاط نهاية **Articles API** في **3 أكتوبر 2026** (بحسب سجل تغييرات X API، بتغطية FutureTweets):
- إنشاء مسودة + نشر فوري بالأمر؛ **لا معامل جدولة ولا طابور** — من يحتاج النشر الموقوت يبني مجدولًا خارجيًا.
- متاح لأي مشترك **X Premium** (وُسّع من Premium+ فقط في يناير 2026).
- الحد ~**100,000 حرف** للمقال (تقدير متتبعين خارجيين — X لم تنشر رقمًا رسميًا، فيُعامل كأفضل تقدير حالي لا مواصفة).
- يرث تسعير الدفع حسب الاستخدام (~0.015 دولار لمنشور نصي، ~0.20 دولار لمنشور فيه رابط).
- مثل API تعديل المنشورات (3 أكتوبر أيضًا: نافذة 30 دقيقة، 5 تعديلات، Premium) — المنشورات المجدولة **مستبعدة**.

## Why it matters for ACI
المحتوى الطويل على X (بيانات، إعلانات، مقالات رأي) مصدر استخبارات اجتماعية قيّم. الـ Articles API يمنح مسار قراءة منظمًا للمحتوى الطويل يتجاوز منشورات الـ 25K حرف. عند توصيل الاستماع الاجتماعي لاحقًا: بوابة Premium + التسعير لكل طلب يؤثران في نموذج التكلفة.
