- **ما الذي تغيّر:** لا شيء. تتبّع KALO IQ لصفحات أسعار 20 منصة مؤثرين (لقطتان: 27 أكتوبر و4 نوفمبر 2026) وجد **صفر تغيير في أي حقل مُتتبَّع** في 18 صفحة قابلة للقراءة — منها **Modash** (Essentials ‏$199/شهر، Performance ‏$499، Enterprise من $14,700/سنة؛ تجربة 14 يومًا بلا بطاقة) و**HypeAuditor** (لا خطة ولا سعر في الصفحة المعروضة). التغيير الوحيد في الفترة كان في صفحة KALO IQ نفسها.
- **لماذا يهم ACI:** أسعار أدوات تحليل المؤثرين/الجمهور مستقرة؛ لا إعادة تقييم تكلفة مطلوبة الليلة.
- **المصادر:** https://www.kaloiq.com/research/influencer-platform-pricing-changes/ (لقطة 4 نوفمبر 2026)

## تذكير عدّاد — فوترة توسعات X API تبدأ 22 نوفمبر (بعد 11 يومًا)

- **ما الذي تغيّر:** لا جديد الليلة؛ التذكير قائم من دورة 6 نوفمبر: من **22 نوفمبر 2026** تُفوتر الكائنات المُعادة عبر `expansions` في X API v2 بمعدل المورد القياسي (منشور $0.005، مستخدم $0.010، وسائط/استطلاع/مكان $0.005 لكل منها). صفحة بحث من 100 منشور مع توسعات كاملة تكلف ~$0.50 اليوم و~$1.72 بعد 22 نوفمبر في عينة حيّة. سقف 3 ملايين قراءة منشور/شهر لخطط الدفع حسب الاستخدام.
- **سياق إضافي:** X API v2 الآن بنموذج دفع حسب الاستخدام بالكامل (رصيد يُشترى مقدمًا، بلا اشتراك)؛ **X Activity API (XAA)** يحلّ رسميًا محل Account Activity API للنشاط الفوري عبر webhooks؛ و**Powerstream** (أدنى زمن استجابة للبث العام) وُثّق في 21–22 أكتوبر. لا نقطة نهاية مخصصة لإنشاء/جدولة المنشورات في التوثيق حتى 31 أكتوبر.
- **لماذا يهم ACI:** أي جمع بيانات X في المهام يجب أن يطلب الحقول المطلوبة فقط ويتجنب التوسعات التلقائية — وإلا تضاعفت الفاتورة ~3.4× لنفس العمل بعد 22 نوفمبر.

- **الإجراء: watch** — صمّم استعلامات X بلا توسعات تلقائية قبل 22 نوفمبر.
