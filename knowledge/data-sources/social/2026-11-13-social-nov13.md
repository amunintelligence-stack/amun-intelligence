# دلتا اجتماعي — إيقاف RSS في Reddit يقع اليوم؛ LinkedIn Boost API؛ تقاعد Graph API v21.0 (13 نوفمبر 2026)

## A. إيقاف RSS في Reddit — اليوم، 13 نوفمبر 2026 (الموعد يقع)

- **ما الذي تغيّر:** Reddit ينهي دعم كل تغذيات RSS اليوم، الجمعة 13 نوفمبر 2026 (أُعلن 30 سبتمبر 2026 في r/modnews). كل تغذية `reddit.com/r/<sub>/.rss` وتغذيات المستخدم والبحث تُظلم في القارئات التي تجلب URL مباشرة (NetNewsWire وFreshRSS وMiniflux وReeder وغيرها). Reddit: «لا بديل» للتغذيات خارج مجتمع تُشرف عليه؛ المشرفون يُوجَّهون إلى تطبيقات Devvit (مثلًا Discord Relay). **تفاصيل جديدة ليست في السجل:** التطبيقات غير المسجلة تبدأ فقدان وصول API في **12 يناير 2027** (تاريخ وسيط جديد)؛ تغذيات Reddit المدعومة بـ API في NewsBlur بدأت تفشل بأخطاء 403 في **13 أكتوبر**؛ Inoreader أكد أنه لا يستطيع مواصلة الجلب بعد توقف التغذيات (مدونة 1 أكتوبر). مجتمع n8n ينشر أصلًا وصفات ترحيل RSS-Read ← HTTP Request.
- **لماذا يهم ACI:** أي تصميم استماع Reddit مبني على RSS مات من اليوم. الطرق الباقية الوحيدة هي Data API المتعاقد/المدفوع من Reddit (الوصول العام يغلق مارس 2027) أو مجمّعات مدعومة بـ API (تكامل Reddit في Feedly، Hushread) — وكلاهما يعتمد على الشروط التجارية لـ Reddit. لا مجموعة ACI تستخدم RSS في Reddit اليوم (حسب السجل)، فهذا قيد تصميم لا انقطاع.
- **المصادر:** https://hushread.com/blog/reddit-rss-shutdown (حُدّث 11 نوفمبر 2026)؛ https://rankhog.com/blog/reddit-api-pricing (حُدّث ~12 نوفمبر 2026، الجدول الكامل شامل 12 يناير 2027)؛ https://community.n8n.io/t/reddit-rss-ends-nov-13-swap-the-rss-read-node-for-one-http-request-keep-everything-downstream/328311
- **الإجراء: adopt (ممارسة)** — RSS في Reddit خارج الطاولة نهائيًا لأي تصميم مهمة؛ سجّل 12 يناير 2027 كجدار Reddit التالي.

## B. LinkedIn Boost API — جديد، أكتوبر 2026، ليس في السجل بعد

- **ما الذي تغيّر:** أضافت LinkedIn **Boost API** (أكتوبر 2026): تطبيقات طرف ثالث تستطيع تحويل منشور عضوي لعضو أو صفحة شركة إلى إعلان ممول برمجيًا. مدرج في جولة سجل تغييرات API الاجتماعية لـ 2–8 نوفمبر 2026.
- **لماذا يهم ACI:** سطح برمجي جديد للترويج المدفوع في LinkedIn — ذو صلة بنطاق مراقبة الإعلانات (المنشورات العضوية المعززة إعلانات، لكنها قد لا تظهر في نفس عروض المكتبة كالحملات الأصلية). وتذكير بأن سطح API في LinkedIn ما زال يتوسع بينما تغرب الإصدارات.
- **المصادر:** https://www.schedulesocialmedia.com/news/week-2026-45/ (9 نوفمبر 2026)؛ https://schedulesocialmedia.com/api-changes/
- **الإجراء: watch** — سجّل كسطح إعلانات LinkedIn جديد؛ تحقق من وثائق مطوري LinkedIn نفسها قبل الاعتماد عليه.

## E. Meta Graph API v27.0 — إزالتان ليستا في ملف v27 في السجل

- **ما الذي تغيّر:** beyond عناصر v27.0 المتتبعة أصلًا (ملف 6 نوفمبر: إعلانات WhatsApp Status وCatalog Batch API و`meta_moment_maker_spec` وحقول الشبه): (1) **ميزات طلب Graph API القديمة أُزيلت على كل الإصدارات في 27 أكتوبر 2026** (منها طلبات متعددة المعرفات للتطبيقات الجديدة من 4 نوفمبر)؛ (2) **مقياس `total_video_consumption_rate` أُوقف**؛ (3) **Graph API v21.0 يتقاعد 21 يناير 2027**، وv22.0 في 20 مايو 2027. (v27.0 `is_ai_generated` مغطى أصلًا 12 نوفمبر.)
- **لماذا يهم ACI:** أي كود جمع Meta يستخدم قراءات دفعية متعددة المعرفات أو مقياس استهلاك الفيديو ينكسر؛ أرضية v21.0 يجب أن تتحرك قبل 21 يناير 2027.
- **المصادر:** https://medium.com/@vyacheslav-gorbin/meta-api-update-2026-what-changes-for-instagram-facebook-and-smm-automation-a21561362201 (ثانوي، ~10 نوفمبر 2026)؛ https://schedulesocialmedia.com/api-changes/ (يؤكد إزالة 27 أكتوبر القديمة وتاريخ v21.0)
- **الإجراء: watch** — أضف تقاعد v21.0 (21 يناير 2027) إلى قائمة المواعيد؛ تحقق من قائمة الميزات القديمة مقابل سجل تغييرات Meta الرسمي قبل التدقيق القادم.
