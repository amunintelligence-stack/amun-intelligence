# YouTube Data API — الرفع من مشاريع غير موثقة لم يعد مقيدًا بالخاص؛ صور مصغرة مخصصة لـ Shorts

- **التاريخ:** 2026-11-02 و2026-11-03 (سجل مراجعة YouTube Data API).
- **ما الذي تغيّر:** (أ) مقاطع الفيديو المرفوعة عبر `videos.insert` من **مشاريع API غير موثقة لم تعد مقيدة بالخاص** — يعكس سياسة يوليو 2020؛ `privacyStatus` الافتراضي الآن `public` إن لم يُحدد. (ب) `thumbnails.set` يدعم الآن **صورًا مصغرة مخصصة لـ YouTube Shorts** بعد المعالجة، مع خاصية جديدة `shortsAspectRatio`.
- **لماذا يهم ACI:** يخفض حاجز النشر البرمجي على YouTube من أدوات ACI (مثل سير عمل قناة Dr Robot)؛ الصور المصغرة لـ Shorts مهمة لتغليف محتوى الاستخبارات الاجتماعية. بلا تغيير في حصص القراءة/البحث.
- **المصدر:** https://developers.google.com/youtube/data/revision_history (إدخالات بتاريخ 2026-11-02، 2026-11-03)
- **الإجراء: watch**
