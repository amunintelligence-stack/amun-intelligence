# YouTube Data API — رفع المشاريع غير الموثقة لم يعد خاصًا إجباريًا؛ صور Shorts المخصصة عبر API (8 نوفمبر 2026)

## رفع المشاريع غير الموثقة: من «خاص إجباري» إلى «عام افتراضيًا» (2 نوفمبر 2026)
- **ما الذي تغيّر:** عدّلت YouTube سجل مراجعات Data API في 2 نوفمبر 2026: مقاطع الفيديو المرفوعة عبر `videos.insert` من مشاريع API **غير موثقة** «لم تعد مقيدة بوضع المشاهدة الخاص» — يمكن أن تكون عامة فورًا، وإن لم يُرسل `status.privacyStatus` في الطلب فالفيديو **يُفترض عامًا** (مع استثناءات حسب إعدادات حساب المنشئ). هذا يعكس قاعدة سارية منذ **28 يوليو 2020** كانت تُبقي رفع المشاريع غير الموثقة خاصًا حتى يجتاز المشروع تدقيق امتثال.
- **لماذا يهم ACI / قناة Dr Robot:** محمد لديه سكربت رفع YouTube API (`youtube-api/upload.py`) لم يُصرَّح به بعد (بلا client_secret/token). عندما يصرّح به: أي رفع بلا `privacyStatus` صريح سينشر **عامًا فورًا** بدل أن يبقى خاصًا كما كان يفترض سابقًا. قبل أول رفع مصرّح به، ثبّت `privacyStatus` صراحة (private أو unlisted) في السكربت — وإلا ففيديو غير مكتمل (بلا ترجمة/صورة مصغرة) قد يظهر علنًا.
- **المصادر:** https://schedulesocialmedia.com/news/youtube-unverified-api-uploads-public/ (4 نوفمبر 2026، ينقل سجل مراجعات YouTube Data API بتاريخ 2 نوفمبر 2026)
- **الإجراء: adopt** — ثبّت `privacyStatus` صراحة في سكربت الرفع قبل أول استخدام مصرّح به.

## صور مصغرة مخصصة لفيديوهات Shorts عبر API (3 نوفمبر 2026)
- **ما الذي تغيّر:** تغيير ثانٍ في اليوم التالي: `thumbnails.set` يقبل الآن صورًا مصغرة مخصصة لفيديوهات YouTube Shorts بعد اكتمال المعالجة، ويكسب مورد الصور المصغرة خاصية `shortsAspectRatio`.
- **لماذا يهم ACI / قناة Dr Robot:** يفتح أتمتة الصور المصغرة لـ Shorts من السكربت نفسه — مفيد لسير عمل النشر (الترجمة + الصورة المصغرة أولًا قبل النشر، حسب قراره).
- **المصادر:** https://schedulesocialmedia.com/news/youtube-unverified-api-uploads-public/ (نفس المقال، 4 نوفمبر 2026)
- **الإجراء: watch** — أضف دعم صورة Shorts المصغرة عند تحديث سكربت الرفع.
