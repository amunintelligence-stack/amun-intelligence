# اجتماعي — غروب LinkedIn غدًا (16 نوفمبر)؛ فوترة توسعات X بعد 7 أيام؛ X API v2 والوصول المبكر (15 نوفمبر 2026)

## 1. LinkedIn Marketing API 202511 — الغروب غدًا، 16 نوفمبر

- **ما الذي تغيّر:** لا جديد في النص منذ أمس، لكن العدّ التنازلي انتهى: **Marketing Version 202511 يُغرب غدًا الاثنين 16 نوفمبر 2026** — أي مكالمة بلا ترويسة `LinkedIn-Version: 202511` بعد ذلك التاريخ تفشل. أُعيد التأكيد عبر وثائق Microsoft Learn (فُحصت 15 نوفمبر): النسخة الأحدث **202610**، وإصدار **202611** صدر ويتطلب حقل `surface` لقوائم الناشرين.
- **لماذا يهم ACI:** هذا آخر تنبيه قبل الغروب. أي جامع LinkedIn في ACI مثبَّت على 202511 يتوقف غدًا. الحد الأدنى للسجل ينتقل إلى 202610، و202611 عند أول مراجعة.
- **المصادر:** https://learn.microsoft.com/en-us/linkedin/marketing/versioning?view=li-lms-2026-10 (إشعار إهمال، فُحص 2026-11-15)؛ https://learn.microsoft.com/en-us/linkedin/marketing/integrations/recent-changes (202611 + الغروب)
- **الإجراء: adopt** — تحقق اليوم من إصدار LinkedIn المستخدم في أي جامع ACI قبل 16 نوفمبر؛ الترحيل تغيير ترويسة أساسًا.

## 2. X API — فوترة التوسعات تبدأ 22 نوفمبر (بعد 7 أيام)؛ الأسعار الدقيقة والتفاصيل الجديدة

- **ما الذي تغيّر:** لا تغيير في التاريخ، لكن التفاصيل الدقيقة ظهرت الليلة من مصادر متعددة: الكائنات التي تعيدها التوسعات (`includes`) تُفوتر من **22 نوفمبر 2026** بالأسعار القياسية نفسها: **منشور $0.005، مستخدم $0.010، وسائط $0.005، استطلاع $0.005، مكان $0.005**. مثال عملي: بحث يعيد 100 منشور مع مؤلفيهم كان يكلف $0.50؛ من 22 نوفمبر يكلف حتى $1.50. ثلاثة من الأسعار الخمسة (وسائط/استطلاع/مكان) **لا تظهر أصلًا في صفحة الأسعار العامة** — الإعلان الوحيد في منتدى مطوري X بتاريخ 23 أكتوبر 2026، لا في سجل التغيير ولا في صفحة الأسعار. حقول `fields` لم تكن فوترتها يومًا ولا تتغير. إزالة التكرار خلال نافذة 24 ساعة UTC ما زالت سارية.
- **لماذا يهم ACI:** أي جامع X في ACI يستخدم `expansions=author_id` أو `attachments.media_keys` سيرى فاتورته تتضاعف حتى ~3.4× لأحمال البحث الثقيلة. القاعدة العملية بعد 22 نوفمبر: أزل كل توسعة لا تستخدمها فعليًا، واطلب الحقول (`fields`) بدل الكائنات الموسَّعة حيث أمكن.
- **المصادر:** https://xautopilot.app/blog/x-api-expansions (نوفمبر 2026)؛ https://www.twitterapis.com/blogs/x-api-pricing-change-2026 (محدَّث 11 نوفمبر 2026)؛ https://futuretweets.com/x-api-expansions-billing-change-2026/
- **الإجراء: watch** — راجع استخدام التوسعات في أي جامع X قبل 22 نوفمبر.

## 3. X API v2 — وصول مبكر لنقاط نهاية جديدة؛ X Activity API يحل محل Account Activity API

- **ما الذي تغيّر:** في 29 أكتوبر 2026 أعلنت وثائق X المطورة **وصولًا مبكرًا لنقاط نهاية X API v2 الجديدة** على نموذج الدفع حسب الاستخدام بالرصيد، بلا اشتراكات ولا حد أدنى للإنفاق. وفي 28–29 أكتوبر **حلّ X Activity API (XAA) رسميًا محل Account Activity API (AAA)** للنشاط الفوري للمستخدمين. كذلك أُطلق **Powerstream** في 21 أكتوبر 2026 كواجهة بث بيانات عامة فورية بأقل زمن استجابة. مسارات البث المباشر ذات نطاق المستخدم تنتهي 1 يناير 2027 (كما هو مسجل).
- **لماذا يهم ACI:** تغييرات بنية تحتية في مصدر X: أي جامع يعتمد على AAA يجب أن ينتقل إلى XAA، وPowerstream خيار جديد لجمع البث الفوري بدل الاستطلاع الدوري. كلها ضمن نافذة الـ30 يومًا ولم تُغطَّ في ملفات الأيام السابقة.
- **المصادر:** https://futuretweets.com/x-api-v2-pay-per-use-pricing-scheduling-gap-2026/ (محدَّث 9 نوفمبر 2026)؛ https://www.twitterapis.com/blogs/x-api-pricing-change-2026
- **الإجراء: watch** — قيّد XAA وPowerstream كخيارات عند أول مراجعة لجامع X؛ لا تبعية AAA مؤكدة في المكدّس الحالي.
