# Google Custom Search JSON API يُغلق بالكامل في 1 يناير 2027

- **التاريخ:** الإغلاق **2027-01-01**؛ مغلق أمام المستخدمين الجدد منذ أوائل 2026.
- **ما الذي تغيّر:** **Custom Search JSON API من Google يُغلق بالكامل في 1 يناير 2027**. كان مسار بحث Google البرمجي الرخيص ($5/1,000 استعلام، 100 مجاني/يوم، سقف 10,000/يوم). بلا بديل مباشر من Google؛ يُدفع المستخدمون نحو تأسيس Gemini / Vertex AI Search أو واجهات بحث طرف ثالث.
- **لماذا يهم ACI:** إن اعتمدت أي مهمة أو أدوات في ACI على Google CSE لبيانات SERP/بحث الويب، فستنكسر خلال أقل من شهرين. انتقل إلى واجهات بحث Brave/Exa/Perplexity/You.com (انظر ai-search/) أو تأسيس Gemini.
