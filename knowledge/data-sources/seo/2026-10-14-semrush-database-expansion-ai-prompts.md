# Semrush database expansion — 28.9B keywords, 808M domains, 261M+ AI prompts

**Date of finding:** 2026-10-14
**Window covered:** last ~30 days

## What changed

- **Semrush's 2026 database figures (reported Oct 2026):** keyword database grown to **28.9 billion keywords across 142 geographic databases**; **808 million domains** tracked; **500 TB** of raw website-traffic data processed; **43 trillion backlinks**; **390 million referring domains**; **10 billion URLs crawled daily**. New: an **AI prompts database of 261 million prompts** (one table in the same report lists 317 million — treat the exact AI-prompt count as approximate; the direction is a large, growing prompt corpus for AI-visibility tracking).
- **Competitor comparison in the same report:** Ahrefs — 19.2B keywords, 28.5T backlinks, 212.5M referring domains; Moz — 1.25B keywords, 43.1T backlinks; SpyFu — 7B keywords, 6B backlinks. Semrush leads on keyword breadth and domain coverage; Moz remains comparable on raw backlink count.
- **Context:** the expansion underpins Semrush's AI-visibility push (see 2026-10-10 Semrush AI Visibility API note) — the prompt database is the raw material for "which brands does AI recommend" measurement.

## Why it matters for ACI

- For ACI's SEO/competitive-intel missions, Semrush remains the broadest single keyword + domain + traffic corpus — best default when one provider must be chosen for keyword-gap or domain-overview work.
- The AI-prompt database is directly relevant to ACI's AI-search work: Semrush can now answer "for which prompts does this brand appear in AI answers" at scale. Where ACI previously probed answer engines itself, Semrush's prompt corpus is a cross-check (and a possible feed).
- The conflicting prompt counts (261M vs 317M in one report) are a data-quality warning: treat vendor-ecosystem figures as directional, and verify any number ACI republishes against Semrush's own documentation before putting it in a client-facing brief.
- Backlink depth still favours a two-provider pattern: Semrush for keyword/traffic breadth, Ahrefs or Moz for link-graph depth (Moz's 43.1T backlinks rival Semrush's).
