# SEO — ملاحظات Semrush API بلا إدخالات جديدة منذ 20 نوفمبر (أُعيد تحديث الصفحة 23 نوفمبر)؛ وأرقام دقة النموذج الجديد؛ و6 إيقافات API بلا تاريخ (23 نوفمبر 2026)

> دلتا عن ملف أمس (2026-11-22-seo-nov22.md): لا نكرر سلسلة إصدارات API v4 (4–20 نوفمبر) ولا مقياس «AI-influenced traffic»؛ الجديد هو التحقق من عدم وجود إدخالات جديدة، وأرقام دقة النموذج الجديد، وقائمة إيقافات بلا تاريخ، وتفصيل Early Access.

## 1. ملاحظات إصدار Semrush API: لا إدخالات جديدة منذ 20 نوفمبر — الصفحة أُعيد تحديثها 23 نوفمبر (تم التحقق)

- **ما الذي تم التحقق منه:** صفحة ملاحظات الإصدار الرسمية (فُحصت 23 نوفمبر 2026) ما زالت تنتهي بإدخال 20 نوفمبر (Traffic & Market API v4) — بلا إدخالات 21–23 نوفمبر، رغم أن تذييل الصفحة يقول «آخر تحديث: 23 نوفمبر 2026». أي أن سلسلة v4 مكتملة كما سُجّلت أمس، والتحديث الأخير تحريري لا منتج.
- **لماذا يهم ACI:** v4 يبقى مسار السحب البرمجي الحالي لـSemrush؛ لا تغيير في خطة التكامل.
- **المصادر:** https://developer.semrush.com/api/v4/introduction/release-notes/ (فُحص 23 نوفمبر 2026).
- **الإجراء: ignore** — لا تغيير؛ أعد الفحص في دلتا الغد.

## 2. أرقام دقة النموذج الجديد لـTraffic & Market (ملاحظات 16 نوفمبر): تحسّن حتى ‏40%‏ للنطاقات الكبيرة الأمريكية

- **ما الذي تغيّر:** ملاحظات إصدار Semrush الرسمية (16 نوفمبر 2026) تكمّم تحسّن النموذج الجديد المسجَّل أمس: دقة تقدير المرور تحسّنت **حتى ‏40%‏ للنطاقات الكبيرة في الولايات المتحدة** و**حتى ‏30%‏ للنطاقات الصغيرة والمتوسطة عالميًا**؛ ودقة إسناد القنوات تحسّنت **حتى ‏45%‏ للصغيرة والمتوسطة في الولايات المتحدة** و**حتى ‏42%‏ عالميًا**. وتؤكد إعادة حساب بيانات Trends API التاريخية بالنموذج الجديد.
- **لماذا يهم ACI:** أرقام قابلة للاقتباس عند تبرير إعادة سحب خطوط الأساس؛ لكنها «حتى» (حد أعلى لا متوسط) ومن البائع نفسه — تُقتبس كادعاء بائع لا كقياس مستقل.
- **المصادر:** https://releasebot.io/updates/semrush (ملاحظات إصدار 16 نوفمبر 2026)؛ https://creatorstoolbox.com/@scout/post/n_1cfzah9xtxbia (نُشر 16 نوفمبر 2026).
- **الإجراء: watch** — أضف أرقام الدقة إلى مرجع Semrush مع وسم «ادعاء بائع».

## 3. ستة إيقافات Semrush API بلا تاريخ محدد — مسارات قديمة ستُزال

- **ما الذي تغيّر:** متتبع تغييرات API مستقل (حُدّث 10 نوفمبر 2026) يسرد 6 إيقافات «مهملة، بلا تاريخ» في ‏api.semrush.com‏ لم تكن في ملف أمس: إزالة نقاط ‏GET /analytics/v1/*‏؛ وإزالة ‏/api/v3/projects/position-tracking/*‏؛ وإزالة ‏/apis/v4-raw/listing-management/v1/*‏ و‏/apis/v4/listing-management/v1/*‏؛ وإزالة ‏/apis/v4/projects/v0*‏؛ وإزالة ‏/management/v1/projects*‏. بلا تواريخ سريان معلنة بعد — أي أن أي تكامل ACI يستخدم هذه المسارات يعمل اليوم لكن بلا ضمان.
- **لماذا يهم ACI:** أي تكامل مستقبلي مع Semrush يجب أن يتجنب هذه المسارات الستة تمامًا ويستهدف v4 الحالية؛ وأي كود قديم يستخدمها يُراجَع.
- **المصادر:** https://www.okapi.bot/providers/semrush-api/ (حُدّث 10 نوفمبر 2026).
- **الإجراء: adopt** — سجّل المسارات الستة كمحظورة في أي تكامل Semrush جديد.

## 4. تفصيل جديد: تقارير v4 للكلمات المفتاحية والروابط الخلفية ما زالت «Early Access»

- **ما الذي تغيّر:** مراجعة مستقلة لوثائق Semrush API (فُحصت نوفمبر 2026) تلاحظ أن تقارير Keyword وBacklinks في v4 موسومة **Early Access** — أي أن نقاط النهاية والصيغ والأسعار عرضة للتغيير — بينما بقية v4 (Domain Analytics، وPosition Tracking، وSite Audit، وTraffic & Market) مستقرة. وتوثّق المراجعة أيضًا فهارس ‏llms.txt‏ منفصلة لكل إصدار API (v4 وv3) على ‏developer.semrush.com‏، مفيدة لوكلاء ACI في استكشاف الوثائق برمجيًا.
- **لماذا يهم ACI:** أي تكامل يعتمد على Keyword/Backlinks في v4 يجب أن يتوقع تغييرات كاسرة؛ و‏llms.txt‏ مسار استكشاف وثائق جاهز للوكلاء.
- **المصادر:** https://www.anchorterminal.com/tools/semrush (مراجعة نوفمبر 2026)؛ https://developer.semrush.com/api/llms.txt.
- **الإجراء: watch** — لا تبنِ تكاملًا حرجًا على Keyword/Backlinks في v4 قبل استقرارها.

## 5. Moz: لا جديد في بحث اليوم (تم التحقق)

- **الإجراء: ignore** — لا تغيير؛ أعد الفحص في دلتا الغد.
