# SE Ranking: خادم MCP رسمي مشمول في كل الخطط (+ تتبع الظهور في بحث الذكاء الاصطناعي)
## ماذا تغيّر
- أطلقت SE Ranking **خادم MCP رسميًا** (سبتمبر 2026): يعرض الكلمات المفتاحية والروابط الخلفية والترتيب وتدقيق المواقع **وتتبع الظهور في بحث الذكاء الاصطناعي (AI search visibility)** عبر 160–180+ أداة — والتثبيت عن بُعد عبر OAuth يستغرق ~30 ثانية بدون Docker.
- النموذج السعري هو المفاجأة: الـ MCP والـ API **مشمولان في كل خطة** (25 ألف–100 ألف رصيد Data API شهريًا)، بينما المنافسون يفرضون رسومًا منفصلة — Ahrefs وSemrush (خطط مدفوعة + وحدات API مُقاسة)، وSimilarweb (مبيعات المؤسسات فقط، بلا MCP).
- مراجعات مقارنة (سبتمبر 2026) تضعه في المرتبة الأولى لفرق الوكالات التي تريد مساعدًا واحدًا موصولًا بكل الـ SEO stack.
## لماذا يهم ACI
- بديل أرخص بكثير من Ahrefs/Semrush لمهام استخبارات الـ SEO والمنافسين: API + MCP مشمولان في الخطة الأساسية (تبدأ ~$129/شهر) بدل رسوم API المنفصلة.
- تتبع AI-search visibility مدمج — يغطي نفس مساحة Ahrefs Brand Radar وSemrush AI Visibility Toolkit التي نراقبها.
