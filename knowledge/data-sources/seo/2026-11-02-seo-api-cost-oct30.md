# SEO API cost landscape, 30 Oct 2026: Semrush / Ahrefs / DataForSEO / Majestic

**Date noted:** 2026-11-02
**Category:** data-sources / seo — procurement reference (no ACI purchase)

## What changed
- AppBoard's comparison (vendor pricing pages read **30 Oct 2026**) prices the first API call for SEO data:
  - **Semrush Standard API**: add-on to the **Advanced/Enterprise** tier only; units bought in packages of **2 / 5 / 10 / 20 million**, unused units **expire at renewal** (do not roll over). Example rate: a backlinks request costs 40 units/line. The public pricing page no longer shows a Business tier — API access is not on Starter/Pro+.
  - **DataForSEO**: **$50 minimum top-up, no subscription**; SERP pages from **$0.60 per 1,000**. Cheapest entry to programmatic SERP/keyword/backlink data.
  - **Ahrefs**: full API access tied to the **Enterprise plan** (price unpublished); free test queries offered without Enterprise.
  - **Majestic**: API on one plan only — **€379.99/month** (monthly) / €316.66 (yearly), 100M analysis units; backlinks only.
  - **SE Ranking**: from **€45 for 250,000 credits**, pay-as-you-go; API + MCP included in every plan (already in registry).
- Companion piece (Professional Toolkit, read 12 Oct 2026): Semrush **AI Visibility toolkit $99/month/domain** (annual) or bundled in Starter/Pro+; Starter/Pro+ include **50,000 MCP units**; Ahrefs includes API + MCP on every plan (100/250/500 rows per request by tier) — "for building on the data, Ahrefs is easier to start with" at low tiers, Semrush wins on daily rank tracking and AI-prompt volume (50/100/200 vs Ahrefs 5/10/20).

## Why it matters for ACI
- ACI's SEO data today is keyless/observation-based. If a paid SEO key is ever approved, the cost order is: **DataForSEO first** (pay-per-request, no subscription lock-in) for SERP/keyword/backlink bulk; **SE Ranking** for an integrated workflow with MCP included; Semrush/Ahrefs only when a specific dataset justifies their tier gates. The Semrush unit-expiry rule is a budget trap to flag in any future purchase memo.
- Semrush MCP (50k units on Starter/Pro+) is already tracked (28 Oct nightly); this file adds the Standard API pricing that sits behind it.
