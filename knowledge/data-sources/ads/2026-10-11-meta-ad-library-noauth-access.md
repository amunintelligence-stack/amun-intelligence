# Meta Ad Library: وصول بلا توكن/تحقق هوية عبر سكرابر Apify + عميل MCP (أكتوبر 2026)

- التاريخ: 2026-10-11 | الفئة: data-sources/ads | الإجراء: **اعتماد/تقييم (adopt — تقييم عملي)**

## What changed
(1) ~7 أكتوبر 2026: ظهر «Meta Ad Library Scraper» (actor على Apify، dev.to) كبديل للمسار الرسمي — لا يحتاج token ولا تحقق هوية، ويعيد لكل إعلان: معرف المكتبة ورابطه، تواريخ البدء/الإيقاف، علامة «نشط»، عدد أيام التشغيل (daysRunning محسوب دائمًا)، المنصات، العنوان والنص والـ CTA، رابط ورابط دومين الهبوط، روابط الصور والفيديو؛ ولإعلانات الاتحاد الأوروبي: الوصول حسب الدولة والفئة العمرية/الجنس والاستهداف المنشور واسم الدافع (بيانات خلف نقرة ثانية على الموقع الرسمي — الـ actor يفتحها تلقائيًا). فيه وضع مراقبة: `onlyNewSinceLastRun` مع تنبيه للإعلانات الجديدة وتجاوز عتبات 30/60/90 يوم تشغيل. المطوّر قاس في أكتوبر 2026: 20 جلسة اختبار بلا حظر فعلي، وبحث Nike + «protein powder» أعاد 85 إعلانًا، وبحث المراقبة بعد 20 دقيقة أعاد فقط الـ 50 الجديدة. (2) عميل MCP خفيف جديد `mcp-meta-ad-library-monitor` (npm، محدّث أوائل أكتوبر 2026) يغلّف نفس الـ actor كخادم MCP لأدوات Claude/الوكلاء — يحتاج Apify token وtoken من تطبيق Meta (الـ Ad Library API ليست مفتوحة بدونه)، وتحقق هوية إضافي لبيانات الإعلانات السياسية. (3) سياق يهم التخطيط: المسار الرسمي (ads_archive) ما زال يتطلب تحقق هوية ببطاقة حكومية على حساب فيسبوك (1–3 أيام عمل) + تطبيق مطوّر + تمرير `ad_reached_countries` مع كل طلب، ويغطي الإعلانات التجارية **فقط** للمعروضة في الاتحاد الأوروبي/المملكة المتحدة (إعلان تجاري أمريكي خالص غير مرئي)، والإنفاق/الانطباعات للسياسية فقط — بينما واجهة الموقع تعرض كل الإعلانات النشطة لأي دولة (لكن طلب HTTP عادي يرجع 403 + تحدي JS). (4) بيئة MCP الإعلانية تتوسع: Meta فتحت موصلات إعلاناتها لـ Claude/ChatGPT (~نهاية أبريل 2026) ثم لأي تطبيق في يوليو؛ وفي خادم طرف ثالث مستضاف `meta-ads.mcp.pipeboard.co` (ملاحظة: ليس رسميًا).

## Why it matters for ACI
موصل ads لدينا بحاجة لمصدر Meta موثوق بلا احتكاك (التحقق بالبطاقة الحكومية احتكاك عملي). هذا الـ actor يعطي مسار تقييم سريع بلا مفاتيح Meta، وحقل daysRunning إشارة أداء ضمنية (الإعلان الذي يبقى ممولًا 60+ يومًا غالبًا مربح). عميل MCP يجعله صالحًا مباشرة لبنية الوكلاء. البديل الرسمي أغنى للاتحاد الأوروبي (نفقات حقيقية) لكن بكلفة التحقق — الاثنان يكملان بعضهما كما في ملاحظة مكتبة mcp السابقة.
