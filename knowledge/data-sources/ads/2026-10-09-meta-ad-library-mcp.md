# أداة MCP جديدة: facebook-ad-library-mcp-cli — وصول مجاني لمكتبة إعلانات Meta

- التاريخ: 2026-10-09 | الفئة: data-sources/ads | الإجراء: **اعتماد/مراقبة (adopt/watch)**

## ما الذي تغيّر
خادم/CLI بصيغة MCP (thenavidm) لقراءة Meta Ad Library من الـ JSON البنيوي للصفحة بدل النص المعروض: 3 خلفيات (متصفح مجاني بلا مفتاح افتراضيًا، ScrapeCreators، Apify)، 8 أدوات للقراءة فقط منها `diff_advertiser` (ما بدأ/توقف المعلن عن تشغيله) و`get_eu_transparency` (الإنفاق والوصول الحقيقيان عبر API الرسمي). سجل التغييرات محدّث قبل ~12 يومًا (v0.2.0: بحث مكرر مجاني، خلفية Apify أرخص).

## لماذا يهم ACI
موصل "ads" لدينا يعتمد على Meta Ad Library — هذه الأداة توفر طبقة جاهزة بصيغة MCP (متوافقة مع بنيتنا) وبديلًا مجانيًا بلا مفاتيح.
