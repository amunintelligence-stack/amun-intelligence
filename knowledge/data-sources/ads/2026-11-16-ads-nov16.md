# إعلانات — Supermetrics: موصلات Meta تنتقل إلى Graph API v26.0؛ حقول تقدير الوصول في Facebook Ads أُزيلت 27 أكتوبر؛ إسقاط SHA-256 في Data Manager يدخل حيّز التنفيذ اليوم (16 نوفمبر 2026)

## 1. Supermetrics — تحديثات منتج نوفمبر 2026: Graph API v26.0 وحقول أُزيلت (نوفمبر 2026)

- **ما الذي تغيّر:** نشرت Supermetrics تحديثات منتج **نوفمبر 2026**:
  - **موصلات Meta تنتقل إلى Graph API v26.0**: Facebook Ads، Facebook Insights، Facebook Public Data، Facebook Billing Data، Instagram Insights، Instagram Public Data.
  - **Facebook Ads: ستة حقول تقدير وصول (Reach estimate) توقفت عن إرجاع البيانات في 27 أكتوبر** — Meta أزالت الحقول الأساسية بلا بديل؛ أزِلها من التقارير.
  - **LY Ads (LINE Yahoo! Ads) Display Ads**: انتقل الموصل إلى API v20 في 4 نوفمبر (v18 يُتقاعد)؛ حقلان أُزيلا ونوع بيانات حقل تغيّر.
  - **AI Campaign Management** أُطلقت **10 نوفمبر**: موجز واحد لـ Supermetrics، ثم تنبيهات واعتماد تغييرات عبر Google وMeta وMicrosoft وTikTok وLinkedIn من محادثة ذكاء اصطناعي.
  - **Semrush Projects**: موصل soft deprecated (انظر ملف SEO الليلة).
- **لماذا يهم ACI:**‏ أي سحب بيانات إعلانات عبر Supermetrics يجب أن يتحقق من حقول تقدير الوصول المزالة (تقارير تعيد فراغًا منذ 27 أكتوبر دون خطأ واضح) ومن إصدار Graph API v26.0. إدارة الحملات بالذكاء الاصطناعي نمط جديد يستحق المتابعة — لكنه تنفيذي (تغييرات على حسابات حقيقية)، فلا يُفعّل في ACI دون ضوابط موافقة بشرية.
- **المصادر:** https://supermetrics.com/blog/november-2026-product-updates (تحديثات نوفمبر 2026)
- **الإجراء: adopt** — راجع أي تقارير Facebook Ads عن حقول Reach estimate المزالة؛ وثّق Graph API v26.0 كإصدار Meta الحالي في قوالب الجمع.

- **الإجراء: watch** — تحقق من أن أي رفع بيانات أولية عبر Data Manager يتبع القاعدة الجديدة.
