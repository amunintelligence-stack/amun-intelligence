# TikTok: API مكتبة المحتوى التجاري (Commercial Content Library) — شفافية إعلانية بموجب DSA
## ماذا تغيّر
- حدّثت TikTok شروط المطورين (~24 سبتمبر 2026، وفق تحليل OpenTermsArchive): أضافت تعريفًا رسميًا لمجموعة بيانات **"CCL Data"** (المحتوى الإعلاني والتجاري) وأغراض استخدامها **"CCL Purposes"** — البحث في مخاطر الإعلانات: إعلانات غير قانونية، تلاعب، تضليل، وتأثيرات على الصحة العامة والأمن والخطاب المدني.
- الـ **Commercial Content Library API** أصبحت مُعرَّفة رسميًا ومربوطة صراحةً بـ **المادة 39 من قانون الخدمات الرقمية الأوروبي (DSA)** — أي مسار امتثال رسمي للوصول إلى بيانات الإعلانات.
- الوصول: المكتبة التجارية مفتوحة للعامة (بيانات أوروبا حاليًا، وتوسع لمناطق أخرى لاحقًا)، والـ API متاح للباحثين بحساب TikTok for Developers.
## لماذا يهم ACI
- مصدر استخبارات إعلانية **جديد ومجاني**: بيانات الإعلانات المدفوعة + معايير الاستهداف (targeting parameters) + تواريخ التشغيل — مثالي لتتبع الحملات الإعلانية للشركات المستهدفة في المهام.
- يكمل ما لدينا: Meta Ad Library (عبر MCP) + Google Ads Transparency (بدون API رسمي) — TikTok كانت الثغرة، والآن لها مسار رسمي.
