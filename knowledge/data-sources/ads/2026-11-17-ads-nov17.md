# إعلانات — بلا تغييرات مكتبات جديدة الليلة؛ تذكير بالاحتفاظ والـ API الرسمي لـ TikTok (17 نوفمبر 2026)

## بلا تغيير — تحقق الليلة

- **Meta Ad Library / Google Ads Transparency Center / TikTok Commercial Content Library**: بلا تغييرات إعلان أو إصدار جديدة الليلة (بحث إخباري).
- **الاحتفاظ (مغطى 11 نوفمبر، تذكير):** إعلانات Google وTikTok تُحفظ **سنة بعد آخر عرض**؛ إعلانات Meta التجارية العادية تختفي عند توقفها (إعلانات الاتحاد الأوروبي/المملكة المتحدة تُؤرشف سنة بعد آخر ظهور) — **لقطة شاشة لأي إعلان Meta مفيد في يوم العثور عليه**.
- **TikTok (مغطى 3 و5 نوفمبر، تذكير):** **لا يوجد API عام لـ Creative Center** — يعمل على نقطة نهاية داخلية موقّعة تعطّلت بيانات الاتجاهات فيها في أكتوبر 2026 (مسارات `/creative_radar_api/v1/popular_trend/` القديمة تعيد `code 0, data null, msg deprecated` منذ 27 أكتوبر). الرسمي الوحيد هو **Commercial Content API** (أوروبا فقط، 10 سجلات لكل استدعاء، عبر TikTok for Developers).
- **Supermetrics نوفمبر 2026 (مغطى 16 نوفمبر):** موصلات Meta إلى Graph API v26.0؛ ستة حقول تقدير وصول Facebook Ads أُزيلت 27 أكتوبر بلا بديل؛ AI Campaign Management أُطلقت 10 نوفمبر (تنفيذية — تحتاج ضوابط موافقة بشرية قبل أي استخدام في ACI).
- **Google Data Manager:** إسقاط شرط التجزئة المسبقة SHA-256 دخل حيّز التنفيذ 16 نوفمبر (مغطى) — بلا جديد الليلة.
- **LinkedIn 202611:** حقل `surface` (LAN/CTV) مطلوب لقوائم الناشرين (مغطى 16 نوفمبر) — بلا جديد.
