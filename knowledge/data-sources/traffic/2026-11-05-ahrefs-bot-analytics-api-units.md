# Ahrefs — Bot Analytics (Vercel/CloudFront/Fastly)، مضاعفة وحدات API، واجهات Brand Radar

- **التاريخ:** 2026-09-05 و2026-09-24 و2026-09-29 (سجل تغيير Ahrefs).
- **ما الذي تغيّر:** (أ) **Bot Analytics** يتكامل الآن مع **Vercel وAmazon CloudFront وFastly** (إضافة إلى Cloudflare) — 29 سبتمبر. Bot Analytics يتتبع حركة زوار الروبوتات/AI إلى موقع. (ب) **وحدات API تضاعفت لكل الخطط (Lite+) بلا تكلفة إضافية** — 24 سبتمبر، صراحة لدعم نمو API + MCP (22× منذ بداية العام). (ج) **واجهة Content Helper Topics** الجديدة، **واجهة إدارة وسوم/مطالبات Brand Radar** (PATCH)، **نقطة نهاية عامة لأعلى مليون نطاق حسب DR** (أيضًا عبر MCP)، واجهة إدارة مشاريع بالمجلدات — 5 سبتمبر. (د) **Ahrefs Connect** (19 أغسطس): طبقة تكامل OAuth على API v3 لأدوات الطرف الثالث.
- **لماذا يهم ACI:** Bot Analytics ذو صلة مباشرة باستخبارات رؤية AI (أي روبوتات/زواحف AI تضرب موقع هدف، وكم مرة) — فئة إشارات جديدة لمهام الحركة. مضاعفة وحدات API + MCP + Connect تخفض تكلفة توصيل بيانات Ahrefs إلى وكلاء ACI.
- **المصدر:** https://ahrefs.com/blog/new-features/ (سجل التغيير، إدخالات 5 / 24 / 29 سبتمبر 2026)
- **الإجراء: watch** (Bot Analytics إشارة استخبارات جديدة حقيقية؛ قيّم عند لمس توصيل استخبارات الحركة تاليًا)
