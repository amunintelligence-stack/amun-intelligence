# Cloudflare Radar يعيد التصميم (2026-10-08): مرصد مجاني + API مفتوح لذكاء الترافيك

## ماذا تغيّر؟

أعادت Cloudflare تصميم **Cloudflare Radar** (radar.cloudflare.com) في **8 أكتوبر 2026** — المرصد العام المجاني المبني على بيانات شبكة Cloudflare العالمية ومحلّل DNS العام 1.1.1.1. التطورات التراكمية: Radar 2.0 + API في سبتمبر 2022، AI Insights (نشاط زواحف الذكاء الاصطناعي) في فبراير 2025، نسبة crawl-to-refer في يوليو 2025.

ما يقدمه مجانًا (بدون مفتاح مدفوع): ترافيك الإنترنت الإجمالي، نشاط البوتات وزواحف AI، الهجمات، حوادث التوجيه (routing incidents)، تصنيفات الدومينات، الأعطال — كل ذلك عبر الواجهة و**Radar API** المجاني.

## لماذا يهم ACI؟

- **مصدر keyless مجاني** لذكاء الترافيك يكمل SimilarWeb (المدفوع) — مفيد لمقارنة ادعاءات الترافيك للكيانات التجارية، ورصد الهجمات/الأعطال التي تمس أهداف المراقبة.
- بيانات AI crawler activity (منذ فبراير 2025) مدخل فريد: يكشف أي دومينات تُزحف بكثافة من أنظمة الذكاء الاصطناعي — مؤشر استخباري على اهتمام السوق/الأبحاث بكيان ما.
- المحاذير: البيانات مُبلَّغة ذاتيًا من Cloudflare، غير مدققة، وتقتصر على قاعدة عملائها — لا تُستخدم كرقم وحيد، بل كمصدر تقاطع (corroboration).

## الإجراء المقترح: تبنَّ

أضف Radar API إلى طبقة ذكاء الترافيك في ACI كمصدر مجاني بدون مفتاح بجانب SimilarWeb — خصوصًا endpoints تصنيف الدومينات ونشاط البوتات وزواحف AI. جرّب الاستعلامات أولًا من الواجهة العامة قبل كتابة connector.

> الثقة: متوسطة (مصدر ثانوي واحد؛ وثائق Cloudflare الرسمية لم تُفتح مباشرة)
