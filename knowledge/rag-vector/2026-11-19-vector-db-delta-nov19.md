# دلتا قواعد البيانات المتجهية — Weaviate 1.40.6 اليوم (إصلاحات أمنية)؛ Qdrant 1.20.2 ما زال الأحدث؛ Chroma Cloud: 3 أيام على إيقاف الكتابة (19 نوفمبر 2026)

## ⭐ 1. Weaviate 1.40.6 (19 نوفمبر 2026، اليوم) — إصلاحات أمنية وموثوقية إعادة الفهرسة

- **ما الذي تغيّر:** صدر **Weaviate v1.40.6** اليوم (19 نوفمبر): بلا تغييرات كاسرة وبلا مزايا جديدة — إصلاحات فقط: الإبلاغ الصادق عن أخطاء سجلات ترحيل إعادة الفهرسة والاحتفاظ بالمجلدات التي قد تحتاجها، تدوير تطابق المستخدم، إصلاح فشل البحث أثناء ترقية فهرس ديناميكي بمكمّمات مختلفة، وتسريع بدء عقدة بـ100 ألف مستأجر من 16 دقيقة إلى 6 ثوانٍ مع إعادة الفهرسة وقت التشغيل.
- **لماذا يهم ACI:**‏ Weaviate خارج المكدّس (هدف الترقية هو Qdrant)، لكنه مرجع المقارنة والخطة الاحتياطية. الحد الأدنى المُصلَّب لأي تجربة Weaviate مستقبلية **يرتفع 1.40.5 ← 1.40.6**.
- **المصادر:** GitHub API (weaviate/weaviate releases/tags/v1.40.6، فُحص 19 نوفمبر 2026)
- **الإجراء: watch** — حدّث الحد الأدنى المُصلَّب في السجل إلى 1.40.6؛ لا تغيير في خطة Qdrant.

## 2. Qdrant 1.20.2 — أُعيد التحقق الليلة كأحدث إصدار؛ بوابة الاعتماد مفتوحة

- **ما الذي تغيّر:** **Qdrant v1.20.2** (16 نوفمبر) ما زال الأحدث؛ لا 1.20.3 بعد. ملاحظات الإصدار: تسريع عمليات البحث الدفعية بنفس المرشح على نفس المتجه، عودة بناء رسوم HNSW بالخوارزمية الكلاسيكية افتراضيًا (ليضبط `ef_construct` جودة الرسم على المقاطع الكبيرة)، وتحميل إعدادات المجموعات دون `ef_construct` حتى يعمل الرجوع من 1.21.
- **لماذا يهم ACI:**‏ هدف الترقية من RAG الحالي (TF-IDF) إلى Qdrant. بوابة الاعتماد التي تحققت في 13 نوفمبر (صدور 1.20.1) ما زالت قائمة، والآن التثبيت المقترح **1.20.2** بدل 1.20.1 — يتضمن إصلاح تراجع HNSW الأبطأ 3× (#11343) إضافة إلى تحسينات 1.20.2.
- **المصادر:** GitHub API (qdrant/qdrant releases/tags/v1.20.2، فُحص 19 نوفمبر 2026)
- **الإجراء: watch** — حدّث التثبيت المقترح في السجل إلى qdrant/qdrant:v1.20.2؛ الاعتماد نفسه يبقى بقرار محمد في نافذة صيانة.
