# Cohere تطلق Embed 5 — نموذجا تضمين مؤسساتيين (Pro + Fast) في مساحة متجهات مشتركة

- التاريخ: 2026-10-09 | الفئة: rag-vector | الإجراء: **مراقبة (watch)**

## ما الذي تغيّر
في 30 سبتمبر 2026 أطلقت Cohere عائلة Embed 5 بنسختين: **Pro** (أقصى جودة استرجاع) و**Fast** (استعلامات تفاعلية أرخص وأسرع) — والجديد أنهما **يشتركان في نفس مساحة التضمين**: تبني الفهرس مرة واحدة بـ Pro وتستعلم بـ Fast دون إعادة بناء. كلتاهما: سياق 128K توكن، +100 لغة، نص/صور/مزيج، أبعاد Matryoshka (2048→256)، float/int8/binary، ViDoRe V3 عند Pro = 85.8. الأسعار: $0.12 (Pro) و$0.08 (Fast) لكل مليون توكن نصي، و$0.40 للصور. متاح عبر Cohere API / Model Vault / Microsoft Foundry / Amazon SageMaker، ويدعم النشر الخاص عبر vLLM للجهات المنظمة.

## لماذا يهم ACI
الـ RAG عندنا حاليًا TF-IDF بسيط — هذا أبرز مرشّح لترقية التضمين نفسها: نموذج متعدد اللغات (مهم للعربية/الإنجليزية معًا في أعمال ACI) بسياق طويل يقلّل التقطيع. النمط الاقتصادي (فهرسة Pro + استعلام Fast) مفيد جدًا لمهمات المسح الكثيفة. لكنه API مدفوع — يحتاج مفتاح Cohere.
