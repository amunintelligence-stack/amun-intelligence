- **ما الذي تغيّر:** صفحة إصدارات Weaviate عبر GitHub API تؤكد أن **v1.41.0-rc.0 نُشر 2026-11-16T19:37:13Z** — يحسم سؤال الأمس عن تاريخ الـ RC (كان غير مؤكد). المستقر ما زال **1.40.5** (10 نوفمبر). محتوى الـ RC كما ذُكر أمس: مساحات أسماء RF=3 والإيقاف، إدارة مفاتيح API متقدمة، إعادة توازن شبه تلقائية للشرائح (معاينة)، وصيغة أقل ذاكرة لعقد HNSW.
- **لماذا يهم ACI:**‏ لا تغيير في الخطة (Qdrant هو الهدف)؛ التاريخ المؤكد يغلق بند المتابعة من الأمس.
- **المصادر:** https://api.github.com/repos/weaviate/weaviate/releases (فُحص 2026-11-17)
- **الإجراء: watch** — راقب استقرار 1.41.0؛ لا تغيير في خطة Qdrant.

## 2. PostgreSQL — إصدارات صيانة 12 نوفمبر تصلّح 52 CVE (منها CVE-2026-6460)

- **ما الذي تغيّر:** في **12 نوفمبر 2026** صدرت إصدارات PostgreSQL الصغرى **18.7 و17.12 و16.16 و15.20 و14.25** تصلّح **52 CVE**؛ أبرزها **CVE-2026-6460**: مستخدم قاعدة بيانات يستطيع إنشاء كائنات يستطيع تنفيذ كود كخادم قاعدة البيانات.
- **لماذا يهم ACI:**‏ طبقة التخزين في ACI ثلاثية (PostgreSQL `aci` ← SQLite ← ذاكرة)، وpgvector يعيش على PostgreSQL. أي نشر مستقبلي لـ Postgres في ACI يجب أن يبدأ من هذه الإصدارات كحد أدنى، لا من إصدار أقدم.
- **المصادر:** https://www.pranavaraparla.com/vibe-coding-security/advisories/index.html (إدخال 2026-11-12)
- **الإجراء: adopt** — حدّد **PostgreSQL 17.12** (أو 18.7) كحد أدنى لأي نشر Postgres جديد في ACI؛ وثّق CVE-2026-6460 كسبب (تنفيذ كود عبر إنشاء كائنات).

## 3. ChromaToast (CVE-2026-45829) — ما زال بلا إصلاح رسمي؛ إغلاق Chroma Cloud بعد 5 أيام

- **ما الذي تغيّر:** لا جديد الليلة. **Chroma 1.5.9** (5 مايو 2026) ما زال الأحدث (GitHub API)، والاستشارة الرسمية GHSA-f4j7-r4q5-qw2c ما زالت تقول **لا إصدار مُصلَح** (آخر تحديث للاستشارة 29 مايو 2026). ملاحظة منهجية: بعض مجمّعات CVE (Feedly) تعرض «Patch available» — هذا **توليد آلي غير موثوق**؛ المصدر الرسمي (GitHub Advisory + Wiz) يقول لا إصلاح. **الموعد: إيقاف الكتابة في Chroma Cloud 22 نوفمبر (بعد 5 أيام)، وإيقاف القراءة 22 ديسمبر.**
- **لماذا يهم ACI:**‏ لا استخدام لـ Chroma في ACI؛ التذكير مستمر لأن أي مهمة تذكر Chroma يجب أن تحمل تحذير «بلا إصلاح، CVSS 10.0، pre-auth RCE».
- **المصادر:** https://github.com/advisories/GHSA-f4j7-r4q5-qw2c (لا إصدار مُصلَح)؛ https://www.wiz.io/vulnerability-database/cve/cve-2026-45829؛ https://api.github.com/repos/chroma-core/chroma/releases/latest (1.5.9)
- **الإجراء: ignore** — لا Chroma في ACI؛ احتفظ بالموعدين كمرجع مخاطر مورّدين.
